# 敵の立ち絵の置き場所

**このフォルダに 敵ID.png という名前で画像を置くだけで反映されます。**
データファイルの編集は不要です。

## 味方との違い

味方の立ち絵は顔を自動で切り抜いてアイコンにしますが、**敵は切り抜きを一切しません。**
生成した画像をそのままの構図で戦闘画面に表示します。加工は不要です。

## 推奨サイズ

**832 x 1216**（縦長）。キャラクターの立ち絵と同じサイズです。表示枠もこの比率に合わせてあります。
別の比率でも動きますが、上下または左右がわずかに切れます。

背景は**透過（アルファ付きPNG）を推奨**します。戦闘画面の背景に馴染みます。
透過していない画像でもそのまま表示できます。

.png のほか .webp .jpg も読み込めます（この順に探索）。

> 立ち絵を置いていない敵については、開発者ツールに404が表示されます。
> **これは異常ではありません。**「探しに行って無かったので紋様タイルにフォールバックした」という動作です。

## ファイル名の一覧

**一覧はここに書きません。** 敵を追加するたびに二重管理になるためです。
現在の一覧と、どれがまだ未設定かは次のどちらかで確認してください。

```bash
python tools/import_images.py --list
```

または開発サーバーを起動して <http://localhost:8124/tools/import.html> を開くと、
未設定のものだけを絞り込んで表示できます。

## 取り込み

手でリネームして置く必要はありません。上の2つの道具が、
生成した画像を正しい名前でこのフォルダへ入れてくれます。
詳しくは [../../README.md の「画像の取り込み」](../../README.md#画像の取り込み) を参照してください。

## 確認

`test/art.html` を開くと、配置済みの敵の立ち絵を一覧で確認できます。
