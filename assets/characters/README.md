# 立ち絵の置き場所

**このフォルダに `キャラクターID.png` という名前で立ち絵を置くだけで反映されます。**
データファイルの編集は不要です。顔アイコンは立ち絵から自動で切り抜かれます。

> 現在、女性キャラクター12体には `raw_image/` から選んだ立ち絵を配置済みです。
> どの画像を誰に割り当てたかは [ASSIGNMENTS.md](ASSIGNMENTS.md) を参照してください。
> 主人公（`ch_hero.png`）だけ未配置で、生成SVGのままです。

## ファイル名の一覧

**一覧はここに書きません。** キャラを追加するたびに二重管理になるためです。
現在の一覧と未設定のものは次で確認できます。

```bash
python tools/import_images.py --list
```

開発サーバーを起動して <http://localhost:8124/tools/import.html> を開いても同じものが見られます。

## 取り込み

手でリネームして置く必要はありません。上の2つの道具が、
生成した画像を正しい名前でこのフォルダへ入れてくれます。
詳しくは [../../README.md の「画像の取り込み」](../../README.md#画像の取り込み) を参照してください。

`.png` のほか `.webp` `.jpg` も読み込めます（この順に探索）。

> 立ち絵を置いていないキャラクターについては、ブラウザの開発者ツールに
> 404（ファイルが見つからない）が表示されます。**これは異常ではありません。**
> 「ファイルがあるか探しに行って、無かったので生成SVGにフォールバックした」という動作です。
> 探索は1回のページ読み込みにつき1度だけ行われます。
> 気になる場合は `data/art.js` の `extensions` を `['.png']` だけに減らしてください。

## 推奨サイズ

**832 × 1216**（縦長）。表示枠もこの比率に合わせてあります。
別の比率でも動きますが、上下または左右がわずかに切れます。

背景は**透過（アルファ付きPNG）を推奨**します。顔の自動検出の精度が上がり、
枠の中でキャラクターだけが浮かぶ見た目になります。

## 顔アイコンについて

顔アイコンは立ち絵から自動で切り抜かれるので、**用意する必要はありません。**

自動検出は次のように動きます。

1. 立ち絵を縮小してピクセルを読む
2. 透過部分（または四隅の色）から背景を判定し、キャラクターの外接矩形を求める
3. その上端から一定割合の帯を頭部とみなす
4. 帯の中の重心を中心に正方形を切り出す

検出結果はブラウザに保存され、次回以降は再解析されません。

### 自動検出がうまくいかない場合

顔の位置は `data/characters.js` の `art.face` で手動指定できます。指定があれば自動検出より優先されます。

```js
ch_rizel: {
  // ...
  art: {
    face: { x: 0.5, y: 0.13, size: 0.30 },  // 画像サイズに対する割合
    // ...
  },
}
```

- `x` … 顔の中心のX（画像の**幅**に対する割合）
- `y` … 顔の中心のY（画像の**高さ**に対する割合）
- `size` … 切り抜く正方形の一辺（画像の**幅**に対する割合）。小さいほど寄る

`test/art.html` を開くと、切り抜き結果をその場で確認しながら値を調整できます。

### 顔アイコンを画像ファイルとして持ちたい場合

`test/art.html` の「顔アイコンを書き出す」ボタンで、切り抜いた正方形を 512×512 のPNGとして
ダウンロードできます。書き出したファイルを `assets/characters/icons/` に同じファイル名で置くと、
自動切り抜きより優先して使われます。

> 書き出し機能はブラウザの制限により、ローカルサーバー経由（`http://localhost:...`）で
> 開いている場合のみ動作します。`index.html` をダブルクリックで開いた場合は使えません。

## 立ち絵を差し替えたとき

顔の検出結果がブラウザに保存されているため、同じファイル名で差し替えた場合は
`test/art.html` の「検出キャッシュを消去」を押してください。
