# 女帝 III — 実装案

作成日: 2026-09-25
状態: 実装済み（2026-09-25）。共有元はSPのツリーだけ、対象は passives の規則表。**複数の女帝は足さずに最大**（ユーザー判断）。経緯と実測は `docs/作業ログ/女帝の実装と測定.md`。
参照: [女帝検討用パッシブ一覧](女帝検討用パッシブ一覧.md)

## 設計意図

本人が習得したパッシブの一部を弱め、その分を他の味方へ共有するアルカナ。
女帝の育て方を、編成全体の育て方へつなげる。
本人に不要な攻撃パッシブであっても、取得するSPと、代わりに取れない回復・防御・支援が対価になる。
本人の効果が半分になることも対価であり、「本人が使わないから無償」とは評価しない。
ただしSP効率が厳密に半分になるわけではない。取得条件・上限・非線形な効果・複数人への共有を含めて評価する。

## 札の文面案

- 利: 自分の共有対象パッシブの半分を、他の味方それぞれに与える。
- 害: 自分に働く共有対象パッシブも半分になる。
- 詳細: 回数・段数・ターンは半減後に切り捨て。倍率そのものや規則を変える効果は共有しない。受け手の通常の上限を超えない。

共有元と対象範囲を確定した後、札にも範囲を明記する。

## 確定した共有量の規則

| 分類 | 共有量 | 例 |
|---|---|---|
| 割合・確率・加算係数 | 元の値の半分 | 付与率40% → 20% |
| 回数・段数・ターン | 半減後に切り捨て。整数部分が1以上なら共有 | 1回 → 0、2回 → 1、3回 → 1 |
| 倍率 | 共有しない | 累撃、基準値1の乗算値 |
| 有無・規則変更 | 共有しない | 全体化、確定会心、皇帝の命令 |
| 種類別の表 | 各要素の実単位で上記を適用 | 異常別の確率は半分、異常別の短縮ターンは切捨て |

分類は表示形式ではなく実際の用途による。登録のfmtがpctでも、連撃など実際は回数のものがある。
「倍率を共有しない」は一覧の独立した倍率分類を指す。火力+○%等の加算係数まで一律に除外する指示ではない。
一覧の件数や分類は作成時点のもの。実装時に新しい登録や用途変更がないか確認する。

## 初版の推奨範囲（未確定）

以下は実装担当への出発案であり、ユーザー確定事項と区別する。

- 共有元はSPで取得したツリー効果に限定する。クラス・キャラ固有・装備・アルカナ・他の女帝からの共有分は含めない。
- 初版は一覧の `passives` 出力を対象とし、`situational`・`build` の常時効果は対象に含めるか別途決める。
- 対象外の倍率・規則変更は、本人側でも半減しない案を推奨する。除外した効果へ機械的に0.5を掛けない。
- 対象となる離散量は、本人分も共有分と同じ切捨て値にする案を推奨する。例: 連撃3回なら本人1回、他の各味方1回。連撃1回なら本人0回、共有0回。
- 受け手は本人以外の通常の出撃メンバー。召喚体を含める拡張は別に検証する。

単騎時にも本人の半減が働く案。受け手がいないことを理由に効果を自動解除しない。
共有範囲や整数半減時の本人分は遊びに関わるため、実装前に採用内容を記録する。

## 算出順序

1. 共有元のツリー効果を、同じキー・同じ種類ごとに通常の合成規則で集計する。
2. 共有元に適用すべき既存の上限を確認したうえで、共有候補値を確定する。
3. 確定した分類に従って半減・切捨てし、共有用の値を作る。
4. 女帝本人の対象となる自前効果を、採用した半減規則へ置き換える。
5. 受け手へ共有分を合流し、その層の通常の上限を適用する。
6. クラス等の他の供給元を既存の設計に従って合流し、実行時の上限も維持する。

ノードごとに1回を半減して消さず、同じキーを集計してから半減する。
共有用の値は元の本人分から計算し、本人分を半減した後にさらに半減して1/4にしない。
受け手の最終値を再共有しない。
上限前後のどちらを共有元にするかは現行の各効果に照らし、上限超過分が共有だけで利益になる経路を作らない。

## 上限と合成の注意

現在の「上限」は単一の最終上限ではない。ツリー側の上限、他の供給元との合流、戦闘中の上限がある。
例えば一覧確認時点では、再行動率はツリー側に0.5の上限があり、クラス由来で超えることを意図したコメントがある。

- 女帝の共有でツリー層の上限を迂回しない。
- 共有の導入を理由に、既存クラスの正当な上乗せを削らない。
- 全項目を100%で丸めない。確率・火力係数・回復量・反射等は別の単位と上限を持つ。
- max型の効果は元から単純加算ではない。共有時も既存の合成規則を尊重する。
- バフ上限拡張など「上限そのものを動かす効果」は、通常上限を超えない要件との関係を個別に明文化する。
- 負の効果や代償を含む場合、女帝を通すことで代償だけ軽くなる可能性も検証する。無言で正の値だけ抽出しない。

## 複数女帝・死亡・更新（未確定）

初期提案は以下とする。

- 複数女帝の共有は、各供給元の元の育成から独立に算出し、通常の合成・上限を適用する。
- 受け取った共有分は本人の自前効果へ戻して再配布しない。女帝同士でも再帰的に増えない。
- 開幕に共有を組み立て、同じ戦闘内では持続させる方式を最小案とする。死亡による共有停止は別案として比較する。
- ウェーブを跨ぐたびに同じ共有量を加算しない。基準値からの再構成、または供給元別の寄与管理を行う。
- 戦闘外の育成・装備・所持キャラの保存値を書き換えず、戦闘用の効果として扱う。
- 死亡で停止する仕様を採る場合は、復活時の再付与、最大HP・能力変換・回数権利の増減まで扱う必要がある。単に最終値から引いて戻す実装にしない。

共有が死亡後も残るなら、女帝を早期に倒しても恩恵が残る運用を評価する。どちらが採用済みかを説明文に反映する。

## 実装担当への確認事項

1. CLAUDE.md、知見の索引、アルカナの作り方、一覧の元になった登録・tree・units・戦闘中の読取箇所を確認する。
2. 各キーに供給元、単位、合成、上限の適用位置、半減規則を対応付ける。
3. 表示形式と用途の不一致、未登録の算出キー、アルカナ専用のキーを洗い出す。
4. 一覧の分類だけで全キーを自動共有せず、対象を明示した規則表を用意する。将来の新効果を無審査で共有対象へ入れない。
5. 共有元を分離できる段階で算出する。最終unit.passivesからツリー由来の値を推測しない。
6. 対象外・半減で0になる効果をビルド画面に示し、取得しても配れない理由を読めるようにする。

実装上の主な対象は効果登録、treeの効果集計、unitsの供給元別合成、パーティ生成、ビルド／戦闘表示、検査。
新しい効果種を追加する場合は既存手順の登録一式を揃える。
実装担当は既存規則の成立確認と検証を行い、大きな仕様変更が必要な場合に根拠と代案を示す。

## 必須の検査

- 割合40%を20%として共有する。
- 回数1・2・3を、それぞれ0・1・1として共有し、小数を実行ループへ渡さない。
- 同じキーの1回+1回を集計してから半減し、共有1回になる。
- 累撃・atkScale・全体化・確定会心・命令等を共有しない。
- 種類別の表を要素単位で処理し、付与確率と短縮ターンを取り違えない。
- 女帝本人の減少と共有が同じ元の値から計算され、1/4にならない。
- 受け手の上限を守り、既存クラスの上乗せを不当に切り捨てない。
- 複数女帝・再構築・ウェーブ移行で共有が増殖しない。
- 戦闘終了後に所持キャラの育成値が変化せず、再出撃でも同じ値になる。
- 採用した死亡・復活・召喚への適用規則を検査する。

## バランス評価

共有量の分類規則は確定事項として維持し、実測では編成全体の投資と見返りを見る。
最新のbalance-tuningスキルと既存の測定道具を使用する。

比較する構成:

- 女帝なしで各人が必要なパッシブを取得した編成。
- 女帝へ投資を集約し、仲間が浮いたSPを別の枝へ回した編成。
- 女帝本人の回復・防御・攻撃が減る影響が出る編成。
- 共有先が既に上限に達している編成。
- 単騎、2人、4人、複数女帝。召喚を対象にする場合は別条件。

全員のSP・装備・レベル・編成枠を揃え、共有分を既存の最強編成へ上乗せするだけの比較で終えない。
勝敗、ラウンド、行動数、各人の実効効果、上限で無駄になった共有分、女帝自身の役割低下を記録する。
整数効果は偶数到達で共有量が増えるため、取得1段違いの境界も確認する。
他のアルカナを選べなくなる機会費用と、女帝に必要な投資を併せて評価する。
