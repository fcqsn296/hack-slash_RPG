# 運命の輪 X — 実装案

作成日: 2026-09-22
状態: 設計整理。実装・整合性検証・バランス実測は未実施。

## 設計意図

物理・魔術・遺物の攻撃技を順に使い、敵への弱体を重ねるアルカナ。
複数のアクティブ技を取得・装備するビルド構築に意味を持たせる。
指定外の攻撃も禁止せず、必要な技を代償付きで使える形にする。
オートは輪を考慮して技を選ばないが、効果・進行・代償は手動と同じ。

## 札の文面案

- 利: 物理・魔術・遺物の順に攻撃すると、防御崩壊・標的・氷結を与える。一周すると味方全員の次の攻撃の上限が上がる。
- 害: 輪に反した攻撃1回につき、敵が動く直前の現在HPが半分になる。
- 詳細: 途中のウェーブ制圧時にも違反を精算する。最終ウェーブの勝利時は精算しない。

各デバフの効果量・持続・付与率、一周報酬の強さは未確定。最終採用値は札の説明にも明記する。

## 合意した基本動作

### 輪の順序

物理 → 魔術 → 遺物 → 物理、の順で巡る。
本人が指定された技種別の攻撃を実行すると1段階進む。装備に積む系統タグ倍率と、技の種別を混同しない。

| 指定に従った攻撃 | 攻撃後の恩恵 |
|---|---|
| 物理 | 攻撃対象に防御崩壊を付与 |
| 魔術 | 攻撃対象に標的を付与 |
| 遺物 | 攻撃対象に氷結を付与 |
| 遺物で一周完了 | 味方全員に、次の攻撃1行動のダメージ上限を引き上げる祝福 |

- 通常の攻撃解決後に恩恵を付与する。その攻撃へ遡って適用しない。
- 多段・同じ技の多重発動でも、1行動で進むのは1段階。恩恵の追加付与も行動単位とする。
- 再行動で次の攻撃を使えば、改めて種別を判定する。
- 回復・補助のみの技は違反にも進行にも含めず、輪の恩恵も受けない。
- 輪はウェーブ間で維持する。ラウンドやウェーブごとに物理へ戻さない。
- 新しい戦闘では物理から開始する案とする。開始位置を選ぶ機能は初版に含めない。

### 違反

- 指定外の攻撃技も使用できる。使用禁止や待機を新設しない。
- 指定外の攻撃1行動につき違反を1回記録する。
- 違反時は輪を進めず、同じ種別を要求し続ける。
- 多段は違反1回。再行動で再度違反すれば追加で1回。
- 途中で正しい種別を使っても、既に記録した違反は帳消しにならない。

## HP減少の精算

未精算の違反回数をn、精算時点の現在HPをHとする。

    精算後HP = H × (0.5 ^ n)

例: 精算直前HPが8,000なら、1回違反で4,000、2回で2,000。
最大HPの半分を引く処理ではない。攻撃中の吸収や回復を済ませた後の現在HPを基準にする。

精算箇所:

1. 通常の敵フェーズへ進む直前。
2. 最終ではないウェーブを制圧した際、次ウェーブへの回復等より前。
3. 最終ウェーブを勝利で終了するときは精算しない。

精算した違反回数は0に戻す。同じ進行で敵フェーズ前とウェーブ移行の両方から二重精算しない。
敵1体の複数行動や、正義による応撃のたびに精算する仕様ではない。通常の敵フェーズと割込み行動を区別する。

HP減少は通常の被ダメージではない。

- 防御・軽減・障壁で防がない。
- 反射・棘・被弾を起点とした反応を発火させない。
- 死亡者を復活させない。
- 端数とHP1での扱いは未確定。初版は生存者に対して切り上げ・最低1を推奨するが、背水や致死防止との相性を検証して決める。

最終勝利で違反が残っていてもゲーム上のHP減少を発生させない。測定では未精算違反を別に記録し、勝利時の残HPだけで代償の重さを評価しない。

## 三種の恩恵

### 物理: 防御崩壊

相手の防御力を0として扱うデバフ。軽減・障壁・無敵まで無効にする効果とは分ける。
既存に同じ効果があるか確認し、無ければ新効果として登録・適用・表示・検査を揃える。
防御崩壊という名称だけで、既存の防御無視確率や防御低下と同じ処理にしない。

### 魔術: 標的

攻撃対象の被ダメージを増やす標的を付与する。
既存の標的処理を確認し、効果量・持続・重複時の置換規則を合わせる。
別の標的を弱い値で上書きする、複数回の適用で意図せず乗算する挙動を避ける。

### 遺物: 氷結

ダメージ増加につながる既存の氷結を付与する。
実装での発火条件・効果量・持続・解除条件・ボスへの適用を確認する。
会話上の期待だけで、既存の氷結とは異なる効果を追加しない。

三種とも、本人の攻撃だけでなく後続の味方の攻撃へつなげることを意図する。
付与率や耐性の扱いは未確定。輪への一致と実際のデバフ成立を区別する。

## 一周報酬: 次の攻撃の上限を引き上げる祝福

- 一周を完成させた遺物攻撃の解決後、味方全員へ付与する。
- 完成させた攻撃には遡って適用しない。
- 回復・補助では消費せず、次の攻撃1行動の全段に適用する。
- 再行動で使う次の技までは持ち越さない。
- 同じ戦闘内なら次ウェーブへ持ち越せる。戦闘終了時は破棄する。
- 未使用中に再び一周しても加算せず、祝福を更新する。
- 本人も対象に含める。死亡中の味方は初版では対象外を推奨する。
- 複数の輪の持ち主が同じ味方へ付与しても同じ祝福枠とし、積み重ねない案を推奨する。
- 召喚体を「味方全員」に含めるかは、召喚の最新仕様と照合して確定する。

上限に届いていない攻撃には利益が薄い点を認識する。威力強化を追加することは合意済みではない。
一周が稀という想定は未実測。再行動型が1ラウンドで何周できるかを確認して強さを決める。

## 判定境界と未確定事項

| 論点 | 初期提案・実装担当の確認事項 |
|---|---|
| 技種別の参照先 | 元の技定義と、変換後の実効種別のどちらを使うかを確認。初案は実効種別。UI表示も一致させる |
| 攻撃兼回復・補助 | 攻撃技として判定し、付随回復だけで違反を免除しない |
| 麻痺・行動不能 | 実行されなかった技は輪を進めず違反も加算しない案。既存のCT消費とは別に扱う |
| ミス・無効 | 攻撃を実行したら種別判定する案。デバフの付与成功は命中・耐性等の採用規則で別判定 |
| 全体・多対象攻撃 | 実際に攻撃した生存対象へ恩恵を付与する案。輪は敵数だけ進めない |
| 敵を倒した場合 | 輪の進行と一周報酬は成立。倒れた敵へのデバフは不要 |
| 反射・棘・自動反撃 | 初版は輪判定の対象外。本人が選ぶ技行動と区別する |
| 皇帝・教皇からの行動 | 本人が攻撃技を実行したなら種別判定する案。借りた技と本人の変換の関係を確認 |
| 月・節制等の一時補正 | 同時所持を仮定しない。味方からの効果や将来の共有経路で上限補正を二重適用しない |
| 共有HP | 違反者のHP減少をどの共有プールへ適用するか、恋人・悪魔の最新仕様を確認。共有相手へ二重転送しない |
| 祝福の不発時消費 | 合法な攻撃を確定した段階で消費する案。麻痺・対象消滅・全弾ミスでの扱いを明示 |

## オートと表示

手動・オートで効果判定は完全に共通にする。
オートは輪の現在位置、次の恩恵、違反数を理由に技の優先順位を変更しない。
通常のオート判断の結果、正しい種別なら恩恵を受け、違えば違反を記録する。
手動とオートの切り替えで位置・違反・祝福をリセットしない。

UIは次の指定種別、次の恩恵、一周までの位置、未精算の違反回数、祝福の有無を表示する。
指定外の技を押せなくせず、違反になることを示す。
HP減少ログには違反回数と精算前後HPを記録し、通常の敵ダメージと区別する。

## 実装担当への手順

1. CLAUDE.md、知見の索引、アルカナの作り方、技種別変換、デバフ、上限、敵フェーズ・ウェーブ移行を確認する。
2. 防御崩壊・標的・氷結の既存処理と、各未確定項目の推奨仕様を整理する。
3. 輪の状態・違反記録・精算を実装し、先に境界の検査を通す。
4. 三種の恩恵と一周報酬を、通常の攻撃後処理へ接続する。
5. UI・測定を接続し、オートの選択ロジックを変えずに共通判定を適用する。
6. 実ビルドで測定し、効果量・持続・祝福の上限補正を確定する。
7. 効果登録一式、解放依頼、単色SVG、札の説明、実測ログを揃える。

進行中の他の変更は上書きしない。既存規則の成立確認と検証は実装担当が行う。
大きな仕様変更が必要なら根拠と代案を示す。通常の内部設計は担当が進める。

## 必須の検査

- 物理→魔術→遺物の攻撃3行動でちょうど一周する。
- 多段や全体攻撃で輪・違反が複数回数えられない。
- 指定外でも技は使え、輪は進まず違反が蓄積する。
- 回復・補助では位置と違反が変わらない。
- 8,000HPで違反1回→4,000、2回→2,000になる。
- 吸収回復後のHPで精算し、軽減・障壁・反射が介入しない。
- 敵フェーズ前と途中ウェーブ制圧時に1回だけ精算し、最終勝利では精算しない。
- 輪はウェーブを跨ぎ、精算済み違反は残らない。
- 三種の恩恵と一周報酬が、その攻撃自身へ遡って効かない。
- 祝福は全段に効き、次の別行動へ漏れず、重複加算されない。
- 手動／オート切替で状態が変わらず、オートの技選択は輪なしの場合と同じ条件で一致する。
- 先制・割込み攻撃・共有HP・死亡時に二重精算や処理停止がない。

## 実測と採否

既存の測定道具と実ビルドを用い、同じ装備・SP・編成で札なし／他の札／運命の輪を置き換える。
三種を揃えるために失ったSPや、最大火力技を使わない損も含める。

比較対象:

- 三種を順に使う手動方針と、輪を見ない通常オート。
- 同じ技を連打して違反する構成と、輪を回せる構成。
- 再行動なし／あり、短期周回／長期戦、単体敵／複数敵。
- 攻撃後に全快する構成、背水・致死防止でHP減少を利用する構成。

記録する値: 勝敗、通算ラウンド、敵行動数、種別別行動数、遵守・違反・精算回数、一周回数、デバフ成立と維持、一周報酬の利用回数、HP減少直後の生存状況。
最終勝利時の残HPだけで安全と結論しない。オートで不利でも、それだけを不具合とはしない。
一周回数や実際に伸びたダメージを測ってから値を調整し、複数の効果量を同時に変更しない。

## 見送った案

- 技種別を厳格に禁止する方式: クールダウンや技不足で行動不能になる。
- 攻撃・バフ・回復の強制循環: 状況上不要な回復やバフを要求しやすい。
- 遺物で麻痺付与: 三種をダメージに関連する恩恵へ揃えるため氷結へ変更。
- 一周で攻撃技のCT解除: 対象が少なく、クラス技は解禁ラウンドで使えない場面が多い。
- 最終勝利時のHP精算: 終了時HPにゲーム上の用途がなく不要。
- 手動限定の効果、輪専用のオート判断: 共通の効果判定と通常のオート選択を維持する。
