# 強いビルドの組み方

遊ぶ人と、テストする人のための手引き。
「何がどう強いのか」と、**その理由**を書いてある。実装の説明はしない。

数字はすべて実際に戦闘エンジンを回して測ったもの。測り方は §9 に書いた。
測っていないことは「未確認」と明記してある。**推測を数字のように書かない。**

- 序盤だけ知りたい人 → **§2 だけ読めば足りる**
- 終盤の伸ばし方 → §3〜§6
- 「強そうなのに効かない」に心当たりがある人 → §8

## 1. 先に覚える3つの規則

この3つを知っているかどうかで、同じSPから出る火力が3倍変わる。

### 規則1 — 違う系統タグは掛け算になる

攻撃力を上げる補正は [物理] [魔術] [遺物] のどれかに属している。
**同じタグの中は足し算、違うタグ同士は掛け算。**

```
系統タグ倍率 = (1 + 物理の合計) × (1 + 魔術の合計) × (1 + 遺物の合計)
```

だから「同じ量を1つに寄せる」より「3つに散らす」ほうが必ず強い。実測（Lv20・SP同額）:

| 振り方 | 消費SP | 系統タグ倍率 |
|---|---:|---:|
| [物理]だけに寄せる（物理の基礎4＋練達5） | 14 | ×1.60 |
| 3つに散らす（基礎を3種とも4） | **12** | **×1.73** |
| 散らして余りを練達へ | 14 | **×1.84** |

**2SP少ないのに勝っている。** これがこのゲームの核。

### 規則2 — ダメージ上限は「1発ごと」にかかる

```
上限 = 500,000 × (1 + 上限突破率)
超えたぶんは 0.1倍まで減衰
```

上限は**1ヒットごと**に判定される。だから
**技のヒット数を増やすと、上限そのものが増える。**

同じキャラ・同じバフ・確定会心・乱数固定で測った（Lv255・基準敵Lv255）:

| 技 | 威力 | ヒット | 1発 | 素の値 | 1手番の合計 |
|---|---:|---:|---:|---:|---:|
| 覇王斬 | 180 | 1 | 584,261 | 1,342,610 | 584,261 |
| 斬撃 | 100 | 1 | 524,589 | 745,895 | 524,589 |
| 双連撃 | 70 | 2 | 502,212 | 522,126 | 1,004,424 |
| **朧四連** | 55 | **4** | 410,241 | 410,242（上限に届かない） | **1,640,964** |

威力180の1発より、**威力55を4回のほうが2.8倍出る。**
技の威力の合計は 180 対 220 でしかないのに、結果が2.8倍になるのは
上限が4回に分けて働くから。

### 規則3 — 上限の下では投資が丸ごと効き、上限の上では1割しか効かない

同じ構成に固有バフ（別枠乗算）を重ねていったときの実測:

| 状態 | 素の値 | 実ダメージ | 素の値に対して |
|---|---:|---:|---:|
| バフなし | 397,810 | 397,810 | 100% |
| 固有バフ +50% ×1 | 596,716 | 509,671 | 85% |
| 固有バフ +50% ×3 | 1,342,610 | 584,261 | **44%** |

素の値を3.4倍にしたのに、画面に出る数字は1.47倍にしかならない。
**上限に張り付いた瞬間、それ以降の投資は1割の値打ちになる。**

逆に言えば、上限突破は「上限が削っていたぶん」をそのまま取り戻す:

| 上限突破率 | 実ダメージ | |
|---:|---:|---|
| 0 | 584,261 | |
| +96%（限界超越12段・24SP） | 1,016,261 | **+74%** |
| +302%（ツリー＋破壊者/極撃 総取り） | 1,342,610 | 素の値に到達 |

## 2. 序盤（Lv5〜20）

**ここが一番大事。** 選べる技も振れるSPも少ないので、
「何を選ぶか」より「何を先に触るか」で差が付く。

### 2.1 レベルで勝手に開くもの

装備枠はスキルツリーではなく**レベル**で増える。SPを払う必要はない。

| Lv | 開くもの | 実測での効き |
|---:|---|---|
| **5** | アクセサリー枠が 1 → **2** | 品揃えが薄いうちは差が出にくい（下の表） |
| 6 | 中級ティア（初級に5レベル振れば） | |
| **10** | 防具枠が 1 → **2** | 火力 +17%（Lv20で計測） |
| 11 | 上級ティア（初級＋中級に10レベル振れば） | |
| 14 | 三系統掌握の1段目が買える（10SP＋3SP） | |
| **20** | 武器枠が 1 → **2**（＝二刀流） | 火力 +18%（Lv20で計測） |
| 30 | クラスに就ける | |
| 50 | 鍛冶（強化・厳選・再抽選） | |

**Lv20 は節目。** 武器2本目が入るところで火力が跳ねる。
テストで「詰まった」と感じたら、まず Lv20 に届いているかを見る。

### 2.2 まず装備。ツリーはその次

序盤は**装備の差がツリーの差より圧倒的に大きい。**
銅の宝箱16個から自動装備で組み、基準敵に覇王斬を800回撃った平均:

| | Lv5 | Lv10 | Lv20 |
|---|---:|---:|---:|
| 未装備 | 296 | 377 | 560 |
| 初期枠だけ使う（武1・防1・装1） | 540 | 657 | 945 |
| **開いている枠を全部使う** | **566** | **798** | **1,342** |
| 未装備からの倍率 | ×1.9 | ×2.1 | **×2.4** |

Lv20 で枠を1つ空けたときの損（同じ在庫から）:

| 空けた枠 | ダメージ | フルとの差 |
|---|---:|---:|
| フル（武2・防2・装2） | 1,342 | — |
| 武器を1本だけ | 1,138 | −15% |
| 防具を1つだけ | 1,149 | −14% |
| 装飾を1つだけ | 1,304 | −3% |

**防具でも火力が14%落ちる。** 防具は「硬さの装備」ではなく、
[物理][魔術][遺物] の副オプションが付く枠だから。
守りの装備だと思って外すと火力が落ちる。

> **テストする人へ** — 「弱い気がする」の報告を受けたら、
> まず装備が全枠埋まっているかを確認すること。実測で最大2.4倍動く。

### 2.3 SPの振り先 — 実測の順位

Lv10（9SP）と Lv20（19SP）で、同じ装備・同じ乱数・同じ手順でオート5連戦。
**勝ったときの平均ラウンド数**（少ないほど強い）。24戦の平均。

| 振り方 | Lv10 廃坑 | Lv20 浅層 | Lv20 竜の巣（推奨28・格上） |
|---|---:|---:|---:|
| 振らない | 7.05R (92%) | 4.08R | 勝率 **0%** |
| ATK/HP/DEF に振る | 5.57R (96%) | 3.25R | 9.60R (42%) |
| 会心に寄せる | 5.26R (96%) | 2.88R | 9.29R (29%) |
| [物理]に集中 | 5.26R (96%) | 2.50R | 7.20R (21%) |
| 属性の心得に寄せる | 5.18R (92%) | 2.00R | 7.10R (42%) |
| 三系統に分散 | 4.21R (100%) | 2.17R | 7.50R (58%) |
| 分散 → 三系統掌握 | 4.21R (100%) | 1.79R | 4.42R (50%) |
| **分散＋奇襲＋先手の気構え** | **3.75R (100%)** | **1.04R** | **3.94R (71%)** |

読み取れること。

**① 攻撃鍛錬（ATK+4%/段）は弱い。** ATKは足し算の項なので、
掛け算になるタグ補正に敵わない。同じSPで 3.25R 対 2.17R。

**② 会心は序盤では割に合わない。** 一点集中は 1SPで +3%。
19SP 全部注いでも会心率は3割に届かず、素の1.5倍が時々乗るだけ。
会心は**倍率と率を両方揃えてから**効く軸で、序盤にはその予算がない。

**③ 三系統掌握（上級・3SP/段）が序盤で一番効率がいい。**
1段で全タグ +6% ＝ ×1.19。3SPあたり +19% は、
物理の基礎（1SP で +5%）の1.3倍の効率。Lv14 から買える。

**④ 一番強いのは「1ラウンド目を厚くする」振り方。**
序盤の戦闘は1〜4ラウンドで終わる。だから
**1ラウンド目だけの効果が、実質いつでも効く効果になる。**

| ノード | ティア | SP | 効果 |
|---|---|---:|---|
| 奇襲 | 初級 | 1×4 | 1ラウンド目の与ダメージ +10%/段（計 +40%） |
| 先手の気構え | 初級 | 1×3 | 戦闘開始時に固有バフ +12%/段（計 +36%・別枠乗算） |

**合わせて7SP、初級だけで届く。** 1ラウンド目に ×1.40 × ×1.36 ＝ **×1.90**。
三系統掌握を全部（9SP）取っても ×1.64 なので、序盤ではこちらが上。

⑤ ただし**戦闘が長引く相手にはこの手が崩れる。** 上の表の「竜の巣」は
推奨Lv28 のフィールドに Lv20 で挑んだ格上戦で、そこでも 71% と最良だったが、
これは**それでも3.94ラウンドで終わっているから**。
10ラウンド級の戦いになる帯（闘技場・高難度）では、
1ラウンド目だけの効果は割合として薄まる。乗り換える前提で取ること。

### 2.4 序盤の振り方（そのまま真似してよい順番）

```
Lv 1〜 5   物理の基礎 → 魔術の基礎 → 遺物の基礎（1SPずつ、3種を平行に）
Lv 6〜10   奇襲4段 ＋ 先手の気構え3段
Lv11〜14   初級を10レベルまで埋めて上級を開け、三系統掌握へ
Lv15〜20   三系統掌握を3段まで。余ったら基礎の残りと体力増強
```

**やらなくていいこと。**

- **限界超越（上限突破）** — 上級・24SP。Lv20 の与ダメージは2,000前後で、
  上限の500,000には**250倍足りない**。1ダメージも増えない
- **属性の極意** — 有利を取れているときしか乗らない。
  相手の属性が固定でない序盤では腐る時間が長い
- **属性の心得を複数の属性に散らす** — 1キャラが使う攻撃属性は普通1つ。
  4属性に散らすと3つが死ぬ（§8.9 の実測）
- **装備セット** — 銅の宝箱からは**セット装備が0%で出ない**。
  銀（10%）から。Lv25 くらいまでは考えなくてよい

### 2.5 物語モードの序盤

物語は Lv5〜6 で第三章の締めに着く設計になっている。
道中の宝箱に**固定の装備が3点**入っていて、これがそのまま火力になる。

| 拾える場所 | 装備 | 枠 | 中身 |
|---|---|---|---|
| 継承の座 | 灰銀の爪 | 武器 | ATK/魔力 168、[遺物] +26%、会心 +5% |
| 継承の座 | 焼けた索引 | 装飾 | HP640・DEF96、[遺物] +22%、軽減 6% |
| 封絶の浅層 | 写しの護符 | 装飾 | 魔力62・HP210、[遺物] +14% |

主人公（覇王斬）で、第三章の締めの相手と同じレベル帯（敵Lv10）に対する実測:

| | Lv6 | Lv10 |
|---|---:|---:|
| 未装備 | 308（HP 1,210） | 382（HP 1,458） |
| 灰銀の爪だけ | 776 | 878 |
| ＋焼けた索引 | 912（HP 1,850） | 1,032（HP 2,098） |
| **3点フル** | **1,056（HP 2,060）** | **1,159（HP 2,308）** |
| さらに三系統分散 9SP | — | **1,721** |

**未装備と3点フルで3.4倍。** 章の締めで詰まったという報告が来たら、
まず宝箱を拾い残していないか、拾って装備し忘れていないかを見ること。

3点とも [遺物] で揃えてあるのは偶然ではない。
序盤に手に入るのは [物理] か [魔術] の装備が中心なので、
**掛け算になる3本目のタグ**をここで配っている。

主人公固有の性質も序盤に効く。

- **等価変換** — ATKと魔力の高いほうに低いほうが揃う。
  灰銀の爪がATKと魔力を同値で持っているのはこのため。物理でも魔術でも無駄にならない
- **レベルで伸びる火力** — レベル×0.5%。Lv10 で +5%、Lv255 で +127%。
  凸ができない代わりの分

### 2.6 属性は「誰に殴らせるか」で使う

序盤に属性ノードを買う必要はない。**技を選ぶだけで1.5倍になる。**

| フィールド | 出る敵の属性 | 有利を取れる攻撃 |
|---|---|---|
| 始まりの草原（敵Lv3） | 水・風・火／ボス土 | 風で土、火で風、水で火、土で水 |
| 崩れた廃坑（敵Lv14） | 土・闇・風／**ボス闇** | **光**（主人公の覇王斬）で闇、風で土 |
| 封絶の浅層（敵Lv22） | 光・闇・土／ボス無 | 光で闇。ボスは無属性なので相性なし |

主人公の覇王斬は**光属性**なので、闇の敵に対しては何も振らずに1.5倍出る。
廃坑のボス（坑底の暴君・闇）は主人公に殴らせるのが正解。

主人公のキャラ属性は**無**なので、受けるほうは全部等倍。前に出しても事故らない。

弱点を突くと**弱点コンボ**が積む（1段 +8%、最大5段で ×1.40）。
デバフ中の相手でも積むので、破鎧撃や毒牙を挟むだけでも繋がる。

### 2.7 手動で戦うとゴールドと経験値が1.5倍

**その戦闘の全部の手番を手で選ぶ**と、ゴールドと経験値が +50%。
1回でもオートを混ぜると付かない。

序盤はレベルがそのまま強さなので、これが実質いちばん効く「ビルド」になる。

## 3. 系統タグの乗算をどこまで伸ばせるか

### 3.1 出どころ

| 出どころ | 上限 | 対価 |
|---|---|---|
| ツリー 物理/魔術/遺物の基礎（初級） | 各 +20% | 各 4SP |
| ツリー 物理/魔術/遺物の練達（中級） | 各 +40% | 各 10SP |
| ツリー 三系統掌握（上級） | 全部に +18% | 9SP |
| 装備の副オプション（汎用） | 1枠あたり +6.0%〜+18.0%（宝箱で拡大） | 枠 |
| 装備の副オプション（技種別限定） | 1枠あたり +14.0%〜+32.0%（同上） | 枠＋技を選ぶ |
| 戦闘中の共通バフ（鬨の声など） | +50%（同タグに加算） | 手番 |

**クラスには系統タグを上げるノードが1つも無い。**（実測・全6クラスを走査）
タグはツリーと装備だけの軸。

宝箱のグレードで副オプションが伸びる倍率（`softScale` = 1 + (等級-1)×0.10）:

| 宝箱 | 倍率 | タグ(汎用)の上振れ | タグ(限定)の上振れ | 上限突破の上振れ |
|---|---:|---:|---:|---:|
| 銅 | ×1.00 | +18.0% | +32.0% | +12.0% |
| 銀 | ×1.10 | +19.8% | +35.2% | +13.2% |
| 金 | ×1.30 | +23.4% | +41.6% | +15.6% |
| 竜 | ×1.65 | +29.7% | +52.8% | +19.8% |
| 星辰 | ×1.75 | — | — | — |

**平坦ステータス（ATKなど）は等級そのままで伸びるのに、タグ補正は緩やかにしか伸びない。**
銅→竜で ATK は7.5倍になるが、タグ補正は1.65倍にしかならない。
これは意図的で、「宝箱の等級だけで強さが決まる」のを避けるための設計。

### 3.2 実際どこまで伸びるか

Lv255・5凸・タグノード総取り（51SP）・竜の宝箱40個から自動装備（+9強化）。
シードを変えて5回測った:

| | 物理技 | 魔術技 | 遺物技 |
|---|---:|---:|---:|
| 系統タグ倍率 | ×20.4〜×24.2 | ×15.3〜×21.1 | ×11.8〜×18.0 |

ツリーだけだと ×5.64（各タグ +78%）。つまり **装備側が3.5〜4倍を上乗せしている。**
タグ倍率の主戦場は装備であって、ツリーはその土台。

### 3.3 装備でも「散らす」ほうが強い

自動装備は「そのキャラの一番強い技」に合わせて組むので、
結果としてタグが1つに偏る。上の5回の実測で、装備由来のタグ合計を
そのまま3つへ均等に割り直したらどうなるかを計算すると:

| 回 | 実際のタグ倍率 | 均等に割り直した場合 | 伸びしろ |
|---:|---:|---:|---:|
| 1 | ×24.16 | ×29.07 | +20.3% |
| 2 | ×20.43 | ×20.82 | +1.9% |
| 3 | ×21.78 | ×25.52 | +17.2% |
| 4 | ×23.37 | ×25.73 | +10.1% |
| 5 | ×21.26 | ×21.73 | +2.2% |

**平均で1割強。** 自動装備に任せきりだと、この1割を毎回捨てている。
手で組むなら「3つのタグがなるべく同じ高さになるように」選ぶこと。

### 3.4 「技種別限定」の副オプションは諸刃

`[物理]系統(物理技限定)` のような副オプションは、値が汎用の約1.8倍ある代わりに、
**その種別の技を撃ったときしか乗らない。**

上の測定に使った1体は、限定枠を 物理 +170%ぶん・魔術 +48%ぶん 引いていた。結果:

| 撃つ技の種別 | 系統タグ倍率 |
|---|---:|
| 物理技（覇王斬など） | ×21.63 |
| 魔術技 | ×14.33 |
| 遺物技 | ×11.79 |

**同じ装備で1.8倍の開きがある。** 限定枠を積むなら、
そのキャラが撃つ技を1種別に固定すること。
物理と魔術を持ち替えて戦うキャラには汎用のほうがよい。

## 4. ダメージ上限との付き合い方

### 4.1 上限に当たっていないなら、上限突破は0

**普通に育てた構成では、Lv255 でも上限に当たらない。**

`test/balance.html` の想定ビルド（初級→中級→上級を素直に進める）で
レベル帯ごとに測った与ダメージ:

| Lv | 与ダメージ（平均） | 上限に当たった割合 |
|---:|---:|---:|
| 20 | 2,197 | 0% |
| 50 | 26,701 | 0% |
| 110 | 122,395 | 0% |
| 150 | 168,109 | 0% |
| 255 | 291,012 | **0%** |

裏を取るために、タグを積み切った Lv255 の一撃で上限突破率だけを変えてみた:

| | 上限突破 0 | 上限突破 +96% |
|---|---:|---:|
| 覇王斬（バフなし・素の値 397,810） | 397,810 | **397,810** |
| 朧四連 1発（素の値 410,242） | 410,241 | **410,241** |

**1ダメージも変わらない。** 24SP が丸ごと無駄になる。

### 4.2 上限に当たり始める条件

素の一撃が 500,000 を超えたところから。実測では、
タグを積み切った Lv255 の覇王斬（素 397,810）に**固有バフを1つ乗せた**時点で当たり始めた。

つまり上限を意識するのは、次のどれかが揃ってからでいい。

- 固有バフ（別枠乗算）を複数重ねる
- 属性有利 ×1.5 と弱点コンボ ×1.40 が同時に乗る
- 会心と会心倍率を積み切っている
- 大技（威力200以上）を撃つ

### 4.3 上限突破はどこから取れるか

| 出どころ | 対象 | 量 | 対価 |
|---|---|---:|---:|
| ツリー 限界超越（上級） | 全部 | +96% | 24SP |
| クラス 破壊者 限界の先へ | 全部 | +96% | 16点 |
| クラス 破壊者/極撃 限界の彼方 | 全部 | +50% | 10点 |
| クラス 破壊者/極撃【極】一撃必倒 | 全部 | +60% | 6点（最大HP −50%） |
| ユニーク 破暁の一撃 | 全部 | +45% | 武器枠1 |
| 装備の副オプション | 全部 | 1枠 +4.0%〜+19.8% | 枠 |
| ツリー 極大（上級） | **大技のみ** | +300% | 20SP |
| ツリー 中庸を破る（上級） | **中技のみ** | +160% | 16SP |

技の帯は威力で決まる。**小技 = 100以下 / 中技 = 101〜199 / 大技 = 200以上。**
帯どうしは排他で、両取りはできない。

ツリーとクラスを取り切ると一般の上限突破は +302%（＝上限 2,010,000。装備ぶんは別）。
ただしそこへ行けるのは**破壊者/極撃だけ**で、
他のクラスでは +96%（ツリーぶん）＋装備ぶんが天井になる。
「上限を殴り抜く」を軸にするなら、クラス選びの時点で決まっている。

### 4.4 上限を無視する2つの抜け道

**① 終焉の一撃（破壊者/極撃）。** ダメージ上限の減衰を受けない唯一の技。
確定会心とセットになっているのは、**上限に届かないうちは上限無視に意味がないから**。
2つで1つの効果。

**② ヒット数を増やす。** §1 の規則2。上限は1ヒットごとなので、
多段技・双撃・小技の連射はそのまま上限の数を増やす。

> 作業ログ「大技の上限突破」の実測では、上限無視の一撃（威力800）が
> 11,144,451。ただし **4回発動する構成では 44,577,804** になっている。
> 上限無視は1発だけ特別という設計だったが、発動回数を止める仕組みは無い。

多段が強すぎる相手には、闘技場の千葬の守り手が
**1ラウンドに30ヒットまで無効化する**ギミックで名指しに対策している
（出典: 作業ログ「闘技場ハードの味付け」）。手数一本槍だとここで止まる。

## 6. 装備・ユニーク・セット

### 6.1 何を狙って集めるか

優先順位は、序盤から終盤まで通してこう。

```
1. 開いている枠を全部埋める            （§2.2 で最大2.4倍）
2. 3つの系統タグがなるべく同じ高さになるように選ぶ  （§3.3 で1割）
3. 上の宝箱に乗り換える                （竜でタグの上振れが1.65倍）
4. ビルドが決まってからユニーク・セット （§6.3 の対価を払える構成だけ）
```

### 6.2 宝箱の性格

| 宝箱 | 性格 | LEGEND率 | セット出現 |
|---|---|---:|---:|
| 銅 | 序盤の埋め草 | 0% | **0%** |
| 銀 | 副オプション2〜3枠が安定 | 2% | 10% |
| 金 | 実用の下限 | 15% | 22% |
| 竜 | **数値を伸ばす箱**。タグ・会心・上限突破が乗る | 50% | 38% |
| 星辰 | **ビルドを変える箱**。中身は100%ユニーク | — | 0% |

レアリティは副オプションの枠数と主ステータス倍率を決める。

| レアリティ | 副オプション枠 | 主ステータス倍率 |
|---|---:|---:|
| COMMON | 1 | ×1.00 |
| RARE | 2 | ×1.25 |
| SUPER_RARE | 3 | ×1.60 |
| LEGEND | 4 | ×2.10 |

### 6.3 ユニークは「系統タグを捨てる」装備

ユニーク装備は**系統タグ倍率を一切持たない。**
着ければ、そこにあったはずの竜装備ぶんのタグと素ステータスが丸ごと消える。

Lv255・タグ総取り・竜+9 の構成で、枠を空けたときの実測:

| | 系統タグ倍率 | ATK |
|---|---:|---:|
| フル（竜6点） | ×21.63 | 3,643 |
| 装飾を1枠あける | ×20.15 (−7%) | 3,365 (−8%) |
| 装飾を2枠あける | ×17.12 (−21%) | 3,222 (−12%) |
| 武器を1枠あける | ×18.20 (−16%) | 3,108 (−15%) |

**装飾1枠をユニークに使う代償は、おおむね火力 −14%。**
だから「効果がこの代償を超えるユニーク」だけを着ける。

その基準で見て、明確に元が取れるものの例:

| ユニーク | 枠 | 効果 | なぜ元が取れるか |
|---|---|---|---|
| 双月の環 | 装飾 | 攻撃技が必ず2回発動 | ヒット数が倍＝上限も倍（§1 規則2） |
| 破暁の一撃 | 武器 | 上限突破 +45% / 大技 +30% | 上限に当たっている構成でだけ |
| 万手の刃 | 武器 | 小技 +50% / 小技が1回多く発動 | 同上、小技側 |
| 見透かしの眼 | 装飾 | 会心倍率 +0.5 / 会心時に防御35%無視 | 会心率を積み切ってから |
| 初手の理 | 武器 | 1R目 +150%（以降 −15%/R・下限40%） | 短期決戦。序盤〜周回向き |
| 疫の封 | 装飾 | 継続ダメージ +50% / 弱体の持続 +1 | 呪術師。割合ダメージはタグに乗らない |

逆に、**素の火力を伸ばすだけのユニークは存在しない。**
「効果を活かせない構成なら竜のほうが強い」というのが設計の意図で、実測もそうなっている。

### 6.4 セットは枠の予算で考える

セットは部位を問わず**同じセットの装備を何個着けているか**だけを数える。
枠は最大6（武2・防2・装2）。

- **2点セット** … 6枠のうち2。残り4枠は自由。序盤から狙える
- **4点セット** … 6枠のうち4。**残り2枠しかない。**
  竜装備4点ぶんのタグ倍率を捨てる計算になるので、
  4点効果が「戦い方を変える」ものでなければ割に合わない

10種あり、どれも数値の上積みではなく戦い方を変えるものになっている。

| セット | 2点 | 4点 |
|---|---|---|
| 衆目 | 狙われやすさ +90% | +180%／反撃 +25%／反撃が全体へ |
| 万軍 | 味方へのバフ +60% | +70%／バフの持続 +1／味方へは +1ターン |
| 孤影 | 自分へのバフ +80% | +170%／**味方へのバフが通らなくなる** |
| 聖痕 | 回復量の45%が敵1体へ | 85%が**敵全体**へ／瀕死への回復 +50% |
| 残響 | 与ダメージの25%を記録 | 45%になり2ラウンド後にまとめて撃ち込む |
| 憤怒 | 被弾の35%を怒りに | 70%になり、次の攻撃で全解放 |
| 千変 | 属性不利を受けない | 弱点コンボが外しても落ちず、上限 +3 |
| 刹那 | 1R目 +80% | 1R目 +180%／以降 −12%/R（下限50%） |
| 常世 | HP35%で復活（1戦1回） | 倒れている仲間1人につき火力 +40% |
| 共鳴 | 味方全員の火力 +12% | **自分の火力半減**／味方 +45% |

**孤影と共鳴と刹那は明確な代償付き。** 代償のほうを先に読むこと。

## 8. 落とし穴

一見強そうで、実は効かない投資。**全部、実測か作業ログで確認したもの。**

### 8.1 上限に当たっていないのに上限突破を積む

§4.1 の実測。想定ビルドは Lv255 でも上限到達率0%で、
上限突破 +96%（24SP）を足しても **1ダメージも増えない**。
上限突破は「上限が削っていたぶん」しか取り戻さない。

### 8.2 1つの系統タグに寄せる

§1 規則1。14SP を [物理] に集中して ×1.60、
12SP を3つに散らして ×1.73。**少ないSPで負ける。**

### 8.3 会心率が100%を超えたぶんは捨てられる

**「極点」（上級・3SP×3）を取っていないと、100%超えの会心率は完全に捨てられる。**
実測（Lv255・タグ総取り）:

| 会心率 | 極点 | ダメージ |
|---:|---|---:|
| 100% | なし | 397,810 |
| 150% | なし | **397,810**（同じ） |
| 150% | 3段 | 502,709（+26%） |

確定会心の技（終焉の一撃・首刈り）を持っていると、
装備の会心率もツリーの一点集中も**全部この状態になる**。
画面には「+7%」と出るのに、効果は0。

### 8.4 割合の効果に上限が当たっていて、投資が結果に出ない

作業ログ「棘の上限」「反射の上限」「状態異常の素の値〜」に3件ある。
どれも「上限が実質の値になっていて、いくら振っても数字が動かない」形だった。
現在は3つとも直っているが、**同じ壊れ方は新しい効果でも起きうる。**

見分け方: **投資量を2倍にして結果が1も動かなかったら、上限を疑う。**

### 8.5 軽減と棘・反射は正面から食い合う

棘も反射も「ダメージを受けたとき」に出る。
**被ダメージ軽減100%だと1発も出ない**（作業ログ「棘の上限」の実測）。
硬くすればするほど、返す火力が消えていく。最適点はおよそ50〜70%（同ログ・推定値）。

同じ理由で「庇う」も棘・反射を通さない。肩代わりは別経路で処理される。
**前に出る手段は狙われやすさだけ。**

### 8.6 枠の対価を払っていない比較

「支援パッシブを攻撃ビルドに足したら強くなった」は、
**その枠に元々あったものを外していない**ので過大評価になる。
比較するときはパーティの1枠・SPの同額・装備枠の同数を実際に差し替えること。
（`CLAUDE.md` §3 の注意そのもの）

### 8.7 つまみ食いは損になることがある

作業ログ「状態異常の素の値〜」の実測。
攻撃型に毒牙を1つ足すと 8R → **9R と遅くなった**。
撒くのに1手番使うぶん、攻撃を続けたほうが速い。
**軸は混ぜず、専業にするか触らないか。**

### 8.8 「技種別限定」の副オプションを、種別を混ぜるキャラに積む

§3.4 の実測。同じ装備で物理技 ×21.63、遺物技 ×11.79。
持ち替えて戦うキャラには汎用の副オプションを。

### 8.9 属性の心得・極意を複数属性に散らす

1キャラが使う攻撃属性はふつう1つ。同じ19SPで、Lv20・24戦の実測:

| 振り方 | 浅層Lv20 | 竜の巣（格上） |
|---|---:|---:|
| 光の心得5段＋三系統分散 | 2.00R | 7.10R (42%) |
| 光/火/土/水に散らす | 2.50R | 8.50R (**17%**) |

**散らすと3つが死ぬ。** 極意（有利時だけ乗る）も同じ理屈で、
相手の属性が固定でないうちは腐る時間のほうが長い。

### 8.10 周回でクラスを評価する

§5.2。通常フィールドは短く終わるので、
**クラス技は解禁ラウンドに届かないことがある。**
クラスの比較は闘技場か、長引く戦いで測ること。
