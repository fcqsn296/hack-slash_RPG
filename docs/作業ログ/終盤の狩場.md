# 終盤の狩場を2本足す

## まず訂正

提案のとき「Lv200から上の狩場が無い」と書いたが、**間違い**だった。
`fl_endless`（終わりなき回廊）は `scaling: { floor: 200, above: 15 }` で
パーティに追随するので、頭打ちではない。

実際の穴は**選択肢が1本しかない**こと。Lv1〜200 に9本あるのに、
200以降は同じ3種＋ボス1体を延々と回すことになっていた。

## 足したもの

| | 推奨Lv | 敵の数 | 追随 |
|---|---|---|---|
| **臨界の際** | 225 | 3〜4 | 床225・上乗せ **+0**（常に互角） |
| **還らぬ位相** | 250 | 1〜2 | 床250・上乗せ **+5**（やや格上） |
| 終わりなき回廊（既存） | 200 | 2〜3 | 床200・上乗せ +15（常に格上） |

**上乗せの幅で性格を分けた。** 常に互角なら安定して稼げ、
常に格上なら置いていけない。3本で階段になる。

敵6体は世界設定の「臨界点」から取った。伝導率が上がりきると
生物であることをやめる、という線。

- **臨界の際** … 越える寸前で足踏みしているもの（渡りかけ／名残の合唱／傾斜の猟犬／際の番）
- **還らぬ位相** … 越えてしまったもの（純度／名を失くした帝）

「帝」の字が残っているのは人だった証拠、という設定をボスに使った。

## 検証テストが規則を2つ教えてくれた

最初 `臨界の際` を**固定Lv225**で作ったところ、2つ落ちた。

1. **据え置きの狩場は初期上限(150)で相手にできること** (§6.5)
   上限は星霜の欠片でしか伸びないので、固定225は
   **欠片を持たない人が一生入れない場所**になる
2. **追随する狩場の床は、据え置きの狩場の最高より高いこと** (§10.8)

どちらも追随に変えることで解決した。上乗せ **+0** にしてあるので、
「常に互角」という当初の狙い（安定して稼げる）は保たれている。

## 数値合わせ

最初に置いた敵が強すぎ、**勝率 38% / 42%** だった（基準は推奨Lvで60%以上）。

原因は、1体あたりの能力を既存の最上位（原初の焔）より上げたうえに
数も増やしたこと。**1体あたりを原初の焔 Lv200 と同水準に揃え直し**、
難度の差は数だけで付けるようにした。

  渡りかけ Lv225   HP 139,200   ← 原初の焔 Lv200 は 140,380
  純度     Lv250   HP 279,000   ← 1〜2体しか出ないので倍にしてある

結果 **96% / 100%**。

## 立ち絵

**まだ無い。** `data/artprompts.js` に6体ぶんの指定を書いた。
獣（傾斜の猟犬）と純エーテル（純度・渡りかけ）には服を書かず、
