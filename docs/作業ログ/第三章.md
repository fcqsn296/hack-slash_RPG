# 第三章

**ブランチ**: `work/story-ch3`
**開始**: 2026-08-25

## 何を作るか

第二章はシキの加入で終わっている。シキは主人公を **「管理者」** と呼び、
「ここに何人納めたか」を覚えていると言う。第三章はその中身を明かす章。

**筋**:
1. シキが「継承の座にはもう一段下がある」と言う（納められた側だから知っている）
2. 下層へ降りる。ここは機械しかいない
3. 索引の亡霊が納めた者の名を唱えている。読めない項目が一つある——**管理者本人**
4. 二番機ドゥオが道を塞ぐ。倒す
5. その奥に**零式の遺構兵装アストラ**。初代管理機ウーヌスが「渡す相手」を待って抱えていたもの
6. ウーヌスはさらに下にいる。今は届かない。アストラが加わって章が終わる

## なぜこの筋か

### 既にある伏線を使い切る

| 既存のもの | どう繋がるか |
|---|---|
| `bs_first_warden` 初代管理機ウーヌスの desc<br>「渡す相手を待ち続け、待ちきれずに『渡す』の意味を書き換えた」 | **渡す相手＝管理者、渡すもの＝アストラ**。ここが章の芯 |
| `em_index_wraith` 索引の亡霊の desc<br>「誰を納めたかを、途切れ途切れに唱え続けている」 | 主人公が管理者だったと明かす口 |
| `fl_sealed` 封絶区画（推奨130） | **なぜ終盤にあの場所があるのか**を物語が説明する。第三章では下層の入口までしか行けない |
| シキ「ここに何人納めたか」を覚えている | 下層の存在を知っている理由 |

### アストラに入手経路が無かった

`ch_astra`（零式の遺構兵装、LEGEND、無属性）は
**ガチャにも他のどこにも載っていない孤立キャラ**だった。
第二章のシキと同じ「筋書加入」にすれば、経路が付いたうえに設定とも噛み合う。

### ウーヌスを倒させない理由

`bs_first_warden` は `fl_sealed`（敵150）のボス。ストーリーは Lv1 から始まる
別プロファイルなので、第三章の想定は Lv20〜30 前後。**同じ個体を二つの強さで出せない**。
下層の入口で引き返す形にすれば、終盤に `fl_sealed` へ行く動機がそのまま物語の続きになる。
