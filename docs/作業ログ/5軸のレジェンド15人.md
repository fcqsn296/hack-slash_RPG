ツリーには枝があるのに、担い手が1人もいない軸が5つ残っていた。
各3人ずつ、軸の中でも役が重ならないように配ってある。

## 静かに死ぬ間違いを3つ踏んだ

### 1. 鍵の名前が登録簿と違う

`revive` / `counter` と書いたが、実際に読まれる鍵は **`reviveHp` / `counterRate`**。
効果種別の名前と、消費側が読む鍵の名前は別物。

**キャラの passives はそのままユニットへ合流するので、値は載る。**
載るのに誰も読まない、という形で静かに死ぬ。
「宣言 → ユニット」を比べる自作の検査も、合流を見ているだけなので素通りした。

検証テストに **「固有能力の鍵が登録簿に実在する」** を足した。

### 2. フィリアの上限突破が実装当初から効いていなかった

1の検査を足した副産物。`capBreak` は**ツリー・装備・セットからは足しているのに、
キャラ定義からの経路だけ無かった**。

フィリアの説明文には「ダメージ上限を25%突破」と書いてあるのに、
ユニットの `capBreak` は 0 のままだった。**説明文だけが独り歩きしていた。**

`units.js` に橋渡しを足し（会心と同じ形）、
「固有の上限突破がユニットの素の値まで届く」を検査に足した。

### 3. ヒアドキュメントが長すぎて切れた

15体ぶんを `bash <<'PY'` で流そうとして、途中で切れた状態の Python が走った。
**大量のデータを足すときはスクリプトをファイルに書いてから実行する。**

## 結果

レジェンド 52人。5軸すべてに担い手がいる状態になった。
検証テスト 1295/1295。
