# 第四章「間に合わなかったもの」の実装

`docs/作業ログ/第四章の設計.md` の構成案どおりに入れた。

## 明かしたもの／取っておいたもの

| | 内容 |
|---|---|
| ○ | エーテルの流入が始まり、旧文明は**適応できないと分かっていた** |
| ○ | 自分たちを救う代わりに、**次を残すほうを選んだ**（＝継承機構） |
| ○ | 各地の地下に保管庫。**見込みのある個体を意識ごと記録**した |
| ○ | **悪役はいない。** 滅ぼしたものに意志は無かった |
| ✗ | 測っていたのは適応度ではなく**伝導率**だった |
| ✗ | 保管庫は傾斜を止める装置＝**育てることは滑落の再開** |

苦い真実を一度に出すと、崩壊の重さと機構の皮肉が食い合う。
第四章は「なぜ滅んだか」まで。「救おうとしたこと自体が間違っていた」は次の段。

第三章の書き換え（アストラ「機構が。……当時の基準で。」）が、
そのまま第四章の入口になっている。

## 舞台 — mp_sealed「封絶の座」

一番機は「順路の巡回を継続している」ので、**地図そのものを輪**にした。
外周・内周・中心の3層で、中心だけが行き止まりの部屋（索引）。
中心へは下側の一箇所からしか入れないので、回って探すことになる。
**「輪を歩く」という所作が、話の側と噛み合う。**

第三章の最奥（板）は (18,6) のまま残し、**降り口は (19,6) に別のマスとして開けた**。
同じマスに条件違いで2つ置くと `eventAt` が先頭しか返さず、
後ろに置いたほうへ永久に届かない。

## 借りる仕組みを3つに増やした

物語は周回用のフィールドを借りている。第三章で `enc.enemyLv` を足したが、
第四章では**それだけでは足りなかった**。

| 借りるもの | なぜ要るか |
|---|---|
| `enemyLv` | 章に合った敵レベル（第三章で追加） |
| **`enemyScale`** | 敵の能力は「素の値 ＋ 成長×(Lv-1)」で、**素の値が下がらない**。索引の亡霊は素で HP10,500・攻撃570。Lv16 まで下げても Lv9 のパーティは一撃で沈む（実測 勝率0%） |
| **`rewardScale`** | 払い出しも Lv130 帯のまま。1体3,600経験値なので、弱くしても**1戦で12,000入って章の刻みが吹き飛ぶ**（実測） |

**強さと払い出しは対で借りるもの。** フィールドを物語用に複製すると
敵とボスを二重に持つことになるので、借りる側で3つとも決められる形にした。

## 実測

パーティ4人（主人公・リゼル・シキ・アストラ）・**装備あり**・オート。

### 装備を持たせずに測って2度外した

`RPG.state.reset()` を通すと**持ち物が空になる**ので、その後に
`autoequip.forCharacter` を呼んでも何も着かない。「装備あり」のつもりで
装備なしを測っていた。

同じ ×0.15 の値が:

| | 勝率 | ラウンド |
|---|---:|---:|
| 装備なし（誤り） | 86% | 9.7 |
| **装備あり（正）** | **100%** | **2.8** |

**2.7倍ずれていた。** 第三章のドゥオでも同じ外し方をしている。
序盤は装備がツリーより効くので、素で測ると遊ぶ人の立ち位置から2段ずれる。

以後、宝箱を開けて鑑定し、自動装備してから測る。

### 道中（封絶区画を Lv16 ×0.10 で借りる・払い出し0.05）

勝率100% / 2.5ラウンド / 戦闘不能0人 / 1戦およそ580経験値。**4戦で1レベル。**

### 初代管理機ウーヌス（パーティLv11・金の宝箱22個+4・14回）

| 設定 | 勝率 | ラウンド | 倒れる人数 |
|---|---:|---:|---:|
| Lv18 ×0.34 | 100% | 6.9 | 0.3 |
| **Lv18 ×0.40** | **93%** | **9.7** | **1.1** |
| Lv18 ×0.46 | 57% | 13.9 | 2.2 |

採用値での通し（14回）は 勝率79% / 10.5ラウンド / 1.6人。

## ボスの経験値を跳ねさせた

**一度しか倒せない相手なので、報酬が跳ねてよい。** レベルが一気に上がる手応えは
RPG の締めとして正しい、という判断。

| | 払い出し | 必要経験値 | 上がるレベル |
|---|---:|---:|---:|
| ドゥオ（第三章・Lv6） | 2,871 exp / 2,376 G | Lv6→9 に 3,037 | **約3** |
| ウーヌス（第四章・Lv11） | 6,615 exp / 1,181 G | Lv11→14 に 6,616 | **ちょうど3** |

`rewardScale` で章の側だけを動かしている。**ボスの exp そのものは上げない。**
ドゥオは周回側の封絶の浅層（推奨20）のボスも兼ねていて、
素の値を触るとあちらの目盛りが動くため。

第三章を Lv9 前後で出て、第四章の道中で Lv11 まで上がり、
締めで Lv14 へ——という繋がりになる。
