# 敵の技と状態異常を増やす

## なぜ

テストプレイ（序盤・中盤・終盤・報酬・集計の5人）で、別々の担当が同じことを指摘した。

- 敵46体が使う技は **20種**。うち12種は素のダメージ技
- 状態異常は6種あるのに、**敵が撒くのは毒だけ**（影喰い・枯死の呪）
- ボス12体は誰も専用技を持たず、汎用技の組み合わせ

その裏で、味方側には弱体の持続短縮（`debuff_resist`）・種類別耐性（`status_resist_kind`）・
回復時の解除（`cleanse`）が揃っている。**毒しか来ないので、取る理由が無かった。**

## したこと

敵専用の技を **25種追加**し、氷結波を凍結付きに直した（敵の技は 20 → 45種、すべてどこかの敵が使う）。
25体の技構成を差し替えた。ボスは9体が専用の一手を持つ。

| 帯 | 主な中身 |
|---|---|
| 序盤（草原・廃坑） | 凍結・出血・火傷・麻痺・呪詛を弱く。喰王は「王の咆哮」で自分を猛らせ、暴君は落盤で全体を打つ |
| 中盤（巣・遺構・深淵） | 火傷・呪詛・麻痺が効き始める。灼獄竜は全体火傷、ゼロスは強い麻痺、アポカリュプスは全体に呪詛＋出血 |
| 終盤（灰燼・創世・臨界・位相） | 出血35〜40%・麻痺25%・呪詛55〜60%など、耐性を積む理由になる強さ。ネロは配下ごと強化、名を失くした帝は3種を同時に刻む |

強さはレベルで目減りしない（最大HP・被ダメージ・確率への割合）ので、帯で段を付けた。
味方側の上限 `STATUS_CAP` は敵が撒いた分にも効く。

### 触っていないもの

- **封絶の浅層・封絶区画の雑魚とボス** … 物語モードでも出る（`data/maps.js`）。物語の難度を動かさないため
- **終わりなき回廊の敵** … 「姿を借りる」仕組みと絡むため
- **還らぬ位相の「純度」** … 1体で出る敵。手応えの問題は別件（「終盤にオート用の張り合いが無い」）

## 測ったこと

フィールドごとに「推奨レベル・主人公＋LEGEND3人・そのフィールドで出る最上位の箱40個で自動装備」の
セーブを1回だけ作って固定し、5ウェーブを16回ずつ回した（`sim.node.js`）。

| | 修正前 | 修正後 |
|---|---|---|
| 草原〜遺構 | 全勝・最低HP 90〜100% | 同じ（序盤は撒く前に倒れる） |
| 深淵 | 15/16・最低HP 60% | 14/16・最低HP 37% |
| 灰燼 | 16/16・72% | 16/16・72%（出血・麻痺が乗る） |
| 創世 | 16/16・83% | 16/16・82%（火傷・麻痺・凍結・呪詛） |
| 臨界 | 16/16・92% | 16/16・91%（出血・呪詛） |

深淵は32回でも比べた: 修正前 27/32・最低HP 53% → 修正後 27/32・最低HP 34%。
**勝ち負けは動かさず、削られ方だけを変えた。**

物語の序盤相当（主人公1人 Lv6・銅箱装備）でも草原のボスを比べた。
修正前は200ラウンドで決着せず 0/48、修正後は 48/48（29R）。
喰王が「王の咆哮」に手番を使うぶん、殴る隙ができた。3人 Lv10 では差が無い。

### 踏んだ罠: 全体技の威力

最初、深淵が 15/16 → 10/16 に落ちた。異常の強さを削っても戻らなかった（8/16、ぶれの範囲）。
原因は**単体技を全体技に置き換えたこと**——人数ぶん総ダメージが増える。
全体技の威力を、置き換えた単体技の半分程度へ下げたら勝率が戻った。

## テスト

- 6種の状態異常がどれもフィールドの敵から撒かれる
- 敵の技は、敵側で動くと確かめたプラグインだけを使う（コンボ・印などは味方の資源が前提）
- 敵の単体技は狙った味方にだけ、全体技は全員に乗る。種類別耐性で弾ける
- 恋人の分配テストが「敵の先頭の技」に依存していたので、噛みつきに固定した
  （草原の敵の先頭が弱い魔術技になった途端、分配が0に丸まって素通りしていた）

## 気づいたが手を付けていないこと

- 主人公1人・低レベルだと、オートが回復を撃ち続けて決着しないことがある（修正前の草原ボスで 0/48）。
  テストプレイでも「29ラウンドかかった」と報告があった。オートの回復判断の問題で、別件
- 浅層・封絶区画のボス（ドゥオ・ウーヌス）と回廊のボスはまだ専用技が無い

## 追記: 乱数を止めて測り直した（2026-11-04）

上の測定は `sim.run` の seed が効いていない状態で行っていた（`ビルドの幅と奥深さ.md` の「罠」）。
seed を効かせて48回で測り直した結果:

| | 修正前 | 修正後 |
|---|---|---|
| 深淵 | 43/48・14R・最低HP 47% | 39/48・14R・40% |
| 廃坑・巣・遺構・灰燼・創世・臨界 | 全勝 | 全勝（最低HPの差は ±3 ポイント以内、創世は 77%→86%） |

深淵だけ少し厳しくなった（勝率 -8 ポイント）。他は変わらない。結論は保つ。

あわせて、敵が異常を撒くようになって**乱数次第で落ちるテスト**が1つ出ていた
（「自傷を糧: 耐性があっても自分の弱体は入る」——手番の後の敵の行動で弱体が1つ増える）。
敵の技を素の噛みつきに差し替えて、自分で受けた分だけを数えるようにした。
