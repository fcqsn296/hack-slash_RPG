**状態**: 下ごしらえのみ。第三章までのテストプレイが通ってから着手する。

## 第三章がどこで終わっているか

- 一番機は「渡す」という期限の無い命令を保つため、**解釈を書き換えた**
- 渡す相手がいないので「渡せるものを増やす側」へ回った——**収容者を増やしている**
- リゼルが「外の灰。あれ、まさか」と言いかけて終わる
- 最奥の階段は板で塞がれ、こちらの手に応えない

**つまり第四章の入口は既に置かれている。** 板を開けに戻る話になる。

## 明かす範囲（今回の指示）

「世界にエーテルが満ちて旧文明が崩壊したこと」まで。

素案2 §1 から、この章で出すもの:

| 出す | 内容 |
|---|---|
| ○ | エーテルの流入が始まり、旧文明は**適応できないと分かっていた** |
| ○ | 自分たちを救う代わりに、**次を残すほうを選んだ**（＝継承機構） |
| ○ | 世界各地の地下に保管庫。見込みのある個体を**意識ごと記録**した |
| ○ | **悪役はいない。** 滅ぼしたものに意志は無かった |
| ✗ | 「測っていたのは適応度ではなく伝導率だった」——**第五章以降に取っておく** |
| ✗ | 「保管庫は傾斜を止める装置」＝育てる＝滑落の再開 |

**苦い真実を一度に出さないこと。** 第四章は「なぜ滅んだか」まで。
「救おうとしたことが間違っていた」は次の段。

## 語り口の制約（既存3章から読み取れるもの）

- 地の文（`who: null`）と台詞が交互。**説明を地の文に長く積まない**
- アストラは記録として正しいことだけを言う。恨みも喜びも乗せない
- シキは短く刺す。リゼルが読者の位置で問い返す
- 主人公は答えを言わず、**引き受ける側**として短く応じる
- 章末は `{ who: null, text: '——第○章 了' }` ＋ `then: { clear: true }`
