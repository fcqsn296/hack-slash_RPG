# 支援のレジェンドを3人

## なぜ

ツリーには支援の枝が **29ノード・337SP** ぶんあるのに、**撒く側の効果を持つ
レジェンドが1人もいなかった**。

持っていたのは
- ミレーヌ `buffDuration`（自分が**受ける**バフの持続）
- アストラ `openingBuff`（開幕の自己バフ）

だけで、`buffPower` / `allyBuffPower` / `selfBuffPower` / `supportStack` /
`buffCapBonus` / `roundBuff` / `buffShield` / `buffHeal` / `buffExtend` は
**全部ゼロ**。【極】旗手まで用意した軸に顔がいなかった。

## 3人の分け方

同じ「支援」でも触り心地を変えてある。

| | 属性 | パッシブ | 役 |
|---|---|---|---|
| **リタニア**（絶えざる連禱） | 光 | `roundBuff: 0.10` / `buffExtend: 1` | 手番を使わずに効く |
| **ヴェスタ**（万雷の触れ役） | 風 | `buffPower: 0.35` / `buffCapBonus: 0.50` | 撃つと大きい |
| **ソルヴェイグ**（護りを編む者） | 水 | `allyBuffPower: 0.35` / `buffShield: 0.12` / `buffHeal: 0.10` | 撃つと固くなる |

- **リタニア** — 号令はラウンドの頭に勝手に配られ、**手番を使わない**。
  そのぶん「かける側の効果量」は乗らない決まり (§5.12) なので、
  置いておくだけで効く枠として成立させた。
- **ヴェスタ** — バフ効果量には天井がある（`BUFF_POWER_CAP = 1.0`）。
  `buffCapBonus` はその天井そのものを押し上げる**唯一の鍵**で、
  積み上げた `buffPower` を捨てずに済むのはこの人だけ。
- **ソルヴェイグ** — バフをかけるたびに障壁と回復がついてくる。
  支援と耐久の橋渡しで、回復役を1枠減らせる。

## 固有技は unique_buff / tag_buff に限る

**この2つだけが `buffAmount`（かける側の効果量）・`buffExtend`（かける側の持続）・
`afterBuff`（障壁と回復のおまけ）を通る。**
`def_buff` と `reduction_buff` はどれも通らないので、支援パッシブを持たせても
看板技に一切効かない（セレナの「風神の障壁」で確認済み）。

  リタニア   sk_lg_litany         絶えざる連禱   unique_buff 全体 +50% 4T
  ヴェスタ   sk_lg_thunder_herald 万雷の触れ     tag_buff [魔術] 全体 +70% 3T
  ソルヴェイグ sk_lg_ward_weave     護りの綴れ織り unique_buff 全体 +45% 3T

## 実測

同じ「万雷の触れ」を撃たせて比べた。

| 撃った人 | 味方が得たバフ |
|---|---|
| リタニア（`buffPower` 無し） | +70.0% |
| **ヴェスタ**（`buffPower` 0.35） | **+94.5%** |

ソルヴェイグの「護りの綴れ織り」（素の値 +45%）:

| | 味方 | 自分 |
|---|---|---|
| バフ | **+60.8%** | +45.0%（`allyBuffPower` は味方限定） |
| 障壁 | 1,440 | — |
| 回復 | 1,200 | — |

リタニアの号令は、戦闘開始と同時に**4人全員へ +10%（1T）**が入ることを確認。
また彼女が「護りの綴れ織り」（3T）を撃つと **4T** になる（`buffExtend: 1`）。

## 能力値

Lv255換算の総合力（HP/10 + ATK + DEF + 魔力）で、
リタニア 5,957 / ヴェスタ 6,019 / ソルヴェイグ 6,092。
レジェンド帯は 5,106〜7,859、中央値 6,348 なので、**純支援らしく中央値の少し下**。

## 立ち絵

**まだ無い。** `artPrompt` は3人ぶん書いてあり、`art` の色と髪型で
手続き生成の肖像が出る（実機で確認済み）。生成は指示があるまで走らせない。
生成したら `face` を `tools/detect_faces.py` で測り直すこと（いまは既定値）。

検証テスト 1220/1220。
