# 月 XVIII — 実装と測定

実装済み。検証テスト 1688/1688 合格（月22件）。
仕様は `docs/月の実装案.md`。**中核仕様・回数3・再現割合100%のまま採用した。**

## 実装したもの

> 利: 刻んだ幻傷を、仲間の攻撃で実体化する。敵1体につき1ラウンド最大3回
> 害: 自分の攻撃では敵のHPを減らせない。敵が行動すると、その敵の幻傷は消える

- 効果種 `moon`（値3＝敵1体・1ラウンドに開ける回数）。値が 0 より大きいことが
  「自分では削れない」旗も兼ねる
- **刻む**: `applyDamage` の中、闘技場の関門と吸収の後・HPを減らす前で止める。
  1行動のあいだ敵ごとに合算し、行動の終わりに1つの幻傷として置く（置き換え）。
  通らない攻撃（回避・衛士・吸収しきり）は刻まない。刻んだ一撃も関門の「1発」に数える
- **開く**: 月でない味方の行動で**実際に当てた敵**（反撃・連鎖は除く）を控え、
  行動の終わりに1回ずつ開く。多段でも1行動1回、再行動の別の攻撃ならもう1回。
  仲間自身の攻撃で倒れた敵には何も起きない
- 実体化は `applyDamage(..., { phantom: 値 })` を通す。計算し直さない（防御・上限を二重に掛けない）。
  闘技場の関門・障壁・凍結・1ラウンドの傷の上限は普段どおり効き、
  吸命・反射・残響・刻印・コンボ・撃破で誘発するパッシブ（戦場の糧・戦果・連鎖する死）は起きない。
  撃破そのもの（図鑑）は数える
- **消える**: 敵が `executeSkill` に入った時点（通常の手番・正義の応撃）。麻痺で飛んだ手番では残る
- 回数は幻傷とは別に敵が持つ（`phantomUsed` / `phantomRound`）。
  **ラウンドが変わったときだけ**戻る。刻み直し・別の月の上書き・消滅では戻らない
- 月だけの編成（削れる仲間が1人もいない）で攻撃すると、その場で打ち切る。
  放っておくと、敵が弱い場では倒しも倒されもせず永久に終わらない
- オートは「削れる量」に幻傷を足して数える（`min(自分の一撃＋幻傷, 残りHP)`）。新しい判断ではなく勘定
- 画面: 敵カードに「幻傷 N（残りk）」。消えても使った回数は「幻傷 使用k」で見える
- 皇帝に命令された月も刻み、命令された仲間は開く

## 測定

### 終盤セーブ（主人公が火力の大半）— 持ち主を選ぶ札だと分かった

| 持ち主 | HP×3000 | 相つき×1000 | 闘技場不死6R |
|---|---|---|---|
| 素 | 6.50R | 5.20R | 157B |
| 主人公・3回 | 6.40R | 6.00R | **36B** |
| 主人公・2回 | 6.80R | 6.05R | 22B |
| ルーメン・3回 | 6.10R | — | 163B |
| アストラ・3回 | 6.50R | — | 157B |

主人公は再行動が多く、**動くたびに自分の幻傷を上書きする**（小さい一撃で大きい幻傷を消すこともある）。
主人公の一撃は仲間の百倍あり、それを仲間の手番へ移すと火力の大半が消える。
ルーメン・アストラの一撃は小さく、幻傷はほとんど効かない。

### Lv255検証編成（4人の火力が揃っている）

周回（相なし）は 6.00R で差なし（床）。

**雑魚の群れでは損をする。** HP×30 の周回で、シャンタルを先頭にして 10.42R → 11.50R。
トレースすると、2.9M の幻傷が1回目で雑魚を倒し、残り2回は相手がいない。
月の一撃が「仲間の手番に遅れて届く」だけになっている。

**隊列の最後に置くと1回も開かない。** オーロラ（最後尾）に着けたら開いた回数0。
刻んだ直後に敵フェーズが来て消える。

**ボス1体（倒せなくして6ラウンドの総与ダメ、持ち主を先頭に）**:

| 持ち主 | 簒奪者 | 虹を喰らう獣 | 闘技場の主 |
|---|---|---|---|
| 素 | 53〜56M | 41〜45M | 40〜55M |
| シャンタル・3回 | **70M（+32%）** | 43M | **66M（+20%）** |
| アストラ・3回 | 66M（+18%） | 54M（+20%） | 測れず（素も2M。早く全滅） |
| 主人公・3回 | 57M（+6%） | 45M | 49M（+22%） |
| オーロラ・3回 | 50M（損） | 28M（損） | — |

同じ物差しでシャンタルに 力 60M／戦車 94M／正義 33M。**月は力と戦車のあいだ。**

**刹那の巨兵（1ラウンドの初撃しか見ない）とは噛み合わない。** 刻む一撃がその初撃を使ってしまい、
2.0R → 4.4〜5.0R。相性の悪い相手として残す（関門を迂回させない）。

### 回数2と3

差は小さい（シャンタル・簒奪者で 68M 対 70M、闘技場の主で 58M 対 66M）。
1ラウンドに開けた回数は平均1.4回で、3回に届く場面が少ない。仕様の初期値どおり3にした。
再現割合（100%）は動かしていない（仕様「回数だけで収まらない場合に初めて割合を調整」）。

### オートの勘定を足しても開く回数は増えなかった

幻傷を「削れる量」に足す前と後で、開いた回数はほぼ同じ（主人公・HP×30 で 8.3 → 7.8）。
開かない理由は狙いではなく、**雑魚が1回目で倒れること**と**隊列の順**だった。
勘定そのものは正しいので残してある。

## 解放依頼「月下の四手」

4人そろって・ボスだけの1ウェーブ・6ラウンド以内。臨界の際、敵Lv225固定、HP×160。

| HP | 終盤4人 | Lv200へ下げた検証編成 |
|---|---|---|
| ×80 | — | 12/12 |
| ×120 | — | 12/12・5R |
| **×160** | **12/12・1R** | **9/12**（落ちた3戦は時間切れ） |

敵Lvを固定しないと、臨界の際はパーティへ追随するので Lv255 のほうが硬い相手と戦うことになった。
Lv255の検証編成はボス1体に弱く（支援寄り）、上限の物差しにならなかったので終盤セーブで見た。

## 決めたこと（仕様の「推奨初期案」から）

| 論点 | 採用 |
|---|---|
| 多段で刻む | 1行動で敵ごとに合算して1つ |
| 全体攻撃 | 敵ごとに幻傷。仲間の全体攻撃は敵ごとに1回ずつ開く |
| 残HP | 保存値は切り詰めない |
| ミス | 回避・関門で通らなかった一撃は刻まない。仲間の全弾ミスでは開かない |
| 吸収 | 刻む時点で吸収後の値を保存。実体化では吸収しない（二重に喰わせない） |
| 実体化の順 | 仲間の攻撃を解いた後。その攻撃で倒れていれば何もしない |
| 月を持つ仲間 | 刻む側。開かない |
| 敵の行動不能 | 技の実行に入った時点で消える。麻痺で飛べば残る |
| 正義の応撃 | 敵の実際の攻撃なので消える |
| 持ち主の死亡 | 刻んだ幻傷は残る（作者の名前を保存） |
| 月の本人の反撃・棘・毒 | 普通に削る（直接の攻撃ではないため）。「本人では絶対に倒せない」とは書かない |
