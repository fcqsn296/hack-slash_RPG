## 1周目（3人）— 火・水・闇で選定

`ch_lg_ignis`（火）／`ch_lg_frisia`（水）／`ch_lg_nox`（闇）を選んだ。属性を散らす
という指示のとおり、既存の3属性で揃えた。

### 個別プロンプトを書く前に見たもの

`assets/characters/ch_lg_ignis.webp` / `ch_lg_frisia.webp` / `ch_lg_nox.webp`
を実際に開いて確認した。

- **イグニス（火・題は「血盟の焔剣」）** — 実物は炎剣ではなく、銀白髪でウサギ耳ふうの
  クリップを着けた整備兵ふうの意匠。巨大な灰色の砲を担ぎ、軍用コートに毛皮の襟。
  橙色は小物（ラメの靴紐・クリップの先）にしか無い。`data/characters.js` の
  `art.hairColor`（#ff6a3c、橙赤）とも実物の絵（銀白髪）は食い違っている。
  **ここで髪を橙に寄せると別人になる**（`ch_hero` のコメントにある「似姿の事故」と
  同じ罠）ので、意匠は実物の絵を踏襲し、火属性はテーマ色末尾と排気の描写だけに乗せた。
- **フリーシア（水・「氷結の女王」）** — 実物は氷結晶のドレス・浮かぶ泡と氷片で、
  題と属性に素直に合っている。意匠はほぼそのまま踏襲し、V5の「外へ伸びる」枠として
  霧と氷片を広げた。
- **ノクス（闇・「厄災の呪詛官」）** — 実物は金髪ベースで、`elementTags.dark`
  の紫黒とは食い違う（`art.hairColor` も #9068e0 紫だが実物は金髪）。イグニスと同じ
  理由で意匠（金髪・角状ヘッドピース・ハート型カットアウト）は保ち、闇属性は
  手先に漂う紫の呪符と背景のテーマ色にだけ乗せた。

### 書いた個別プロンプト

`data/artprompts.js` の `characters` に3件追加。書き方は「容姿の印象 → 髪 → 目 →
表情 → 服装 → 象徴する物 → 佇まい → テーマ色」の順、先頭に `1girl`/`1boy` は書いていない
（`rarityTags` が落ちるため）。V5 の「外へ伸びる」表現として、イグニスは排気とコート裾、
フリーシアは霧と氷片、ノクスは紫の靄と髪の流れをそれぞれ画面の外側まで伸ばす指定を
入れた。

`--dry-run` で3件とも警告なし（`1girl`/`1boy` を名乗っていないので `rarityTags`
が乗っていることを確認済み）。

### 生成

1人につき6枚、逐次生成（`novelai_gen.py` の待ち時間をそのまま使用。並列は投げていない）。
Anlas 残量は生成前後とも 10000（無料枠の範囲内）。

## 測る

### 測定方法

既存のスクリプトが見当たらなかったので、`_scratch/measure_legend_v5.py` を新規に書いた。

- **彩度・明度の中央値** … 不透明画素（alpha>=128）のみを対象に、
  `colorsys.rgb_to_hls` の S と L の中央値を取る。
  **HSV ではなく HSL であることに注意。** 最初 HSV で測ったところ既存46体の
  中央値が 彩度0.275 / 明度0.582 になり、`rarityTags.LEGEND` コメントの
  数字（彩度0.306 / 明度0.419）と合わなかった。HSL に変えたら
  彩度0.305 / 明度0.428 とほぼ一致したので、こちらが元の測り方だと判断した
  （`_scratch/legend_baseline.txt` に46体それぞれの値を残してある）。
- **囲まれた透明の割合** … 画像の縁から alpha<32 の画素を4方向フラッドフィルし、
  到達しなかった透明画素を「囲まれた透明」として、全透明画素に対する比率を出す。
  旧方式（外周からの塗りつぶし）はこの「囲まれた」場所に届かないので、
  比率が出ているということは V5 のアルファがそこを独自に正しく抜いている証拠になる。
  実際、**旧絵（ch_lg_frisia.webp / ch_lg_nox.webp）は囲まれた透明が0%**
  （抜けていた場所がそもそも透明扱いされていない＝白いまま残っていたことに一致）。

### 読み取れたこと

- **ノクスが基準に最も近い。** 彩度0.31〜0.38 / 明度0.40〜0.49 で、
  基準（彩度0.305 / 明度0.428）にどの候補もほぼ乗っている。
- **イグニスは彩度が基準より低い。** 現行(0.114)より底上げはできている
  （候補は0.12〜0.18）が、基準0.305にはまだ届かない。銀・灰・生成りの
  「gunmetal grey and cream white theme」で意匠を保った代償で、
  これは彩度より **「明るい色が占める面積」**（rarityTagsコメントの指摘）の
  問題に近い。橙のテーマ色をもう一段強めるか、意匠を保ったまま挑戦するか
  依頼側の判断を仰ぎたい。
- **フリーシアは明度が基準より高い。** 明度0.69〜0.79で、現行(0.751)と
  同程度。氷というモチーフ自体が白に寄るので、既存46体の中でも外れ値
  （現行時点で明度0.751）であり、**V5化による劣化ではなく元からの特性**とみられる。
- **囲まれた透明が実測できた。** 旧絵は0%だったのに対し、V5候補は
  0.1〜10.7%が「囲まれて」いながら正しく透明になっている。特に
  フリーシア候補5（10.72%）は裾の氷片と霧が画面内で輪を作り、
  その内側が正しく抜けている実例（`_scratch/legend_sheets/ch_lg_frisia.png` で目視確認済み）。

## うまくいかなかったこと

**ノクスの「呪符」表現が UI ラベルのような紫の光る文字看板になった。**
個別プロンプトの `glowing violet cursed glyphs drifting around her fingertips`
が原因で、**6枚中6枚全部**に、丸みを帯びた矩形の縁取りに疑似文字が並ぶ
「テキストラベル」のような発光オブジェクトが出た（読める英単語ではないが、
ゲームのUI吹き出しに見える）。`negative` に `text` は入っているが、
positive側で「glyphs」と名指しした結果、除外より個別の指定が勝った形。

**次に進めるなら、この語を外して作り直す。**
`glowing violet cursed glyphs` → 例えば `curling wisps of violet miasma`
のように、文字を連想させない語に変えて `ch_lg_nox --count 6` を撮り直すのが良い。
今回の6枚は候補としては採用しない前提で依頼側に見せる。

イグニス・フリーシアは技術的な破綻は見られなかった（申し送りは上の「彩度が低い」
「明度が高い」の2点のみ、いずれも意匠を保った結果の特性）。
