# 画像工程の汎用化

## なぜ

「他のプロジェクトからこのパイプラインのツールを利用することもできるような作りに
なっていますか？」に対する答えが **できていなかった** ため。

調べたところ、`tools/` の19本すべてが

```python
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
```

を持っていて、**必ず自分のリポジトリに対して働く**作りだった。
さらに `cutout_background.py` / `strip_png_metadata.py` / `to_webp.py` には
`add_argument` が1つも無く、対象は

```python
TARGETS = ['assets/characters', 'assets/enemies']
```

と直書き。`detect_faces.py` / `import_images.py` / `novelai_gen.py` は
`data/*.js` を読み書きする。つまり**灰銀専用**だった。

## どう分けたか

「処理」と「このリポジトリの事情」で切った。

| 残したもの（`tools/`） | 移したもの（`imagekit/`） |
|---|---|
| どのフォルダが対象か | 塗りつぶしで背景を辿る処理 |
| どこへ退避するか | PNG チャンクの読み書き |
| そのあと何をすべきか（案内文） | WebP への変換 |
| `--model` の名前・`--check` の文面 | トークン・UA・再試行・待ち時間の下限 |
| プロンプトの組み立て・候補の管理 | 契約の確認 |

置き場所は**このリポジトリの外**（`claude_build/imagekit/`）。

```
claude_build/
  hakusura-rpg/tools/locate.py   道案内。これだけがこちら側の持ち物
  imagekit/imagekit/             実装
  imagekit/README.md             罠の記録
  imagekit/selftest.py           合成画像だけで検査。通信も課金もしない
```

### 中に置かなかった理由

`hakusura-rpg/tools/imagekit/` に置いて他プロジェクトへ写す形も考えたが、
**写すと必ずずれる**。このリポジトリの原則そのままで、採らなかった。

代わりに兄弟ディレクトリへの依存を負う。**見つからないときは止まる。**
機能を落として続く作りにはしていない——メタデータ除去のような
「通っていないと困る工程」が素通りすると、生成プロンプトが埋まったまま公開される。
218枚で実際に起きかけたので、ここは「走らなかった」ではなく「止まった」でなければならない。

`locate.py` は環境変数 `IMAGEKIT_HOME` → 兄弟ディレクトリ → `site-packages` の順に探し、
見つからなければ探した場所と直し方3通りを並べて落ちる。

### 顔の切り出しは移していない

`detect_faces.py`（アルファのくびれを見て頭を切り出す）は、
`data/characters.js` への書き戻しと一体になっている。
切り離すにはアダプタが要るので、今回は手を付けていない。

## 同じ結果になることを確かめた

**移す前の実装を git から取り出して、新旧を実物の PNG で突き合わせた。**
原本は読むだけ、書き込みはスクラッチへ写したものだけ。

| 見たもの | 枚数 | 結果 |
|---|---|---|
| メタデータの読み取り | 8 | 辞書が一致（うち2枚は6項目を保持） |
| 除去後のバイト列 | 3 | **バイト単位で一致** |
| 透過（1段階） | 3 | 画素・割合・経過が一致（68.2% / 64.6% / 75.6%） |
| 透過（2段階・`--deep` 相当） | 1 | 一致 |
| WebP | 2 | **バイト単位で一致**（173,550 / 93,494） |

食い違い 0 件。

そのうえで、書き換えない経路だけを実際に流した。

```
tools/to_webp.py                 → 0 枚（すでに WebP 化済み）
tools/strip_png_metadata.py      → 対象 0 枚
tools/cutout_background.py       → 画像 0 枚
tools/recover_metadata.py        → 控え 98 件 → 98 件（md5 変わらず）
tools/prepare_release.py         → 6工程すべて確認のみで完走
tools/novelai_gen.py --list-prompts / --dry-run / --check
```

`--check` は契約の確認だけなので画像を作らない。実行前後で Anlas 10,000 のまま。
**生成は一度も走らせていない。**

`imagekit/selftest.py` は合成した PNG で 24 項目。通信しない。
検査用の PNG は Pillow を使わず手で組み立てている——
Pillow を通すとテキストチャンクが消えるので、それでは検査にならない。

## 効き方

`tools/` から **531 行が消えて 186 行になった**（差 −345 行）。
消えたのは重複していた処理で、同じものが3か所にあった箇所もある
（PNG チャンクの読み取りが `strip_png_metadata` / `recover_metadata` /
`publish_check` に別々に書かれていた。前2つを1つにした）。

待ち時間の下限・User-Agent・透過用の語は、こちら側では
`imagekit` の値を指すだけにした。**別に持たないこと。**

## 触った範囲

Python のツールだけ。`src/` `data/` `styles.css` `index.html` は1行も変えていない。
ゲーム本体の検証テストが見る範囲に届いていないので、公開前に流し直す以外の意味はない。
