# 女帝 III — 実装と測定

実装済み。検証テスト 1736/1736 合格（女帝11件）。
仕様は `docs/女帝の実装案.md`、棚卸しは `docs/女帝検討用パッシブ一覧.md`。

## 実装したもの

> 利: スキルツリーで得たパッシブの半分を、他の味方それぞれに与える（回数・ターンは半分を切り捨て）
> 害: 自分に働くそのパッシブも半分になる。倍率・有無・一度きりの効果は分けない

- 効果種 `empress`（旗、shape max）
- **共有元は SP で取ったツリーの効果だけ**（仕様の初版推奨）。クラス・固有・装備・アルカナは分けない。
  出どころを区別できるのは `buildCharacterUnit` の合流前だけなので、そこで扱う
- **対象は passives の規則表** `RPG.arcana.EMPRESS_SHARE`（明示した一覧。新しい効果は審査なしで入らない）
  - 割合・確率・加算係数（反撃・再行動・吸命・棘・DEF→ATK の変換など 82種）… 半分
  - 回数・段数・ターン（連撃・小技の繰り返し・持続・コンボ段など 14種）… 半分を切り捨て
  - 種類ごとの表（攻撃時の弱体・弱体中の敵への火力・弱体耐性）… 要素ごと
  - 入れていない: 倍率（累撃・atkScale・反撃の威力）、有無・規則変更（全体化など）、
    一度きり（不屈・復活・ウェーブ復活。半分を配ると復活そのものを配ることになる）、
    上限を動かす効果（バフ上限）、アルカナ固有・代償（手番の負債・自縛など）。
    これらは**自分も満額のまま**（除外した効果へ機械的に半分を掛けない）
  - situational・build（上限突破・系統タグなど）は初版では対象外
- 算出順: ツリーを集計（同じキーは合算）→ ツリーの上限 → 半分にした値を「自分の値」と「分ける値」の両方に
  （同じ元から作るので 1/4 にならない）
- 受け手: 共有分を**ツリーの層**に足し、ツリーの上限を掛け直してから、クラス・アルカナ・固有・装備と合流。
  ツリーの上限（再行動0.5 など）は越えず、クラスで越える分（戦術家）は削らない
- 配るのは `state.partyUnits`（出撃・依頼・塔・闘技場・派遣・物語の入口がすべて通る）。
  **保存された育成は書き換えない**。戦闘の開始時に組み立て、戦闘中は変えない（女帝が倒れても残る）
- **複数の女帝は、同じ効果を足さずに最大だけ**（`combineShares`、ユーザー判断）
- 単騎でも自分は半分になる（受け手がいないことを理由に解除しない）
- ビルド画面: 女帝を就けていると「分ける（各自へ／自分も同じ値）」「半分で0になり配れない」
  「分けない（自分には満額）」を並べる

## 測定（終盤セーブ、20試行）

| 女帝の持ち主 | 敵HP×3000 | 先制＋あまねく×1000 | 倒せないボス6Rの総与ダメ |
|---|---|---|---|
| 素 | 6.50R | 5.20R | 157B |
| 主人公（火力の要） | 11.05R | 11.80R | **19B** |
| アストラ | 5.60R | 5.00R | 249B |
| ルーメン | **5.45R** | **5.00R** | **257B** |
| ミレーヌ | 5.70R | 5.30R | 206B |

主人公に着けると、自分の DEF→ATK の変換（2.8）が半分になり ATK 28,310 → 15,914。
**補助役に着けて主人公へ配る札**になる。同じ物差しで主人公に 力 251B／吊るされた男 328B。
女帝は補助役の枠を使うので、主人公の札とは重ねられる。

### 強さの出どころは能力の変換

| | 女帝1人 | 2人 | 3人 |
|---|---|---|---|
| 仕様どおり（足し合わせ） | 257B | **459B** | 449B |
| **足さずに最大（採用）** | 257B | 335B | 331B |
| 変換（DEF↔ATK・HP→ATK/DEF）を分けない | 163B | 173B | 196B |

補助役はどれも DEF→ATK を 2.8 前後持っていて、その半分 +1.4 が主人公へ入る。
足し合わせると女帝2人で 2.8 積み上がり、札なしの2.9倍になる。
3案を示してユーザーが「足さずに最大」を選んだ。

## 解放依頼「行き渡る実り」

あまねく相（敵の攻撃が全員へ届く・攻撃力2倍）＋誰も欠けさせない。創世の残響、敵Lv160、HP×30。

## 残したこと

- 「女帝へ投資を集約し、仲間が浮いたSPを別の枝へ回した編成」の比較はしていない（振り直しの型を作る必要がある）
- 死亡で共有を止める案は採っていない（開幕に組み立てて戦闘中は変えない最小案）
- 召喚は未実装なので照合していない
- situational・build の常時効果（上限突破・系統タグなど）は対象外のまま
