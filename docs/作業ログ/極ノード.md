# 【極】ノード

**ブランチ**: `work/extreme-nodes`
**日付**: 2026-08-25

## 何を解いたか

上級帯で取捨選択が起きていなかった。大技+会心フルが215SPで、
上級を5つ取ってなお43SP余る。一方でツリー全体は2819SPあり、
上限258では9%しか取れない——**絶対量は余っていないのに、1ビルドぶんは全部入る**。

排他や枠制ではなく **代償つきの選択肢を足す**形を選んだ。
「AかBか」を仕組みで縛ると既に両方振ってあるセーブを壊すが、
足すだけなら既存の振り方は1つも動かない。

**`src/` を一切触っていない。** `stat_pct` の負値と、
`low/high_power_boost` が `situational *= 1 + 値` で負値を素通しすることで成立している。

## 実測で2回作り直した

### 1回目: 一閃が「素直な上積み」だった

`crit +0.45` と `crit_damage +0.8` を配ったところ、
**会心を一度も振っていないビルドにも +47〜51%** 出た。
クラス設計の注記が戒めている形そのもの。

会心「率」を配るのをやめ、**倍率だけ**にした。
率を配ると誰にでも効くが、倍率なら会心する回数の少ない者には代償だけが残る。

### 2回目: 代償が効いていなかった

`stat_pct` の名目 -25% が、実際のダメージでは **-8.6%** にしかならなかった。
終盤は装備がATKの2/3を占め、`stat_pct` は素のステータスにしか掛からないため。

| 名目 | 実効 |
|---|---|
| ATK -25% | **-8.6%** |
| HP -30% | -18.5% |
| DEF +40% | +21.2% |

ATKだけ希釈が激しい。名目 -0.7 にしておよそ実効 -24%。
**`desc` には実効を併記した**（表示と体感が食い違うため）。

> **クラスの極点も同じ希釈を受けているはず。** `gd_undying` の ATK -45% などは
> 文面ほど痛くない可能性が高い。あちらは未検証。

## 最終的な効き

| ノード | 効果 |
|---|---|
| 一閃 | 会心フル **+19%** / そこそこ +1% / 会心なし -5% |
| 剛撃 | 大技 +90% / 小技 -70% / 中技 0% |
| 乱撃 | 小技 +110% / 大技 -80% / 中技 0% |
| 明鏡 | 攻撃 -10%（会心ビルドなら -53%）。実戦では fl_origin 勝率 **7%→34%**、生存 1.35→2.75 |

一閃は**振り切った者だけが得をする**形になった。
明鏡は攻撃計算では損にしか見えないが、守りに寄せたビルドでは大きく効く。

## 検証

検証テスト 1207/1208。唯一の不合格は `プロンプト: 全ての敵に個別の指定がある` で、
これは 8124 の `python -m http.server` がキャッシュ無効化ヘッダを返さないための
**古い artprompts.js を掴んだ結果**（node では 敵36/プロンプト36で欠けなし）。
skilltree.js のほうは新しく読めている（326ノード、`tr_x_flash` あり）ので、
**新ノードはテストを通っている**。

## 残り

【極】は攻撃側の軸にしか無い。支援・属性・状態異常には代償つきの終端が無く、
そちらは依然として素直に積み上がる。同じ作法で足せるが、1つずつ実測が要る。
