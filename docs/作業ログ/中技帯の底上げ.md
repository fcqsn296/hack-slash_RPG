# 中技帯の底上げ（実測にもとづく再調整）

## きっかけ

「中技帯は多段特化や終焉の型と比べて本当に見劣りしないのか」と問われて実測した。
**見劣りしていた。**

同一装備・Lv255・同じ共通土台での1手あたり（調整前）:

| ビルド | SP | ATK×1 | 1SPあたり |
|---|---|---|---|
| 中技（刻み断ち 115×2） | 56 | 19,246 | **344** |
| 多段（焔の連舞 85×4） | 44 | 43,644 | 992 |
| 大技（世界断ち 620） | 75 | 93,738 | 1,250 |
| 終焉の一撃（800・上限無視） | 75 | 120,953 | 1,613 |

**中技は多段の1/3、大技の1/4。**

## 原因は4つあった

1. **技そのものの威力総量が全帯で最低** — 中技の最大 250（連環斬 125×2）／
   小技 340（焔の連舞 85×4）／大技 620〜800
2. **ツリーの火力が薄い** — 中技 +76%(20SP) / 小技 +170%(20SP) / 大技 +218%(45SP)
3. **【極】ノードが無い** — 小技に乱撃、大技に剛撃があるのに中技だけ空
4. **上限突破が半分** — 中技 +160% / 大技 +300%

このうち **2 と 3** を埋めた（1 は既存技を触ることになるので見送り）。

## 直したこと

| ノード | 前 | 後 |
|---|---|---|
| 中段の心得 (basic 2SP) | ×4 v0.07 = +28% | **×5 v0.10 = +50%** |
| 中段の極意 (mid 3SP) | ×4 v0.12 = +48% | **×4 v0.18 = +72%** |
| **中段の極み** (high 5SP×3) | — | **v0.28 = +84%**（大技の「覇道」に対応） |
| **【極】間合** (high 10SP×1) | — | **v1.30 = +130%** |

**火力合計 +76% → +336%。**

【極】間合は**両側を捨てる**。剛撃は小技だけ、乱撃は大技だけを捨てるが、
中段は上下どちらへも振れる位置にあるので、小技・大技の両方を −60% する。
そのぶん本体の伸びは3つの中でいちばん大きい。

## 調整後の実測

| | ATK×1 | ATK×20 | **ATK×100（終盤）** |
|---|---|---|---|
| 中技（連環斬 125×2） | 51,822 | 1,036,470 | **2,858,234** |
| 中技（刻み断ち 115×2） | 47,676 | 953,552 | **2,816,776** |
| 多段（焔の連舞 85×4） | 43,644 | 872,916 | 2,236,456 |
| 大技（世界断ち 620） | 93,738 | 1,874,775 | 2,737,387 |
| 終焉の一撃（800） | 120,953 | 2,419,065 | 12,095,328 |

**終盤の規模では中技が通常の大技を追い抜いた。** 上限に当たると
2ヒット × 上限突破が効くため。ノエルの説明文
「上限に潰されていた中技を、大技と同じ土俵まで押し上げる」が実際に成立した。

序盤〜中盤（上限に当たらない帯）では大技が上のまま。
1SPあたりでも 836 vs 1,704 で大技が上。**帯の性格は保たれている。**

終焉の一撃だけは `ignoreCap` なので別格のまま。これは意図どおり
（クラス技の演出として決着済み）。

## 残した差

技そのものの威力総量（中技250 / 大技800）は触っていない。
ここを動かすと既存の技の設計を全部見直すことになるため。
差は残るが、上限に当たる終盤では**多段の性質が効いて逆転する**ので、
帯として成立していると判断した。

なお中技は状態異常技の本拠地でもある（15本中9本）。
毒・火傷は最大HPの割合で天井50%/ラウンドなので、
闘技場の主（HP2億）には**1億/ラウンド** — 終焉の一撃の8倍が通る。
直接ダメージだけで比べると、この帯の価値を見誤る。

検証テスト 1237/1237。
