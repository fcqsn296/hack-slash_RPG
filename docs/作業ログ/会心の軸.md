# 会心の軸（中技の穴埋め）

**ブランチ**: `work/crit-axis`
**開始**: 2026-08-24

## 何をしているか

中技（威力101〜199、攻撃技46本）だけ**無条件で効く帯支援が存在しない**問題を、
会心を軸にして埋める。効果を2つ足す。

1. `mid_power_crit` — 中技のクリティカル率を上げる
2. `crit_overflow` — 会心率が100%を超えたぶんを会心ダメージへ変換する

## なぜこの形か（調査済みの根拠）

### 中技だけ形が違った

| 帯 | 支援 | 条件 |
|---|---|---|
| 小技(≤100) | `low_power_boost` ほか4系統 | 無条件（`damage.js:442` で素通し） |
| 大技(≥200) | `high_power_boost` ほか | 無条件（`damage.js:444`） |
| 中技 | `mid_power_combo` / `mid_power_status` | **両方とも条件付き** |

- `mid_power_status` は `statusOnHit` への倍率でしかない → 別途買わないと 0
- `mid_power_combo` は `battle.js:84` の `advantage || weakened` の内側 →
  属性有利でも弱体中でもない相手には 0

中技46本のうち **38本(83%)** が弱体を自前で持たない。覇王斬もその1本。

### 会心を選んだ理由

- **無条件で効く。** 属性も弱体も要らない
- `crit_stack`（会心するほど会心率上昇）と `crit_combo`（会心でコンボ追加）は
  「何度も殴る」前提なのに、**居場所がなかった**。小技は連射/拡散、大技は低頻度の一撃。
  中技（CD持ち7%、そこそこの一撃を何度も）がこの2つの本来の住所
- `crit_combo` が既存の `mid_power_combo` と同じ方向を向く。
  会心が**無条件の着火点**になるので、条件付きだった `mid_power_combo` が自立する

大技のほうが元から会心が高い（平均0.240 対 中技0.095）が、
**それは技の側から無料でもらっているもの**。ツリーで中技に配るのは重複ではなく埋め合わせ。

### 溢れの変換が要る理由

**既に投資が捨てられている。** 会心率1.00の技が2本ある。

| 技 | 威力 | 元の会心率 |
|---|---|---|
| 終焉の一撃 | 800 | 1.00 |
| 二閃 | 320 | 1.00 |

このキャラは会心率ノードも装備の会心率も**効果が正確に0**。しかも画面には
「会心率 +7%」と出るので**無駄だと分からない**。今日ある不具合に近い。

無条件で積める会心率はツリーの `一点集中` 0.15 だけ。属性別・系統別の刃/冴えは
各0.20だが条件付き。装備 `af_crit` は1枠 0.02〜0.07。
**溢れさせること自体が既にビルドの成果**なので、報酬に変えてよい。

## 決めること（実測が要る）

- `mid_power_crit` の1段あたりと最大段数
- `crit_overflow` の変換率。**等倍にしない。**
  `CRIT_MULTIPLIER=1.5` に対し `痛打` が最大+0.75、ユニークに+0.50 で素で2.75倍まで届く。
  等倍だと会心率ノードが `痛打` の上位互換になる。0.30〜0.50 から測り始める
