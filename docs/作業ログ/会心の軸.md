# 会心の軸（中技の穴埋め）

**ブランチ**: `work/crit-axis`
**開始**: 2026-08-24

## 何をしているか

中技（威力101〜199、攻撃技46本）だけ**無条件で効く帯支援が存在しない**問題を、
会心を軸にして埋める。効果を2つ足す。

1. `mid_power_crit` — 中技のクリティカル率を上げる
2. `crit_overflow` — 会心率が100%を超えたぶんを会心ダメージへ変換する

## なぜこの形か（調査済みの根拠）

### 中技だけ形が違った

| 帯 | 支援 | 条件 |
|---|---|---|
| 小技(≤100) | `low_power_boost` ほか4系統 | 無条件（`damage.js:442` で素通し） |
| 大技(≥200) | `high_power_boost` ほか | 無条件（`damage.js:444`） |
| 中技 | `mid_power_combo` / `mid_power_status` | **両方とも条件付き** |

- `mid_power_status` は `statusOnHit` への倍率でしかない → 別途買わないと 0
- `mid_power_combo` は `battle.js:84` の `advantage || weakened` の内側 →
  属性有利でも弱体中でもない相手には 0

中技46本のうち **38本(83%)** が弱体を自前で持たない。覇王斬もその1本。

### 会心を選んだ理由

- **無条件で効く。** 属性も弱体も要らない
- `crit_stack`（会心するほど会心率上昇）と `crit_combo`（会心でコンボ追加）は
  「何度も殴る」前提なのに、**居場所がなかった**。小技は連射/拡散、大技は低頻度の一撃。
  中技（CD持ち7%、そこそこの一撃を何度も）がこの2つの本来の住所
- `crit_combo` が既存の `mid_power_combo` と同じ方向を向く。
  会心が**無条件の着火点**になるので、条件付きだった `mid_power_combo` が自立する

大技のほうが元から会心が高い（平均0.240 対 中技0.095）が、
**それは技の側から無料でもらっているもの**。ツリーで中技に配るのは重複ではなく埋め合わせ。

### 溢れの変換が要る理由

**既に投資が捨てられている。** 会心率1.00の技が2本ある。

| 技 | 威力 | 元の会心率 |
|---|---|---|
| 終焉の一撃 | 800 | 1.00 |
| 二閃 | 320 | 1.00 |

このキャラは会心率ノードも装備の会心率も**効果が正確に0**。しかも画面には
「会心率 +7%」と出るので**無駄だと分からない**。今日ある不具合に近い。

無条件で積める会心率はツリーの `一点集中` 0.15 だけ。属性別・系統別の刃/冴えは
各0.20だが条件付き。装備 `af_crit` は1枠 0.02〜0.07。
**溢れさせること自体が既にビルドの成果**なので、報酬に変えてよい。

## 決めること（実測が要る）

- `mid_power_crit` の1段あたりと最大段数
- `crit_overflow` の変換率。**等倍にしない。**
  `CRIT_MULTIPLIER=1.5` に対し `痛打` が最大+0.75、ユニークに+0.50 で素で2.75倍まで届く。
  等倍だと会心率ノードが `痛打` の上位互換になる。0.30〜0.50 から測り始める

## 実測の結果

基準は `docs/拡張コンテンツの作り方.md` の「1SPあたり実効火力 +2〜3%」。
比較対象として大技帯フル（心得+極意+覇道 35SP）を測ると **3.0〜3.7%/SP**（+128%）。

### 技巧（中技の会心率）: 2SP × 5段 = 10SP、+0.30

| 技 | 伸び | per SP |
|---|---|---|
| 覇王斬(180) | +25.7% | 2.57% |
| 重斬(160) | +28.1% | 2.81% |
| 疾風刃(120) | +25.7% | 2.57% |

帯の排他も確認済み（大技の心得を積んでも覇王斬には 0.0%）。
実戦（fl_sealed、3種×24戦）でもラウンド **3.01 → 2.57（-14.6%）**。**値はこのまま。**

### 極点（会心率の余り → 会心倍率）: 3SP × 3段 = 9SP、変換0.75

**3回作り直した。** 経緯を残す。

1. `4SP × 0.12`（12SP/変換0.36）→ 静的計算で 0.09%/SP。ほぼ無意味
2. `3SP × 0.30`（9SP/変換0.90）→ 実戦でも -4.0%。**上げても動かなかった**

ここで調整をやめて原因を測った。`damage.calc` を包んで実戦中の会心率を記録したところ:

```
味方の攻撃 646回中、溢れたのは 73回（11.3%）
会心率の中央値 0.503 / 最大 1.742
```

**溢れていなかった。** 検証台は4人に同じツリーを配るが、`tr_crit_light`（光）と
`tr_crit_phys`（物理）は技の属性・系統が合った1人にしか乗らない。
残り3人は会心率が低いままで、パーティ平均が薄まっていた。
**極点は「1体が飽和して初めて効く終端ノード」なので、均一パーティの平均では過小に出る。**

飽和した1体だけを見て、`crit_stack` の戦闘中の積み上がりを `critBonus` で再現して測り直した。

| 熱狂の積み | 溢れ | 伸び | per SP |
|---|---|---|---|
| 0 | 0.068 | +2.3% | 0.25% |
| 0.2 | 0.268 | +8.9% | 0.99% |
| 0.4 | 0.468 | +15.6% | 1.73% |
| 0.6 | 0.668 | +22.3% | **2.47%** |
| 0.8 | 0.868 | +28.9% | **3.21%** |

実戦で観測した最大会心率 1.742 は「積み 0.67」に相当するので、上限側は約2.8%/SP。
**踏み込まないと割に合わず、振り切ると帯に入る**形になった。`high` 帯の終端として妥当。

変換0.90 では積み0.8で 3.86%/SP と band を超えたので 0.75 に落としてある。

## 残った課題（未着手）

**中技帯の総量が足りない。** 技巧は per SP では大技と並ぶが、
帯として使えるSPが 10SP（+28%）しかなく、大技帯は 35SP（+128%）ある。
中技に寄せたビルドは、帯の中に振る先が尽きる。

会心率は 1.0 で頭打ちになるため、技巧を増段しても伸びない（そこは極点が受けるが変換で目減りする）。
総量を足すなら **中技だけの会心「倍率」** を持つノードが要る。上限が無いので総量を担える。
効果を1つ増やす話になるので、いったん報告して判断を仰ぐ。
