# 生成ツールに「差し替え」を足す

## 何が足りなかったか

`--missing` は **まだ絵が無いもの**をまとめて対象にする。
絵柄の方針を変えたときに直したいのは、その裏側——**もう入っているもの**のほう。
IDを一列に並べて打つしかなかった（今回、10体ぶんを手で並べた）。

なお `install()` 自体は最初から差し替えに対応していて、
同じIDで拡張子違いが残らないよう古いほうを消す作りになっていた。
足りなかったのは**対象の選び方**と**そのあとの案内**だけだった。

## 足したもの

### `--redo {enemy,character,all}`

`--missing` のちょうど裏返し。

```
python tools/novelai_gen.py --redo character --dry-run   対象と文面を確認
python tools/novelai_gen.py --redo all                   全部撮り直す
```

実測: `--redo character` は51体、`--missing character` は15体。

### 差し替えたときだけ出す注意

`--install` で既存を上書きしたら、末尾でこう出すようにした。

  ・`prepare_release.py --apply` へ進むこと
  ・**味方は顔の位置を必ず測り直すこと**

後者が肝心で、**`detect_faces.py --write` は既に `face` がある対象を触らない**
（作者が意図して決めた値とみなすため）。差し替えでは
「測り直したつもりで何も書かれていない」が起きる。実際に起きた。

対象のIDも並べて出すので、そのまま `--sheet` に渡せる。

敵は顔の切り抜きをしないので、この注意は味方のときだけ出る。
