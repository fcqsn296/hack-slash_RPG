#### 1. 拠点にいる間も矢印キー・Enter が地図に効く（進行不能級）

**何が起きたか**
物語の探索中に「拠点へ戻る」を押して拠点画面にいるあいだ、矢印キーを押すと
**画面に映っていない地図の上で主人公が歩いてしまう**。歩数が溜まると遭遇判定が起き、
拠点から突然 story 戦闘へ叩き込まれる。戦闘が終わると `finishBattle` が
`showMap()` へ返すので、**拠点にいたはずが探索画面に立たされている**。
Enter / スペースも同じで、拠点画面で押すと地図側の `interact()` が走る。

**再現手順**
1. 物語 → 探索へ入り、mp_vault の (14,5)（mp_deep への階段）に立つ
2. 「拠点へ戻る」を押して拠点画面を出す
3. Enter を1回押す
4. `RPG.worldmap.current()` を見ると `mp_vault (14,5)` → `mp_deep (1,6)` に移動している。
   画面は拠点のまま（実測でこの通りになった）

遭遇のほうは、mp_deep の (4,9) 付近で拠点に戻り、拠点画面のまま ← → を14回押したら
5歩目あたりで `screen-battle` が開いた。

**どこで**
`src/main.js` の `showBase()`（175行付近）が `RPG.ui.worldmap.unmount()` を呼んでいない。
`src/ui/worldmap.js` の `bindKeys()` は `window` に付けたまま、
外す条件が `unmount()`（＝`root = null`）だけ。`unmount()` を呼んでいるのは
`playPendingScene` / `leaveStory` / `startStoryBattle` の3箇所で、拠点行きの経路が抜けている。
図鑑からシーンを読み返す `replayScene()` も同じで、Enter が
「シーンを送る」と「地図で調べる」の両方に届く。

**どのくらい困るか** 進行不能。拠点で装備を触っているだけで戦闘に飛ばされ、
気づかないうちに別のマップへ移動している。

#### 2. 封絶の浅層の宝箱を開けると「装備」タブが二度と開かなくなる（進行不能級）

**何が起きたか**
mp_deep (3,9) の宝箱から「写しの護符」を拾ったあと、拠点の**「装備」タブを押しても何も起きない**。
画面は前のタブのまま、タブの見出しも切り替わらない。エラーは画面に出ないが、
コンソールに `TypeError: Cannot read properties of undefined (reading 'color')` が出ている。
装備の付け替えも自動装備の画面も開けないので、以後この周では装備をいじれない。

**再現手順**
1. 第三章で mp_deep へ降り、(3,9) の宝箱を開ける（「写しの護符」が手に入る）
2. 拠点へ戻り「装備」タブを押す → 何も起きない

**どこで**
`data/maps.js` 295行、mp_deep の `deep_chest_2`:

```js
base: 'eq_relic_seal', rarity: 'EPIC', name: '写しの護符',
```

`EPIC` は `RPG.data.rarities` に無い（`COMMON` / `RARE` / `SUPER_RARE` / `LEGEND` の4つだけ）。
`src/ui/widgets.js:240` の `const r = RPG.data.rarities[item.rarity];` が undefined になり、
`r.color` で落ちる。落ちるのは `renderGear` の途中なので、`replaceChildren` まで到達せず
**画面が黙って据え置かれる**（他のタブ — 鑑定・ビルド・出撃・図鑑・鍛冶・編成 — は無事）。
なお `RPG.gear.forge` はレアリティを検査しないので、拾う瞬間は普通に成功する。

**どのくらい困るか** 進行不能。この宝箱は二番機ドゥオへ向かう途中に置いてあるので、
先に拾ってしまうとボス前に装備を整え直せなくなる。

#### 3. 20列のマップでは主人公の駒が画面外に出たまま歩くことになる

**何が起きたか**
mp_ashfield / mp_hamlet / mp_deep（いずれも横20マス）は、ウィンドウ幅が足りないと
地図が横スクロール領域になる。ところが**スクロール位置が主人公を追わない**ので、
東へ進むと駒が見えなくなる。自分がどこにいるか分からないまま歩くことになる。

**再現手順**
1. ウィンドウ幅 538px（内容幅 481px）で mp_deep を開く
2. 東へ歩いて x=17 あたりまで行く
3. `.wm-viewport` の `scrollLeft` は 0 のまま、`.wm-hero` の左端は 520px
   （ビューポートの右端は 501px）。駒は枠の外

**どこで**
`styles.css:3290` `.wm-viewport { overflow-x: auto }` と `.wm-grid { width: max-content }`。
`src/ui/worldmap.js` の `render()` に、駒を可視範囲へ寄せる処理が無い。
セルは28px（480px以下では22px）なので、20列で 580px / 460px。
今回の幅では 481px しか無く、mp_forge(14列) と mp_vault(16列) だけが収まる。

**どのくらい困るか** 遊びにくい。移動はできるので詰まりはしないが、
手で横スクロールしないと自分の位置が見えない。

#### テスト側の注記

自動戦闘用に書いた使い捨てスクリプトが、非表示になった戦闘画面の「マップへ戻る」を
押し続けてしまい、`finishBattle` が同じ戦闘に対して60回走った（宝箱66個・戦績60勝）。
**こちらの不手際**なので不具合として数えていない。気づいた時点で
ゴールド・経験値・宝箱を実際の払い出し（1,118 G / 220 exp / 銅11・銀1）へ戻してから続けた。
ただし `finishBattle` が同じ battle オブジェクトで何度でも報酬を払うのは事実なので、
二重押しに弱い作りではある（通常操作では `showOnly` が即座に画面を隠すので踏みにくい）。
