# レベルの節目を作る

## 前提として調べたこと

レベルで動いていたものは、実はもう2つあった。

| 何が | 決まり方 |
|---|---|
| SP | (レベル−1) + 凸 … 毎レベル |
| ステータス | base + growth×(レベル−1) … 毎レベル |
| **クラスポイント** | `floor(レベル/5)` … **5レベルごと** |
| 装備枠 | Lv5 / 10 / 20 |
| 闘技場 | Lv60（アカウント単位） |

穴は2つ。**ゲームで最も大きな選択であるクラス就任がレベルと無関係**だったこと
（無条件・無料）と、**Lv150〜255にSPしか無い**こと。

## 今回入れたもの

| | レベル | 誰のレベルで見るか |
|---|---|---|
| クラスに就ける | **30** | そのキャラ自身 |
| エンドレスタワー | **40** | 主人公 |
| 鍛冶（強化・厳選・再抽選） | **50** | 主人公 |
| 闘技場（既存） | 60 | 主人公 |

装備枠(5/10/20)と合わせて、**5 → 10 → 20 → 30 → 40 → 50 → 60** の階段になった。

### 誰のレベルで見るかを分けた理由

- **クラスはそのキャラ自身**。1人ずつの選択なので、主人公の到達で
  全員のクラスが開くのはおかしい
- **塔・鍛冶・闘技場は主人公**。装備も挑戦記録もアカウントで共有するので、
  1人ずつ開けても意味がない

### 鍛冶が Lv50 の根拠

宝箱の落ち方を調べた。

| 推奨Lv | フィールド | 落ちる箱 |
|---|---|---|
| 1 | 始まりの草原 | 銅・銀・金 |
| 12 | 崩れた廃坑 | 銀・金・竜 |
| 28 | 灼獄竜の巣 | 銀・金・竜 |
| **50** | **忘却の遺構** | **金・竜**（銀が消える） |
| 80〜 | 終焉の深淵ほか | 竜 |

**推奨Lv50 から銀が落ちなくなり、竜（レジェンド50%）と金だけになる。**
それより前は数フィールドごとに装備を丸ごと乗り換えるので、
強化に払っても次の宝箱で捨てることになる。乗り換えが落ち着くのがここ。

### クラスが Lv30 の根拠

スキルツリーの上級ティアが開き、装備枠が3つとも揃うあたり。
**1人につき一度きりの選択**なので、「自分がどう戦いたいか」が見えてから
選べる位置に置いた。中身（6クラスの説明）は解禁前から見られる。
何が待っているか分からないままレベルを上げさせるより良い。

## 実装で気をつけたこと

**画面だけ塞いで入口を塞ぎ忘れる**のがこの手の変更でいちばん起きやすい。
`enhance` / `reroll` / `refine` / `tower.start` / `state.setClass` の
**関数側にも条件を置いた**。検証テストは実際に呼んで断られるところまで見ている。

就任済みのキャラは条件を通さない。後から条件を厳しくしたときに、
既に就いているキャラが転職すらできなくなるのを避けるため。

既存テストが1つ落ちた。§7.6 の鍛冶テストは Lv1 のまま強化していたので、
解禁レベルから始めるように前提を足した（解禁そのものの検査は別に置いた）。

## 見せ方

解禁前でも**中身は見せる**。クラスは6つの説明が並び、塔は階層表が出る。
鍛冶だけは「乗り換えが落ち着くころに開きます」と理由を書いた。

図鑑にも「レベルの節目」の項を足し、本文の数値は実装の定数と突き合わせている。
