# 棘に上限を設ける

**ブランチ**: `work/thorns-cap`
**日付**: 2026-08-25

## きっかけ: 闘技場のHP見積もりを9倍間違えていた

反射の調査中、闘技場ボスのHPを 4,760,600 と見積もっていたが、**実際は 39,981,600**。
利用者から実機の画面を示されて発覚した。

掛け忘れが2つあった。

```
正しい式: statsAtLevel(def, 255) × (scale × HARD_SCALE) × bossStatMultiplier
                                          ~~~~~~~~~~~~     ~~~~~~~~~~~~~~~~~~
                                          =6 を忘れた       =1.5 を忘れた
```

| ボス | ハードHP |
|---|---|
| 無貌の簒奪者 | 42,845,400 |
| 三重の守護者 | 42,574,032 |
| 終刻の審判者 | **39,981,600** |
| 闘技場の主 | 15,552,000 |
| 千葬の守り手 | 13,264,290 |

味方HP 35,724 に対して **370〜1,200倍**。「20〜133倍」と報告したのは誤りだった。

## 正しい数字で測ると、問題は反射ではなく棘だった

棘は `attacker.maxHp × 率` の割合ダメージで、**上限が無かった**。

```
39,981,600 × 0.29 = 11,594,664   ← 棘1発
3.5回被弾するだけでボスを削り切る。しかも13SP。
```

闘技場ハードでの実測（修正前）:

| 構成 | 勝率 | 貢献 | ボスHP比 |
|---|---|---|---|
| **棘** | **50%** | 40,581,324 | **101.5%** |
| 反射(×0.1) | 0% | 820,437 | 2.1% |
| 同SPを火力へ | 0% | — | — |

## ただし「棘でしか勝てない」ではなかった

利用者の実セーブで確認したところ、**主人公＋破鎧撃持ちの2人で完走できる**。

| 構成 | 勝率 | 最大で削れた量 |
|---|---|---|
| 実主人公＋ゼロ（破鎧撃）2人 | 11% | 39,981,600（完走） |
| 実セーブのパーティ4人 | 67% | 39,981,600 |
| 検証台の2人 | 0% | 1,210,267 |

検証台の自動生成キャラは実物の 1/33 しか出せない。
「アタッカーは勝率0%」と報告したのは**測る相手が弱すぎた**だけだった。

正しくは「**棘を積めば弱いキャラでも勝てる**」。13SPで被弾3.5回という対価の軽さが問題。

## 入れたもの

率は割合のまま（インフレ耐性を残す）で、**1発の頭だけを自分のスケールで押さえる**。

```js
const THORNS_CAP_RATIO = 30;   // 自分の最大HPの30倍まで
const cap = defender.maxHp * THORNS_CAP_RATIO;
const back = Math.min(attacker.maxHp * thorns, cap);
```

### 効き

| | 修正前 | 修正後(×30) |
|---|---|---|
| 闘技場 棘1発 | 11,594,664 | 860,640 |
| 闘技場 ボスHP比 | 101.5% | **8.0%** |

**通常フィールドには一切当たっていない。**

| 場 | 棘合計 | 敵HP比 | 上限に当たった回数 |
|---|---|---|---|
| fl_origin | 136,100 | 7.1% | **0** |
| fl_endless | 318,047 | 11.7% | **0** |

数値は修正前と完全に同じ。効くのは桁違いの相手のときだけ。

### 倍率の選定

| 倍率 | 闘技場での棘 |
|---|---|
| ×20 | 5.3% |
| **×30（採用）** | **8.0%** |
| ×40 | 約11% |

通常フィールドの棘が 7〜11% なので、×30 でほぼ同水準に揃う。
「割合ダメージは強い相手ほど効く」性質もわずかに残る。

検証テスト 1210/1210。

## 残っている非対称

闘技場での貢献は 棘 8.0% 対 反射 2.3%。
反射のレベル倍率(×0.1)は通常フィールド向けに決めた値なので、
闘技場ではまだ届いていない。ここを揃えるかは別の判断。
