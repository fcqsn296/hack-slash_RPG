# 支援役を1枠使う価値（拡張ロードマップ C1）

ブランチ `work/支援の価値`。計画は `docs/拡張ロードマップ.md`。

## 結論

**支援の価値は「どれだけ削られるか」で決まる。** 終盤の周回では削られないので価値はゼロ、
格上に挑むと逆転する。「支援は弱い」ではなく「**支援が働く場面が周回に無い**」が実態。

そして測る前に、**オートが軽減技を1つも使っていなかった**（下記）。
これを直してから測り直している。

## 見つけた不具合: オートが軽減技を選ばない

`autoplay.js` の `BUFF_PLUGINS` は `unique_buff / tag_buff / def_buff` の3つだけで、
**`reduction_buff` が入っていなかった**。軽減技は威力0なので攻撃技でもなく、
回復でもない。**どの分岐にも引っかからず、手札の中で死んでいた。**

対象は8種:
絶えぬ灯・名乗り・光帷の加護・不動明王・守りの号令・不落の誓い・絶対防壁・万人の盾。

テオドラの看板である『万人の盾』、ネヴィアの『絶えぬ灯』が、
**オートでは一度も撃たれない**状態だった（実測: Lv120 の苛烈な条件でも
テオドラは 不動の砦 と 重斬 しか使っていない）。

### 直した内容

- `BUFF_PLUGINS` に `reduction_buff` を足した
- `buffActive` が `buffReduction` も見るようにした。軽減バフは
  `statusEffects` ではなく `buffReduction` に積まれるので、
  足さないと「もう張ってある」が判定できず毎ターン張り直す。
  軽減技はクールダウンが持続+1なので実害は出にくいが、
  **クールダウン頼みにすると持続とCTの関係を将来変えたときに静かに壊れる**

### 効果

| | 修正前 | 修正後 |
|---|---|---|
| ネヴィアが絶えぬ灯を使った回数（6戦） | 0 | 9 |
| テオドラが万人の盾を使った回数（6戦） | 0 | 12 |
| 回復編成の勝率（格上 Lv150） | 50% | **71%** |

攻撃編成（plain）の結果は変わっていない。**攻撃役が手番を無駄にしてはいない。**

`barrier`（動かぬ壁・大盾の宣誓）は入れていない。障壁は持続を持たず
`buffActive` で「もう張ってある」が判定できないため、別の手当てが要る。
1回に1つだけ変える。**未着手として残す。**

## 測った結果（臨界の際・24試行・Lv255は5凸）

支援を1つの型で代表させず、**plain のディアナ1枠だけ**を入れ替えた3種で測った。

| | 素直な攻撃 | 属性特化 | 支援(バフ) | 回復 | 防護 |
|---|---|---|---|---|---|
| **安全 Lv255** 勝率 | 100% | 100% | 100% | 100% | 100% |
| 　　　　　　 1周R | 6.0 | **5.0** | 9.7 | 9.5 | 7.0 |
| **格上 Lv150** 勝率 | 75% | 58% | **96%** | 71% | **100%** |
| 　　　　　　 1周R | 7.7 | 11.2 | 16.0 | 20.6 | 20.0 |
| **苛烈 Lv120** 勝率 | 17% | 0% | 13% | 0% | **100%** |
| 　　　　　　 1周R | 13.3 | — | 22.0 | — | 30.3 |

### 読み取れること

**① 安全な周回では支援の価値はゼロ。** 勝率も残HPも天井なので、
支援は「所要が +58〜62% 伸びるだけ」。防護でも +17%。
枠を1つ攻撃役から外す対価だけが残る。

**② 格上では逆転する。** バフが +21pt、防護が +25pt。
ここで初めて「1枠を支援に使う」が意味を持つ。

**③ 苛烈な帯では防護しか答えにならない。** plain 17% に対して防護 100%。
ただし所要は 13.3R → 30.3R と倍以上。**「遅いが死なない」**という別の遊び方。

**④ 属性特化は速いが脆い。** 安全帯では最速（5.0R）なのに、
格上で 58%（plain 75% を下回る）、苛烈で 0%。
**速さと耐久が入れ替わる**帯があるのは、編成を選ぶ意味として健全。

## 未確認・宿題

- **防護（テオドラ）が強すぎないか。** Lv120（推奨Lv225のフィールド）で勝率100%は、
  100レベル以上の差を1枠で埋めていることになる。所要が倍という対価はあるが、
  数値の見直しが要るかもしれない。**今回は測っただけで触っていない。**
- **回復（ネヴィア）は苛烈帯で 0% のまま。** 受動的な再生（毎ラウンド26.5%）では
  追いつかない。能動的な回復技を持たないキャラなので、
  「回復役」として測るなら別のキャラ（マリカ・アガタ）でも測る必要がある
- `barrier` をオートが使えない件（上記）
- ここで測ったのは**オート**。手動なら段取りを組めるので結果は変わる（未測定）
