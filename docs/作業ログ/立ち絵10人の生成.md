# 支援・会心・中技帯 10人の立ち絵

## 生成

`data/characters.js` の `artPrompt` から自動合成。逐次1件ずつ、10秒間隔。
まず1人だけ投げて通ることを確かめてから残りを流した。

**契約情報の確認 (`--check`) だけが HTTP 400 で落ちる。**
`api.novelai.net/user/subscription` が
「Please refresh NovelAI.net. If using a third-party tool, update to the image URL.」
を返す。画像生成そのもの（`image.novelai.net/ai/generate-image`）は通るので、
生成には支障がない。**ツール側の未修正点として残っている。**

## 撮り直したのは1人

ヴェルナの初回は **バイザーが顔全体を覆って顔が無かった**。
顔アイコンが切り出せないので、プロンプトを言い換えて撮り直した。

  before: sharp golden eyes behind a slim marksman visor
  after : sharp golden eyes clearly visible,
          thin marksman visor pushed up onto her forehead

「目の前にバイザー」と書くと生成側は顔を覆う。**額へ上げた形に言い換える**と
目が出る。同じ書き方をする装備（ゴーグル・面頬）では気を付けること。

他9人は1枚目をそのまま採用。

## 顔の位置で踏んだ罠

`detect_faces.py --write` が **0体しか書かなかった**。
このツールは「既に `face` がある＝作者が意図して決めた値」とみなして触らない。
立ち絵が無い間の**仮値**（`x: 0.5, y: 0.11, size: 0.36`）を置いていたので、
全員が手動指定扱いになっていた。

計測値を手で書き入れた。**新しいキャラを足すときは、立ち絵ができるまで
`face` を仮値で埋めないほうがよい**（埋めるなら、後で必ず上書きすること）。

### ヴェルナだけ自動計測が外れた

自動値は `x=0.602`。弓の炎が右上に伸びているぶんに引っ張られていた。
頭部だけを測り直すと塊は `0.50` 付近だったので、顔を見て `x=0.47` に手で直した。
ディアナも大剣を持っているが、こちらは頭の塊が `0.428` で自動値と一致していた。

**大道具が斜めに伸びる絵は自動計測がずれる。** 出力を必ず目で見ること。

## パイプライン

透過 → 顔の算出 → メタデータ除去 → WebP。
`assets_png_master/` に元PNGが退避されている（公開対象外・消さないこと）。

  容量  7.9 MB → 0.7 MB（92%減）
  控え  tools/image_metadata_backup.json に10人分のプロンプトとシードを追記

**WebP 化すると `detect_faces.py --sheet` は使えなくなる**（PNGを読むため）。
顔の確認は変換前に済ませること。今回は変換後だったので、
ゲームと同じ式（`facecrop.applyRect`：x,y は切り抜きの**中心**）で
実データから描き直して確認した。10人とも中央に収まっている。
