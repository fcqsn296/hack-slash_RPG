**ブランチ**: `work/記録の器`

## 何を変えるか

物語を**会話主体**にして、世界の説明はアイテムのフレーバーへ移す。
そのアイテムは「進行に応じて配られる、説明を入れておく箱」で、図鑑から読み返せる。

|---|---:|---:|---:|

| 第二章 継承の座 | 195字 | 387字 | 34% |
| 第三章 二番機 | 662字 | 893字 | 43% |

**設定を明かす章ほど地の文が増える。** 第四章は会話より地の文のほうが多い。
旧文明・継承機構と明かすものが重くなるほど「説明する声」が要るので、
放っておけば第五章はさらに地の文寄りになる。

## 作り

### 道具ではなく図鑑に置いた

最初は `RPG.data.items`（道具）へ足す形を考えたが、2つの理由で採らなかった。

1. **`items` は `PROFILE_KEYS` に入っている。** 物語側で配ったものは周回側から見えない。
   図鑑は共有されるので、**物語で拾って周回で読み返せる**のは図鑑側だけ
2. 道具は「使う」ものとして持ち物に並ぶ。使えない箱を混ぜると棚が濁る

### セーブに何も足していない

手に入れたかどうかは**物語の進行から導出する**。図鑑の設計方針そのもの
（`src/core/codex.js` 冒頭「図鑑そのもののデータは持たない」）に合わせた。

進行は `save.story.progress` にあり、`RPG.state.storyProfile()` は
**モードに関係なく**そこを返す。だから周回側からも同じ判定ができる。

```js
rc_gargh_gut: {
  name: 'ガルクの未消化物',
  when: { flag: 'gnaw_slain' },     // { scene } / { chapter } も可
  short: '…', body: ['…'], see: ['bs_gnaw_king'],
}
```

### 収集率には数えない

記録は**物語モードでしか手に入らない**。収集率に足すと、周回しか遊んでいない人の
達成率が、この区分を足した日に下がる。既にある数字の意味を変えないため
`collect: false` にして、区分の中だけで「4 / 8」と数える。
検証テストで分母が 124（キャラ66＋敵46＋場12）のままであることを固定した。

### 手に入っていないものは並べない

読み返し（物語の区分）と同じ理由。品名だけで先が透ける
——「ウーヌスの掌」が一覧にあれば、ウーヌスに何が起きるか分かってしまう。
代わりに件数だけ出して、まだ増えることは伝える。

### 知らせ方

導出なので、放っておくと増えたことを誰も知らせない。拾った実感が要るので、
**シーン再生の前後で差を取って**トーストを出す（`src/main.js`）。

前に控えるのがみそで、**シーンを起こした旗そのものが記録の解放条件になっている**
（`gnaw_slain` は `ch1_boss` を起こし、同時に「ガルクの未消化物」を開ける）。
`finish` の後だけを見ても差が出ない。

どのシーンも起こさない旗に紐づけると、増えても誰にも知らされない。
**検証テストがそれを禁じている**（「記録: 手に入れたことを知らせられる」）。
