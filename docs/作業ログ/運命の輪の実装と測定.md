# 運命の輪 X — 実装と測定

実装済み。検証テスト 1711/1711 合格（運命の輪23件）。
仕様は `docs/運命の輪の実装案.md`。未確定だった値は下のとおり決めた。

## 実装したもの

> 利: 物理・魔術・遺物の順に攻撃すると、防御崩壊・標的・凍結を与える。一周すると味方全員の次の一撃の上限が上がる
> 害: 輪に反した攻撃1回につき、敵が動く直前に現在HPが半分になる

- 効果種 `wheel`（値 1.0＝一周の祝福の上限倍率）。0 より大きいことが違反を数える旗も兼ねる
- 判定は `performAction` で**攻撃を解いた後**（`turnWheel`）。恩恵はその攻撃に遡らない。
  多段・多重発動でも1行動1段。反撃・棘は performAction を通らないので数えない。
  麻痺で飛んだ手番・正義で不発になった手番は判定しない
- 系統は**実効の系統**（魔術師の書き換えがあればそちら）
- 恩恵は**この行動で実際に当てた生きている敵**へ（月の実装で作った actionHits を共用）。
  値は既存の技に揃え、新しい効果は作っていない:
  防御崩壊2T（破鎧撃などと同じ `setDefIgnore`）／標的 +35%・3T（単体の照準と同じ `mark`。
  強い標的を弱い値で上書きしない）／凍結 +20%・3T（単体の凍結技と同じ）
- 一周の祝福: 味方全員（倒れている者は除く）へ。使う前にもう一周しても足さずに更新。
  次の攻撃1行動の開始時に移して使い切る（節制と同じ）。回復・補助・麻痺では消費しない。
  上限の式は正義と同じ「削られた値を (1+X) 倍、素点まで」。正義と重なったら掛け合わせる
- 違反の精算: `runEnemyPhase` の先頭（通常の敵フェーズの直前）と、途中のウェーブ制圧時。
  最終ウェーブの勝利では精算しない。開幕の先制と正義の応撃は runEnemyPhase を通らないので精算しない。
  現在HP × 0.5^違反、**切り上げ・最低1**。防御・障壁・反射を通さない（hurt も通さない）。倒れている者は蘇らせない
- オートは輪を見ずに選ぶ（仕様どおり）。判定だけは手動と同じ
- 画面: コマンド欄の頭に「運命の輪 1/3 — 次は物理（防御崩壊）／違反 1（敵が動く前にHP×0.5）／祝福 上限+100%」。
  外れる攻撃技には「輪に反する」のチップ（押せなくはしない）

## 測定（終盤セーブ、20試行）

輪に従う打ち手は測定用スクリプトだけに書いた（求められた系統の攻撃のうち見積もり最大を撃ち、無ければ通常オート）。
ゲームのオートには足していない。

### 主人公（魔術の攻撃が弱い）

| | 素 | 輪・オート | 輪・輪に従う |
|---|---|---|---|
| 周回 | 5.00R | 5.00R（違反4.9） | 5.00R（一周1.0） |
| 敵HP×3000 | 6.50R | 7.20R（違反9.8・精算4.5） | **8.45R**（一周3.9） |
| 先制＋あまねく×1000 | 5.20R | 5.90R | 5.40R |
| 闘技場ハード終刻 | 4.05R | 4.05R・主人公が倒れる戦 10% | 4.05R |
| 簒奪者ハード・倒せない6R | 157B | 131B | **203B** |

輪に従うと、3手に1回は弱い魔術の技（魔力斬、上限の1.2倍）を強いられ、雑魚の多い場では損をする。

### アストラ（3系統の攻撃を持つ）

| | 素 | 輪・オート | 輪・輪に従う |
|---|---|---|---|
| 敵HP×3000 | 6.50R | 7.45R | **5.75R** |
| 先制＋あまねく×1000 | 5.20R | 6.35R | **5.00R** |
| 簒奪者ハード・倒せない6R | 157B（持ち主が倒れる戦 45%） | 145B（100%） | **307B**（25%） |

アストラが置いた標的と凍結に、主人公の大技が乗る。**持ち主が3系統を持つかどうかで損得が裏返る。**

### 既存の札との比較（主人公に装備、簒奪者・倒せない6R）

力 251B／吊るされた男 328B／戦車 185B／正義 164B／月 36B。
アストラの輪（307B）は上位の札と並ぶ。

### 祝福の大きさ

主人公・輪に従う:

| 祝福 | HP×3000 | 簒奪者6R |
|---|---|---|
| +0% | 9.25R | 201B |
| +50% | 8.35R | 202B |
| +100% | 8.45R | 203B |
| +200% | 7.60R | 205B |

ボス相手ではほとんど動かない（主人公の与ダメの大半が上限を無視する終焉の一撃のため）。
効いているのは三種の弱体のほう。正義の上限強化と同じ +100% に揃えた。

## 解放依頼「巡る三相」

パーティ全体で 物理→魔術→遺物 の順の攻撃を2周させてから、15ラウンド以内に抜ける（創世の残響、HP×50）。
新しい規則 `wheelLaps`: 順に合う攻撃だけが進め、外れても失敗にしない（札と同じく背くことは許す）。
周回が足りないまま最後の敵を倒すと失敗。戦闘画面の見出しに「輪 1/2周・次は魔術」を出す。
依頼一覧の条件にも出す（ついでに `noRepeat` と `idleHero` も条件表示に足した。これまで出ていなかった）。

| | 終盤4人 | Lv200へ下げた検証編成 |
|---|---|---|
| 3周・HP×50 | 2/12（5ラウンドで倒しきり、2周で終わる） | 12/12・15.5R |
| 2周・HP×50 | 12/12・5R | 12/12・15.5R |
| **2周・15ラウンド以内** | **12/12** | **7/12**（落ちた5戦は時間切れ） |
| 2周・16ラウンド以内 | 12/12 | 11/12 |

周回を増やすと、強い編成ほど「倒しきる前に巡らせる」手加減の問題になるので2周にした。
