# 中技帯のレジェンドを4人

## 構造的な穴

「中技が割を食っている」の原因は、枝の中身にあった。

| 帯 | 直接火力 | 上限突破 | 搦手 |
|---|---|---|---|
| 小技 | `low_power_boost` ○ | — | 拡散・連射・追撃 |
| **中技** | **× 無い** | **× 無い** | 会心・弱体・コンボ |
| 大技 | `high_power_boost` ○ | `high_power_cap` ○ | — |

**中技だけ、素直に強くする手が1つも無かった。** あるのは会心・弱体・コンボという
搦手だけで、どれも「相手を選ぶ」か「積み上げが要る」。
だから中技は、手数でも威力でも上を取れない帯になっていた。

## 効果を2つ足した

- `mid_power_boost` … 中技の火力
- `mid_power_cap` … 中技のダメージ上限突破

どちらも `situational` 経路で、威力帯で排他（小技・大技には乗らない）。
ツリーにも枝を置いた（中段の心得 basic / 中段の極意 mid / 中庸を破る high）。

実測。ツリーを満額（boost 0.76 / cap 1.6）積んで比べた:

| 技 | 素 | 投資後 |
|---|---|---|
| 岩塊圧（威力140・中技） | 4,656 | **8,195（+76.0%）** |
| 一撃の秤（威力265・大技） | 8,813 | 8,813（変化なし） |
| 双連撃（威力70・小技） | 2,328 | 2,328（変化なし） |

帯限定が正しく効いている。

## 4人

中技の4つの鍵を1人ずつに配ってある。

| | 属性 | 能力 | 役 |
|---|---|---|---|
| **リーヴェ**（浸みる刃） | 水 | `midPowerStatus: 0.55` / `debuffDuration: 1` | 弱体を通す |
| **ツバキ**（連環の型） | 風 | `midPowerCombo: 1` / `comboPower: 0.03` | コンボへ橋を架ける |
| **ナディア**（中段の理） | 無 | `midPowerBoost: 0.50` / `guardBreak: 0.30` | 帯そのものの火力 |
| **ノエル**（際を断つ者） | 光 | `midPowerCap: 0.85` / `midPowerBoost: 0.15` | 上限を破る |

固有技の威力は全員 **101〜199**。外すと固有能力が看板技に効かない。
（ノエルの「際断ち」は195で、帯の際いっぱい）

実測: ナディアの固有技 3,645 → **5,467（+50.0%）**。
ノエルは上限に当たる規模で 803,618 → **1,186,118（+47.6%）**。

## 経路を間違えて外した

`midPowerBoost` / `midPowerCap` を最初 `passives:` に書いた。
これらは登録簿では `to: situational` で、`battle.js` は
`attacker.situational` を見る。**passives に書くと値は載るが誰も読まない。**
エラーも警告も出ず、画面上は何も異常が無い。

同じ罠を二度踏まないよう、検証テストに
**「固有能力が登録簿どおりの塊に書かれているか」** の照合を足した。

**その場で既存のバグが1件見つかった。** ネフェリの `neutralPower: 0.30` が
`passives` に置かれており、**ずっと効いていなかった**（`situational` へ移した）。
「無属性攻撃への火力+30%」が実装当初から死んでいたことになる。
