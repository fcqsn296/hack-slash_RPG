# ストーリー中に「拠点へ戻る」と装備がいじれない

## 症状

物語の探索中に「拠点へ戻る」を押しても、**装備画面が使えない**。

## 原因

`showBase()` が**隠す画面を書き漏らしていた**。

```js
function showBase() {
  $('#screen-battle').classList.add('hidden');   // 戦闘だけ隠している
  $('#screen-base').classList.remove('hidden');
  ...
}
```

`#screen-map` と `#screen-story` を隠していないので、地図の上に拠点が重なる。
実測すると、押した直後に **`screen-base` と `screen-map` が両方とも表示**になっていた。

装備の仕組みそのものは壊れていなかった。宝箱から装備を受け取って主人公に
着せるところまで通し、ATK 130 → 298 になることを確認している。
**画面が重なっていて触れなかっただけ。**

## なぜ起きたか

画面の切り替えを「隠すほうを1行ずつ書く」形にしていた。

| 関数 | 隠していたもの |
|---|---|
| `showMap` | base / battle / story |
| `playPendingScene` | base / battle / map |
| マップからの戦闘 | base / map |
| **`showBase`** | **battle だけ** |

出す画面が増えるたびに、既存の関数すべてに1行足す必要がある。
**足し忘れても何も言われない。**

## 直し方

`showOnly(id)` を1つ作り、全部そこへ寄せた。

```js
function showOnly(id) {
  for (const s of ['screen-base', 'screen-battle', 'screen-map', 'screen-story']) {
    const el = document.getElementById(s);
    if (el) el.classList.toggle('hidden', s !== id);
  }
}
```

`src/main.js` から `classList.add('hidden')` / `remove('hidden')` は**0件**になった。
画面を足すときは、この配列に1行入れるだけで全経路に効く。

## 確認

| | 表示中の画面 | モード |
|---|---|---|
| はじめ | screen-base | hack |
| 地図へ | screen-map | story |
| **拠点へ戻る** | **screen-base** | **story** |
| 探索へ戻る | screen-map | story |
| ハクスラへ戻る | screen-base | hack |

どの場面でも表示は常に1つ。モードも保たれている。

## 検査に落とせなかった

`test/index.html` は `src/main.js` を読み込まない（読ませるとアプリが起動してしまう）。
ソースを `fetch` して調べる手もあるが、**`file://` で開ける要件**があるので使えない。

代わりに**構造で防いだ**。隠し忘れる余地そのものを消してある。
画面を足すときは `showOnly` の配列だけを触ること。
