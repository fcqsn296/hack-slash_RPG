# 会心のレジェンドを3人

## 何が空いていたか

会心の枝は **27ノード・230SP** あるが、埋まっていたのは
**会心が起きた後**の広がりだけだった。

| 効果 | 持ち主 |
|---|---|
| 波及・連鎖・貫通・追撃・回復会心 | シャンタル |
| 会心でコンボ追加 | ヴィオラ |
| ウェーブ最初の攻撃が確定会心 | アルヴィナ |
| **会心率そのもの** | **誰も持たない** |
| **会心倍率そのもの** | **誰も持たない** |
| **100%超過の行き先（極点）** | **誰も持たない** |

「会心が起きたらどうなるか」の担い手はいるのに、
**そもそも会心を起こす／重くする**担い手がいなかった。

## 経路が無かった

`critRate` と `critDamage` は **passives ではなくユニットの素の値**として持っている
（`damage.js` が `attacker.critRate` / `attacker.critDamage` を直接読むため）。
一方、キャラの固有能力は `def.passives` に書く決まり。

**その間の橋渡しが無かった。** `passives: { critRate: 0.5 }` と書いても
どこからも読まれず、エラーも警告も出ないまま何も起きない。
装備セット側には同じ橋渡しが既にあり（`setFx.critRate`）、
キャラ側だけが抜けていた。

`units.js` に足した。足すのは `innate`（そのキャラ自身の宣言）であって
`passives` ではない — あちらはツリーぶんが合流しているので二重になる。
橋渡ししたキーは `passives` から消す。読み口が無いのに残っていると
「効いている」ように見えるため。

同じ罠を二度踏まないよう、検証テストで
「宣言 → ユニットの素の値 → 実際のダメージ」まで通しで見ている。

## 3人

| | 属性 | パッシブ | 役 |
|---|---|---|---|
| **ヴェルナ**（零れる極点） | 火 | `critRate: 0.55` / `critOverflow: 0.35` | 率を満たして倍率へ流す |
| **ディアナ**（一撃の秤） | 闇 | `critRate: 0.20` / `critDamage: 0.85` | 一撃の重さ |
| **サヤ**（刻みの技巧） | 土 | `midPowerCrit: 0.40` / `critRate: 0.15` | 中技を刻んで会心を稼ぐ |

**ヴェルナ** の固有技「極点の一射」は `crit_rate: 1.0`。技の会心率は
`attacker.critRate` と**足し算**される (§3.2 ステップ6) ので、
素の55%がまるごと100%超過ぶんになり、極点が即座に働く。

**サヤ** の「刻み断ち」は威力115×2。1発の威力を必ず中技帯（100 < power < 200）に
収めてある。ここを外すと `midPowerCrit` が乗らず、彼女の固有能力が看板技に効かない。
中技帯の穴も一部埋まる。

## 実測

| | 結果 |
|---|---|
| ディアナの会心倍率 | 通常6,757 → 会心15,879 = **2.35倍**（1.5 + 0.85） |
| ヴェルナの極点 | 合計会心率1.55 → 超過0.55 × 0.35 = **+12.8%** |
| サヤの会心率 | 刻み断ち(115)**70%** / 岩塊圧(140)60% / 一撃の秤(265)40% / 双連撃(70)25% |

サヤの数字は威力帯で綺麗に段が付いている。中技だけに +40% が乗っている。

能力値は Lv255換算でヴェルナ 6,324 / ディアナ 6,272 / サヤ 6,280。
レジェンド帯の中央値6,348のすぐ下で、アタッカーらしい位置。
