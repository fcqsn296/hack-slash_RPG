# 教皇 V — 実装と測定

実装済み。検証テスト 1725/1725 合格（教皇13件＋皇帝の麻痺1件）。
仕様は `docs/教皇の実装案.md`。**参加の仕方だけ仕様の初期案から変えた**（ユーザー判断、下の「全員強制を採らなかった」）。

## 実装したもの

> 利: 自分の通常手番で攻撃技を使うと、後ろに控える仲間のうち、その技のほうが自分の攻撃より削れる者が同じ技をそれぞれの能力で撃つ
> 害: 加わった仲間はそのラウンドの手番を使い、自分の技を選べない

- 効果種 `ritual`（旗、shape max）
- 手番の台帳: 各ユニットに `turnTakenRound`（このラウンドの通常手番を使ったか）と
  `ritualRound`（儀式で手番を使ったか）。`nextWave` が `totalRounds` を進めるので、ウェーブをまたいでも混ざらない。
  `skipDeadActors` は儀式で手番を使った者を飛ばす
- 儀式を始めるのは `commandSkill`（手番の持ち主の行動）だけ。**教皇の通常手番**でのみ始まり、
  再行動・奇襲・戦車の手番・勅命では始めない。参加者の行動から儀式は起きない（再帰なし）
- 参加者は**本人が動く前に予約**する: 隊列で教皇より後ろ・生存・通常手番が残る・反動と負債が無い・
  借りた技を skillReady に通せる（CT・魔術師の縛り・皇帝の縛り。未習得は理由にしない）・
  **借りる技の見込みが自分の攻撃技の最大以上**（`worthJoining`、先頭の生きている敵で見積もる）
- 共有できる技: 攻撃技のうち、クラス技・手番を生む技・フルバーストを除くもの。それ以外は教皇だけが撃つ
- 実行は `performAction(..., { borrowed: true, counted: true })` を参加者ごとに1回。
  技の中身は技から、能力・パッシブ・札は撃ち手から（教皇のダメージは写さない）。入力は1回だけ数える
- 敵フェーズとラウンドは儀式のあとに1回だけ（教皇の finishTurn）。敵が全滅したら儀式を打ち切る
- 単体の相手が先に倒れていたら、先頭の生きている敵へ向ける
- 参加者の追加行動（撃破の再行動・戦車・奇襲・確率の再行動）は普段の規則で得て、
  ラウンドの終わりに使う権利（grantedExtra）に変える。既に権利を持つ者からは奪わず重ねない。
  このため finishTurn から `earnExtra` を切り出した（規則を写さず共用する）
- 画面: 教皇の技ボタンに「儀式 N人」（押す前に、誰の手番を使うか分かる。名前は title に）

## ついでに直したもの — 勅命の受け手が麻痺すると、受け手の手番が飛んでいた

`performAction` の麻痺の分岐は「自分の手番」を前提に順番を1つ進めていた。
勅命は受け手の行動を `performAction` で撃ったあと、皇帝の `finishTurn` でもう1つ進めるので、
**受け手が麻痺すると2つ進み、受け手自身の通常手番が黙って消えていた**（52回中52回）。
儀式も同じ道を通るので、借りた行動（`borrowed`）では麻痺・使用不可でも順番を進めないようにした。
検査を足してある。

仕様の初期案（加われる仲間は全員加わる）で測った。

最良の組み合わせでも既存の札に届かず、ボス戦では回復役・支援役まで殴らされて倒れる。
仕様書の「手番を使って弱い攻撃を複製するだけなら不採用」に当たるので、ユーザーに判断を仰ぎ

## 仕様書が期待していた構成は成立しなかった

「攻撃時に確率で弱体を付ける4人が、教皇の多段技を借りる」。
攻撃時の弱体付与（毒手 `status_on_hit`・種類指定 `status_on_hit_kind`）は `executeSkill` の最後で
**1行動・1体につき1回**抽選している。多段技を借りても試行は増えない。
仕様どおり、儀式のためだけに抽選の規則は変えていない。

## 残したこと

- 参加者を手で選ぶ機能は作っていない（規則は手動もオートも同じ「得なら参加」）
- 見積もりは攻撃どうしの比較。回復や補助を撃つつもりだった者の損は数えていない（札の代償のうち）
- 召喚は未実装なので照合していない
