### 必殺が負けていた理由
会心率・倍率は上限の手前で掛かる。主人公の覇王斬は素点 15M に対して上限後 2.7M で、倍率を積んでも1/10。
会心率も幹の「会心の連鎖」が長い戦いで100%まで上げるので、極の +50% は余る。
派生に34点を払うと幹の双撃・返り血・孤高（上限の後で効く手数）を取りこぼし、そのぶん負ける。
極（DEF −60%）は変換の材料も減らすので、取ると与ダメが減っていた（×0.90〜0.95）。

### したこと
- 新しい効果「壁抜き」crit_cap: 会心した一撃は、上限で削られた後の値が (1+値) 倍（素点は超えない）。正義と同じ形
- 最初は壁を広げる形（capSum に足す）で書いたが、+70% で与ダメ +3%。上限の後で掛ける形にした
- 極に +50%、痛打の極みに +10%/段（計 +80%）。正義の +100%（条件付き）を越えない
- ボス10R（HP×200）の与ダメ、前→後: 主人公 97→139M、アストラ 84→111M、エレナ 94→112M（その枠で最良）、カグラ 77→81M
- 他の派生・闘技場・物語・塔には流れない（critCap を持つのは必殺だけ。0 のときは掛け算を通さない）
- 途中で踏んだもの: (1+正義)·(1+0)−1 の浮動小数のずれで正義の一撃が1変わり、恋人の検査が落ちた → 0 のときは通さない
- 前周の取りこぼし: ガルドの固有パッシブ（庇う15%）で恋人の検査「札を持たない味方には及ばない」が揺れて落ちた → 4人目をリンに

必殺には上限の後で掛かる「壁抜き」を足したが、布陣にも同じ手を足すと「上限の後の倍率を派生ごとに配る」が定石になり、
正義（上限の後 ×2）や極撃（上限無視）の「規則が違う」という特別さが薄れていく。
選択肢: (a) 布陣にも上限の後の手を足す（例: 陣立ての3ターンだけ味方の一撃を上限の後で +X%）、
(b) 布陣は中盤の派生と割り切る（ただし Lv150 でも弱いので数値の見直しは要る）、
(c) 終盤の上限の扱いそのものを見直す。どれを採るかはユーザーに聞く。

**揃えにくさが倍になった**（特定セットの4点は竜の宝箱で約105箱→約210箱）ので、ユーザーの判断で2つ足した:
- 竜の色違い4種（猛き・堅き・巡る・蝕む）。灰燼・還らぬ位相・臨界・創世の竜の宝箱が色違いになり、
  セットが出たとき70%で系統（各5種）から選ぶ。系統のセットの4点は約68箱。回廊は普通の竜の宝箱のまま
- 鍛冶の「セットの付け替え」。セットを持っている装備だけを別のセットへ（欠片1個＋厳選の2倍のゴールド）。
  セット無しの装備には付けられないので、セットの出る率の意味は残るユーザー方針: 先を読んだ立ち回り（貯めて吐く・前借り）はオートに入れず、手動の利点として残す。

## オートの改善（2026-11-04 夜、ユーザー依頼）

### 訂正: 「オートは全体バフを撃たない」は誤りだった
ユニーク追加ループ2周目で「段の技も全体バフも一度も撃たない」と書いたが、全体バフについては誤り。
数えた REFERENCE の編成は**誰も全体バフを持っていなかった**（鼓舞の号令はツリーの技で、REFERENCE は取らない）。
持っている仲間はオートでも張る。エレナに鼓舞の号令（2SP）を取らせると、ボス戦の与ダメが 74M → 81M。
旗手の杖（バフの効果量・上限）も、張る本人が着ければ +5.9%。外した旗手の杖は戻した。

### したこと: オートが段の技で段を読む
- `estimate` が段の技の上乗せ（resolveCombo の scale）を入れる。必要な段が足りなければ 0
- `comboReturn`: 段を積む技は「積めた段×1段の重さ×味方1ラウンドぶんの火力」の半分を足す、払う技は同じものを引く
- 積む価値は、戦いがすぐ終わるとき（終わりかけ、または味方が2ラウンドで削りきれる残り）は 0
- 「全体バフを先に張る」も入れたが、闘技場の主 12/24→5/24（主人公が自己バフを張らなくなる）で外した

## 測り直した実測（3周目、seed固定48回、推奨Lv・主人公＋LEGEND3人・最上位の箱40個）

耐性パッケージ（置き換え）: lean = 精神耐性3＋万象の胆力2（12SP、持続 -5）、
full = lean＋気丈4（20SP）。base は耐性ノードを禁止して同じSPを他へ。蝕む相は強めた値。

| | base | lean | full |
|---|---|---|---|
| 通常 深淵 | 48/48 10R 59% | 48/48 10R 61% | 48/48 |
| 蝕む 深淵 | 44/48 11R 45% | 48/48 10R 61% | 47/48 |
| 蝕む 灰燼 | 48/48 72% | 48/48 78% | 48/48 |

- 正しい編成だと、通常の深淵まで全勝する。蝕む相が効くのは深淵だけで、それも小さい
- 蝕む相の最初の値（麻痺30%・凍結35%…）では深淵でも 46/48→48/48。上限の手前まで強めた

- 不動心系（full）は過剰。持続短縮で既に消せるところへ8SP足して火力を削るだけ

## 回復役は塔で成立しない（第2ループ1周目の実測）

REFERENCE を土台に、1人だけを役に振り、3人は攻撃専念（seed固定）:

| 1人の役 | 還らぬ位相（24回） | 塔 101階から（8回の中央値） |
|---|---|---|
| なし（4人とも攻撃専念） | 11/24 | 124階 |
| 回復（回復量・瀕死回復・拡散・献身） | 12/24 | 126階 |
| 支援（全体回復の技3種・全体軽減の技3種・回復量） | 20/24・最低HP 59% | 127階 |
| 守り（挑発・庇う・軽減・HP） | **24/24**・89% | **153階** |

- 回復だけの型は、回復の技を4戦で3回しか撃たない。殴られる前に倒れる
- 支援の型は位相では立つ（20/24）が、塔では攻撃専念と変わらない
- 塔の死因（支援の型、140階）: ボスの1発が 76,112、非守り役の最大HP は 23,000〜28,000。**一撃で落ちる**。
  そして塔では**倒れた者が次の階に戻らない**（ボス階の回復も生存者だけ。検証テストが意図として見ている）
- 蘇生の技（還りの祈り＝LEGEND固有、再臨の光＝癒し手のクラス技）は readyRound 3〜4。
  塔の1階は2ラウンドで終わるので**一度も撃てない**
- つまり塔で効くのは「倒れさせない」守り役だけで、「倒れたあと立て直す」回復役の出番が構造的に無い

## 罠: sim.run の seed が効いていなかった

`battle.start` は `cfg.seed` を読まない。`sim.run` も乱数源へ渡していなかったので、
seed を指定しても Math.random のままだった。同じ条件・同じ seed の32回が
15/32・19/32・22/32 とぶれた。`sim.run` で `RPG.rng.seed(o.seed)` を呼ぶよう直した。
**2026-11-04 以前の「前後比較」は乱数を止めていない。** 差が数ポイントの結論は測り直す価値がある。
