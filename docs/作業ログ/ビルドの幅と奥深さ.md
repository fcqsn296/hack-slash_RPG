## 1周目の実測（決定的な seed、48回、推奨Lv・主人公＋LEGEND3人）

耐性パッケージ（置き換え）: lean = 精神耐性3＋万象の胆力2（12SP、持続 -5）、
full = lean＋気丈4（20SP）。基準 base は耐性ノードを禁止して同じSPを他へ。

| | base | lean | full |
|---|---|---|---|
| 通常 深淵 | 39/48 14R 40% | 39/48 13R 46% | 38/48 |
| 蝕む 深淵 | **26/48** 15R 11% | **46/48** 13R 51% | 35/48 |
| 蝕む 創世 | 47/48 | 48/48 | 40/48 |
| 蝕む 灰燼 | 48/48 67% | 48/48 68% | 48/48 |

- 通常フィールドで味方を完全免疫にしても、勝率もラウンドもほぼ動かない（戦闘が短い）
- 蝕む相は「敵が実際に削ってくる場所」（深淵）でだけ効く。灰燼・臨界では素通りに近い
  ——終盤の手応えの薄さ（保留中「終盤にオート用の張り合いが無い」）がそのまま出ている
- 報酬は既存の規則（要求された組み替えをすれば1ラウンドあたり素の約1.3倍）に従い 1.30。
  lean の勝ちR 13 ≒ 通常 base の 14
- 不動心系（full）は過剰。持続短縮で既に消せるところへ8SP足して火力を削るだけ

## 罠: sim.run の seed が効いていなかった

`battle.start` は `cfg.seed` を読まない。`sim.run` も乱数源へ渡していなかったので、
seed を指定しても Math.random のままだった。同じ条件・同じ seed の32回が
15/32・19/32・22/32 とぶれた。`sim.run` で `RPG.rng.seed(o.seed)` を呼ぶよう直した。
**2026-11-04 以前の「前後比較」は乱数を止めていない。** 差が数ポイントの結論は測り直す価値がある。
