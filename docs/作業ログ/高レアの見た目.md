# 最近のキャラが「モブに見える」問題

## 指摘

初期キャラと最近のキャラを並べると、**色使いと露出度で明確に差がある**。
高レアの女性キャラは露出度が高めというイメージがあるので、最近のものは
モブかNPCに見える。アクセサリーも多めのほうが高レアらしい。
エフェクトは今のままでよい。

## 実測

感覚で直すと再発するので、**実際に生成に使われたプロンプト**
（`tools/image_metadata_backup.json`）を数えた。

| 1体あたりの語数 | 初期29体 | 追加10体 |
|---|---|---|
| 露出の語 | **1.34** | **0.10** |
| 淡い色の語 | 0.38 | **2.60** |
| 装飾の語 | 0.45 | 1.20 |
| 鮮やかな色の語 | 0.76 | 1.50 |

**初期29体のうち25体に `revealing` が入っていた。私の10体は0。**
淡い色の語は6.8倍。指摘のとおりだった。

初期キャラ（`ch_lg_nox`）の実際のプロンプト:

```
skindentation, cleavage cutout, fantasy job, accessory, curvy, thick,
coverd nipple, revealing clothing, colorful costume, pantyhose, rating:general
```

**私はこの語彙を1つも書いていなかった。**

## 原因は土台の非対称

`base.enemy` には `gigantic breasts / thick thighs / skindentation` が入っている。
**`base.character` には身体も衣装も何も無い。**

初期キャラはそれを1体ずつ手で書いていたので揃っていた。
自動合成に寄せた最近の分だけが地味になった。

## 直したこと

### 1. レアリティごとの層を足した

`data/artprompts.js` に `rarityTags` を新設し、`novelai_gen.py` が
`data/` からレアリティを読んで土台の後ろに足す。

  LEGEND … revealing clothing, cleavage cutout, skindentation, colorful costume,
           ornate accessories, fantasy job, curvy, thick thighs,
           covered nipples, rating:general

**男性を名乗っているプロンプト（`1boy` / `male focus`）には付けない。**
主人公に掛かると破綻するため。組み立て後の実物で、
マリカには付き主人公には付かないことを確認した。

`base.character` に入れなかったのはこのため。レアリティは `data/` から
読めるので、組み立ての1か所で引くのがいちばん薄い。

### 2. 25人の個別プロンプトを書き直した

露出と装飾は土台が配るので、個別の仕事は**色と飾り**に絞った。

| | 前 | 後 |
|---|---|---|
| 淡い色の語 | 2.60 | **0.28** |
| 露出の語 | 0.10 | **2.92** |
| 装飾の語 | 1.20 | **3.08** |
| 鮮やかな色の語 | 1.50 | **4.04** |

道具（satchel / gourd）を飾り（ornate ~ / jeweled ~ / ear cuffs /
arm rings / hair ornaments）へ置き換えている。

### 3. スキルに書いた

`art-prompt-authoring` に節を足した。数字と、初期プロンプトの実物と、
「淡い色の語を先頭に置かない」を残してある。

## まだやっていないこと

**絵の再生成。** プロンプトを直しただけで、既に生成済みの10体の画像は
そのまま。撮り直しは指示があってから。
