# コンテンツの棚卸し

**目的**: 「厚みの足りない場所」「物足りない場所」を数えて洗い出す。**このドキュメントは修正しない。**
ブラウザは使っていない（同時に別担当がストーリーモードのテストプレイでセーブを使っているため）。
`data/*.js` を Node.js の `vm` に読み込ませ、実データを集計した（自分でセーブは触っていない）。

数字はすべて 2026-08-31 時点の `data/` から実測。既存 docs（`強いビルドの組み方.md` 等）の記述と
矛盾する箇所は、**実データを正**として扱い、その旨を明記する。

12分類の平均は27.9ノード / 261SP。**弱点コンボ軸は平均の1/7、最大の生存・防御軸の1/15しかない。**
`弱点コンボ` は `combo_gain`（連鎖の心得）`combo_keep`（執念）`combo_power`（2ノード）の
実質3種類の効果を4ノードに割り振っただけの軸。`強いビルドの組み方.md` にも
「コンボは手動戦闘でしか積めない」と説明があり、手動運用が前提の軸とはいえ、
選べるノードの絶対数がこれだけ少ないのは他の分類と並べると際立つ。

**系統タグ軸も13ノード/99SPと少ない。** ただしこちらは `強いビルドの組み方.md §3` の実測どおり、
最終的な倍率の大半（×20前後）を装備側が担っており、ツリー側は土台（×5.6程度）でよい設計
なので、単純な「薄い」に数えるのは早計。**軸の絶対数として少ないことは事実として記録する。**

### 1.3 登録されているのにノードが1個しかない効果

`data/effectkinds.js` の登録効果は139種。**ツリー336ノードだけで見ると57種（41%）が1ノードのみ。**
クラス（`data/classes.js` 全6クラス・167ノード）を合わせて数え直すと、**29種（21%）が
依然として1箇所のみ**（0ノードの効果は無い）。

```
auto_low_skill / solo_buff / self_buff_lock / stealth / chaos / combo_gain / combo_keep /
crit_overflow / element_adapt / element_pierce / evade / focus_power / relay_power /
cooldown_cut / high_hp_power / high_power_cap / hp_to_def / low_power_repeat / mid_power_cap /
mid_power_combo / mid_power_crit / mid_power_status / mono_element_power / neutral_power /
rainbow_power / status_on_hit / tag_all / weak_guard / weak_hunter
```

**注意**: この一覧には `tag_all`（三系統掌握）`element_adapt`（全属性適応）
`crit_overflow`（極点）など、`強いビルドの組み方.md` で**要となる強力ノード**として
名指しされているものが多数含まれる。「1個しかない＝弱い」ではなく「1個しかない＝
そのノードを取るか取らないかの二択で、育て方の選択肢がない」という意味。
依頼文の「実質選べない」はこの意味で成立している。効果としての強さとは別軸の話。

## 2. 技と装備の厚み

### 2.1 技の系統×威力帯×属性

そのままカウントに含めている）。帯は `拡張コンテンツの作り方.md` の定義に合わせ
**小技=100以下 / 中技=101〜199 / 大技=200以上**。

3系統 × 3帯 × 7属性 = 63マスのうち、**穴（0件）は15マス（24%）。**

### 2.2 装備ベース・ユニーク・セット

| | 数 |
|---|---:|
| 装備ベース | 12（武器5・防具3・装飾4） |
| 装備セット | 10（すべて2点/4点構成） |
| ユニーク装備 | 27 |

装備ベースは**防具・装飾が系統ごとに実質1択**（防具: 物理1・魔術1・遺物1／
装飾: 物理1・魔術1・遺物2）。武器だけ物理2・魔術2・遺物1で選択肢がある。
ベース自体の差は主ステータスの種類だけなので致命的ではないが、記録しておく。

**ユニーク装備27種のベース内訳が系統で大きく偏っている。**

| 系統 | ユニーク数 | 割合 |
|---|---:|---:|
| 物理（ロングソード0・グレートアクス1・プレート0・指輪1） | 2 | 7% |
| 魔術（ロッド0・魔導書1・ローブ1・護符3） | 5 | 19% |
| **遺物**（遺物の爪6・古代の鎖帷子4・遺物のコア6・封印の紋章4） | **20** | **74%** |

`強いビルドの組み方.md §6.3` の言うとおり「ユニークは系統タグを捨てる装備」なので数が多いこと
自体は強さと直結しないが、**物理特化ビルドで使えるユニークは実質2種類しかない**
（武器のグレートアクス用と装飾の指輪用が各1、防具ユニークはゼロ）。
物理ビルドの装備の個性は、ほぼ竜装備の副オプションだけで作ることになる。

### 2.3 副オプション（affixes）の穴

`data/equipment.js` の副オプションは全12種類。うち「技種別限定」（汎用の約1.8倍の値、
`拡張コンテンツの作り方.md §3.4`）は `af_tag_phys_only`（物理技限定）と
`af_tag_magi_only`（魔術技限定）の2つだけが存在し、**`af_tag_reli_only`（遺物技限定）に
相当する副オプションが無い。** 遺物ビルドは、物理・魔術ビルドが持つ「限定枠で汎用の1.8倍を
取りに行く」という強化ルートそのものが存在しない。2.1の穴と合わせて、**遺物系統は技・副
オプションの両方で選択肢が薄い**ことが数字で裏付けられる。

### 2.4 レアリティ分布（既存 docs との整合確認）

`data/boxes` は5種（銅・銀・金・竜・星辰）、`equipRarities` は4段階
（COMMON〜LEGEND、副オプション枠1→4・主ステータス倍率×1.00→×2.10）で、
`強いビルドの組み方.md §6.2` の記述と一致した。ここは薄くない。

## 3. コンテンツの量

### 3.1 フィールド・塔・闘技場

フィールドは実測 **12**（§0参照）。推奨Lv 1〜255まで階段状に並ぶ。

塔は7段階の `tier` を持つが、参照している `fieldId` は
`fl_plain / fl_mine / fl_nest / fl_ruins / fl_abyss / fl_ashfall / fl_origin` の7つだけ。
**12フィールド中5つ（fl_deep・fl_sealed・fl_verge・fl_beyond・fl_endless、42%）は
塔に一切出てこない。** 新規の敵は追加されておらず、既存フィールドの敵構成を流用して
`scalePerFloor` で強くしているだけの構造（データ量としては軽い）。

闘技場はボス7体（それぞれ通常/ハードで実質14戦）。**7体全員、既存フィールド・ボスの
使い回し**（例: `ar_null_sovereign` は `fl_origin` の `em_null_weaver`、
`ar_the_warden` は `fl_origin` のボス `bs_genesis_echo`）。新規の敵グラフィックは0で、
`gimmicks`（属性無効化・全体攻撃無効・多段無効化・ラウンド制限）というデータだけで
7通りの体験を作っている。これは「敵の種類が薄い」というより「意図して使い回している」
形なので、④の物足りない場所には数えない。

**遊べる時間の推定（根拠付き・粗い見積り）**

- Lv1→255に要る総経験値: `expToNext(L)=floor(60×L^1.45)` を1〜254で積算すると
  **19,182,996**（`src/core/units.js` の式から計算。実測ではなく式からの算出）
- 作業ログ「終盤の狩場」の実測: 1レベルに要る周回数は**2.8〜14周**（`test/balance.html` の
  検査基準）。これはレベル帯によって変わり、ゲーム全体を通した平均は測っていない（**未確認**）
- 上記の周回数レンジと、`強いビルドの組み方.md §9` のラウンド数実測（1戦あたり平均
  1.2〜10ラウンド帯）をそのまま掛け合わせると、Lv1→255の総プレイ時間は
  **数十〜百時間規模**になる計算だが、レベル帯ごとの周回数を実測していないため、
  時間の一点推定は**未確認**として書くに留める。数値の芯は上の2点（総経験値・周回数レンジ）。

塔・闘技場はレベル上げの終着点にある「腕試し」枠で、周回そのものの主戦場ではない
（`data/arena.js` 冒頭コメントに明記）。時間としては「フィールド周回で育ててから挑む」ため、
フィールド周回時間に内包される形になり、単独の時間換算はしていない（**未確認**）。

## 4. 物足りない場所（重い順）

数字の再掲のみ。詳細は各節を参照。`docs/保留中のアイデア.md` に重なるものは無かった
（弱点コンボ・遺物の技/副オプション・クエスト分布・防具装飾のベース種は、
いずれも保留中のアイデアには挙がっていない）。

1. **弱点コンボ軸がツリー全336ノード中4ノード（32SP）しかない。**
   12分類の平均27.9ノードの1/7、最大の生存・防御61ノードの1/15。（§1.2）

2. **[遺物]技は威力帯×属性の21マス中9マス（43%）が空。** 物理・魔術は各3マス（14%）
   しか空いておらず、遺物だけ突出して選択肢が狭い。加えて「技種別限定」の高倍率
   副オプションが物理・魔術用にはあるのに遺物用（`af_tag_reli_only`相当）が存在しない。（§2.1, §2.3）

3. **ユニーク装備27種のうち20種（74%）が遺物ベースに集中し、物理は2種（7%）しかない。**
   物理特化ビルドは武器・装飾の各1種以外にユニークの選択肢が無く、防具ユニークはゼロ。（§2.2）

4. **クエスト15件が12フィールド中8フィールドにしか無く、4フィールド（33%）はゼロ。**
   fl_nestだけ4件で残りは0〜1件という偏り。fl_deep・fl_sealedは中間帯にありながら未着手。（§3.4）

5. **ストーリー第二章が3シーン・582字と、前後の章（8シーン1,578字／6シーン1,555字）の
   半分以下。** 物語全体でも3,715字しかなく、Lv7以降249レベル分の周回コンテンツの厚みと
