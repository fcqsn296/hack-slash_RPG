# 正義 XI — 実装と測定

実装済み。検証テスト 1666/1666 合格（正義27件＋皇帝の入力数え1件）。
仕様は `docs/正義の実装案.md`。**上限の増やし方だけ仕様から変えた**（下の「上限の式」）。

## 実装したもの

> 利: 敵の裁きを耐えた一撃は、ダメージ上限が上がる（上限で削られた値を最大 +100%）
> 害: 攻撃する前に、対象から使用可能な最強の攻撃を受ける

- 効果種 `justice`（値 1.0）を1つ。値が 0 より大きいことが「応撃を受ける」旗も兼ねる。
  利と害が同じ旗から出るので、利だけ持つ状態が作れない
- 差し込み口は `performAction`。入力の集計とクールダウンの後、**麻痺の抽選より前**
  （応撃で受けた麻痺も、この手番の抽選1回で効く）
- 応撃は `executeSkill(敵, 最強技, [本人])` を1回だけ。敵フェーズは呼ばない。
  敵の通常手番は減らず、闘技場のボスでも `actionsPerRound` 回ぶんは呼ばない
- **`isCounter` にしない。** 普通の攻撃として通すので、本人の反撃・棘・反射がそのまま働く。
  応撃は performAction を通らないので、応撃から応撃は起きない
- 最強の技 = `autoplay.estimate`（乱数1.0・会心なし）で本人への見積もりが最大のもの。
  選ぶだけでは乱数を消費しない。同点は技IDの順
- 敵の技には CT が無く、`enemiesAct` は持ち技から無作為に引くだけ。
  「使用可能」は**持っている攻撃技すべて**。正義のために敵の規則は変えていない
- 結果は4つ: 技が無い・敵が麻痺 → 応撃なし（強化なし）／耐えた → 強化して撃つ
  （回避・障壁で防いでも「耐えた」）／本人が倒れた・相手が先に倒れた → 撃たない
- 全体技は**主対象1体だけ**が応撃する。画面は `battle.pickKind` を読み、
  正義持ちの全体技でだけ「先に裁きを受ける敵を選ぶ」を出す。オートは先頭の敵
- 主対象は技そのものへ渡さない（渡すと「執着」が全体技で積み上がる）
- あまねく相では応撃も全員へ届く（仕様の初版候補どおり）
- 皇帝に命令された正義も応撃を受ける

## 上限の式 — 壁を広げても効かなかった

**節制と同じ「壁を (1+X) 倍」で書いて測ったら、ほとんど効かなかった。**

終盤セーブの主人公（黄昏）を闘技場で1発:

| 上限の強化 | 一撃 |
|---|---|
| なし | 21.0M |
| 壁を +200% | 24.5M（×1.17） |

素点が上限の約12倍ある（闘気・号令・累撃が乗る）。上限の先は ×0.1 なので、
一撃の大半が壁の先の部分になり、壁を動かしても小さくしか伸びない。
壁だけで倍にするには +1000% 級が要り、それは破壊者の「上限の外に出る」(§12) に踏み込む。

次に「曲線ごと (1+X) 倍に拡大」`(1+X)·cap(raw/(1+X))` を書いた。**数値が1桁も動かなかった。**
展開すると壁を広げるのと同じ式になる（減衰の傾き 0.1 は拡大しても変わらない）。

採った形: **上限で削られた後の値を (1+X) 倍、ただし素点は超えない。**

```
capped = min(raw, cap(raw) × (1 + X))    （上限に当たっていないときは何もしない）
```

- 上限に届かない一撃 … ×1.0（札の文面「上限が上がる」どおり）
- 少し越えた一撃 … 素点まで（=その一撃から上限が消える）
- 深く越えた一撃 … ×(1+X) に近づく
- 上限を無視する技（終焉の一撃）… 何も足さない（仕様「余分な利益を新設しない」）

## 測定（終盤セーブ `_scratch/save_20260920.json`、主人公に装備、20試行）

主人公: HP 9,620・軽減50%・反撃15%・破壊者。アストラ・ルーメンは守りへ振り直し（PRI）。

### まず応撃だけ（上限強化ゼロ）

| 場 | 素 | 正義(+0%) |
|---|---|---|
| 周回（相なし） | 5.00R・主人公が倒れる戦 0% | 5.00R・**20%**（応撃4.8回・不発1.1回、うち倒れた0.2／相手が先に倒れた0.9） |
| 先制＋あまねく | 5.00R・30% | 5.00R・**90%**（応撃が全員へ届く） |
| 敵HP×3000 | 6.50R | **6.10R**（速くなった） |
| 闘技場ハード（終刻） | 4.05R | 4.05R・応撃10.2回を全部耐える |

応撃だけで速くなったのは、主人公の「返す刃」（反撃15%）が応撃のたびに起きるため。
仕様の「反撃・棘型には被弾の機会が利益」がそのまま出ている。

### 上限強化を振る（主人公）

| | 素 | +0% | +50% | +100% |
|---|---|---|---|---|
| 敵HP×3000 | 6.50R | 6.10R | 5.50R | **5.25R** |
| 先制＋あまねく×1000 | 5.20R／100% | 5.32R／95% | 5.16R／95% | **5.11R／95%** |

→ **+100% に決めた。** 利の天井を「上限に当たる一撃だけ ×2」に置くと、
吊るされた男（×2.7〜3.3帯）・死の最後の一撃（×3.17）より下に収まる。
代償（毎回、最強の一撃を先に受ける）が周回では軽く、相を重ねると重い——という向きも札の像に合う。

### 闘技場は物差しにならない

- 実戦では1ラウンドの床（終刻は1ラウンドあたりの傷に上限）
- 敵を倒せなくして6ラウンドの与ダメを見ると、+100% でも主人公は +7% だけ。
  主人公の与ダメの大半が破壊者の終焉の一撃（上限無視、1発 68.5B）で、正義はそこに足さない
- 千葬の守り手・闘技場の主では主人公が倒れる戦が増えた（7/10 → 10/10 など）

### 型ごとの結果

| 型 | 結果 |
|---|---|
| 既存攻撃型（主人公） | 上記。上限を越える一撃を持つので利が出る |
| 既存耐久型（アストラ） | 応撃を全部耐える。だが一撃が上限の0.2〜0.4倍しか無く、**利がゼロ** |
| 反射・棘型（ミレーヌ、棘0.29） | ほぼ攻撃しないので応撃が起きない。闘技場で応撃14.8回、与ダメは変わらず |
| 耐久へ置き換えた攻撃型 | 下の表。**攻撃を削って守りへ回した損を、正義が取り返す** |

→ **上限を越える一撃を持ち、かつ耐えられる型だけが得をする。** 札の像どおり。

### 攻撃を守りへ置き換えた型

主人公は元から「守りを火力へ変える」型（DEF・軽減・対ボス軽減を振り切り、def_to_atk と atk_to_def で鏡写し）で、
最大HPだけを取っていなかった。そこで**信仰・魔術の系統タグ（23SP）を外して最大HPへ回した**。
黄昏は信仰系統なので、本当に火力を失う置き換えになっている（素点／上限 4.6 → 3.0、HP 9,620 → 15,863）。

| | 元・素 | 元・正義 | 置換・素 | 置換・正義 |
|---|---|---|---|---|
| 敵HP×3000 | 6.50R | 5.25R | 8.00R | **5.55R** |
| 先制＋あまねく（主人公が倒れる戦） | 30% | 90% | 5% | **45%** |
| 先制＋あまねく×1000 | 5.20R／100% | 5.11R／95% | 5.50R／100% | **5.25R／100%** |

置き換えだけでは 6.50R → 8.00R と遅くなるが、正義を着けると 5.55R まで戻り、
しかも相つきで落ちにくくなる（勝率 95% → 100%）。**守りへの投資を攻撃力へ転換する役割が成立している。**
（最初に「守りを先に全部振り直す」形で測ったら、ツリーが黄昏の枝へ届かず攻撃の核が消えて 34R になった。
置き換えは、使っている枝を残して行うこと）

### 既存の札との比較（元の攻撃型、主人公に装備、20試行）

| 札 | 敵HP×3000 | 先制＋あまねく×1000 |
|---|---|---|
| 力 | 5.75R | 14.69R／80% |
| 吊るされた男 | 6.40R | 5.90R／100% |
| 死 | 負け（終止符） | 25.75R |

## ついでに直したもの — 皇帝の入力が2回数えられていた

`commandDecree` は入力を数えてから `performAction(..., null)` を呼び、
「null を渡せば数えない」とコメントしていた。**実際は performAction が null を手動1回と数えていた。**
命令1回が2回と数えられ、オートの命令まで手動に数えられていた（§10.1 手動ボーナスが歪む）。
`{ counted: true }` で明示するように直し、検査を足した。

## 残したこと

- 置き換えの測定は主人公1通りだけ。一撃が上限に届かない型（アストラ）は利がゼロのまま
- オートは応撃の危険を考えない（仕様「初期実測後に判断」）。周回では勝率が落ちなかったので足していない
