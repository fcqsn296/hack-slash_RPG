# 狭い画面でビルド画面が長すぎる

## 何が起きていたか

縦1列に落ちる幅（860px以下）では、スキルツリーに辿り着くまでの高さが積み上がっていた。
実測（41人所持・Lv255・クラス就任済み）:

| | 高さ |
|---|---|
| キャラクター一覧 | 2,979 px |
| クラスパネル | 4,369 px |
| **ツリーまでの合計** | **8,627 px** |

画面（812px）にして10枚ぶん。ビルドを触るたびにここを通ることになる。
装備画面もキャラクター一覧を共有しているので同じ。

## 直したこと

### キャラクター一覧を畳む（狭い画面だけ）

選んでいる1人だけを1行で出し、押すと一覧が開く。**選ぶと自動で閉じる**
（選んだ先を見たいのに、一覧が居座っては意味が無い）。

広い画面では左右に並ぶので畳む理由が無い。出し分けはCSSに任せ、
JS側は常に両方を組み立てておく。

### クラスパネルを畳む（既定で閉じる）

共通枝＋派生3つを全部並べると、この1枚だけで4,369px ある。

畳んでも「やることがある」ことは分かる。**見出しに残りCPを出したまま**に
してあるので、振れるポイントがあれば数字で目に入る。
スキルツリーの分類を既定で畳んでいるのと同じ考え方。

一度は「残りCPがあるときだけ開く」形にしたが、Lv255で未消費なら常に開くので
ほとんど畳まれない。それでは直したことにならないので、既定で閉じる形にした。

## 結果

| | 前 | 後 |
|---|---|---|
| ツリーまでの高さ | 8,627 px | **1,273 px** |
| ページ全体 | 9,808 px | **2,454 px** |

広い画面（1280px）では左右2列・一覧は常時表示のまま変わらない。
横溢れ 0px。検証テスト 1219/1219。
