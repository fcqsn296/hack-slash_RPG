# 1ラウンドに認める傷の上限

**ブランチ**: `work/arena-rest`
**日付**: 2026-08-25

## 何を解いたか

闘技場ハードが速すぎて、クラス技（解禁2〜4ラウンド目）が動かない。
HPを盛るだけでは上振れが止まらず、多段特化ビルドが最短2ラウンドで沈めていた。

`maxRoundDamageRatio`（1ラウンドに最大HPの◯%までしか受けない）を入れる。

## 前回の失敗と、その原因

**5回作り直してなお漏れた。** HPを減らす道が10箇所あり、個別に塞ぐと必ず残る。

```
applyDamage の中で抑える → 漏れる
手番の終わりに床を強制する → 漏れる
決着判定の入口でも強制する → 漏れる
```

**解決は集約だった。** `hurt(battle, unit, amount)` を1つ作り、
HPを減らす経路を全部そこに通した。

| 通した経路 |
|---|
| 通常ダメージ / 出血 / 残響 / 波及 / 棘 / 反射 / 継続ダメージ / `directDamage` |

味方側の「庇う」「肩代わり」は闘技場ボスに関係しないので通していない。

集約後、`RPG.arena.start()` の本来の経路で8戦回して**上限超過ゼロ**。

## 切り捨てから繰り越しへ

最初は溢れた分を捨てていた。これは**大きく殴るほど損**になる。

```
一撃型: 40M の一撃 → 30M に切られ 10M が消える（25%の損失）
多段型: 50万 × 64発 → 30M をぴったり埋める（損失ゼロ）
```

上限は「速すぎる決着を止める」ためのもので、一撃型と中技を潰すためのものではない。
**溢れた分は次のラウンドへ繰り越す**形にした。
総量はどの型でも変わらず、「何ラウンドかかるか」だけが揃う。

繰り越しは `arenaRoundTick` で新しい予算から先に払う。
払いきれなければまた繰り越されるので、何ラウンドでも正しく分割される。

## 効き（終刻の審判者ハード / 実データ・10戦×4構成）

| 型 | 勝率 | 平均R | 最短R | クラス技/戦闘 |
|---|---|---|---|---|
| 実セーブそのまま | 90% | 5.4 | 5 | 1.0 |
| 多段特化 | 90% | 5.0 | 4 | 1.1 |
| 一撃型 | 90% | 5.7 | 5 | 0.9 |
| 中技型 | 90% | 5.7 | 5 | 0.9 |

**4つの型がすべて5ラウンド前後に揃った。** どの型も損をしていない。
クラス技は 0.17〜0.21回 だったものが 0.9〜1.1回 になり、
反射・棘・バフ・コンボも動く長さになった。

多段特化がわずかに速い（5.0R）のは正しい姿で、
特化した投資は報われつつ、床が保証されている。

## 闘技場の主だけHPで立ちはだかる

塔を除けば最強の相手なので、ここは「攻略不能に見えてよい」場所。
終刻(1億5千万)より重くして、序列を数字でも示す。HP 1,555万 → **2億**（hpMult 12.86）。

**`maxRoundDamageRatio` は付けていない。** 1ラウンドの上限は
「刻を数えるもの」という終刻のコンセプトに紐付いた仕掛けで、
他のボスに配ると**適当に殴っていたら時限で死ぬ相手**にしか見えなくなる。
闘技場の主は全ギミック持ちなので、素直にHPで立ちはだかるほうが筋が通る。

# 虹を喰らう獣: 吸収を割合にする (§17.4)

## 方針

有利属性を**全部**喰われると、その道が完全に閉じる。
割合にしておけば「損だが通る」ので、極まったビルドなら強引に押し切れる余地が残る。

`elementAbsorbRatio` を導入（既定 1 ＝従来どおり）。ハードで **0.8**。
有利(1.5倍)で殴っても実効0.3倍なので、普通は等倍で殴るほうが得。

満タンのときも吸収そのものは効くよう、**通す量と吸収する量を分けて**数えている。
（回復は減っているぶんまでしか乗らないので、
　「全部回復に化ける」形だと満タン時に素通りしてしまう）

## 途中で塞いだ穴: 属性変換で吸収を回避できていた

`rawAdvantage` が `skill.element` しか見ていなかった。
`element_convert` で闇に染めると、**有利倍率(1.5倍)は得たまま吸収だけ回避**できる。
実測で吸収0だった。

`damage.js` が実際に使う攻撃属性（`mods.convert || skill.element`）と揃えた。
適応や極意は「倍率」を動かすだけで属性そのものは変えないので、
元のコメントにある「全属性適応で逃げ道が消える」問題は起きない。

## 効き（実データ・10戦、パーティ全員を染めた場合）

| 構成 | 吸収率 | 勝率 | 平均R | 吸収された量 |
|---|---|---|---|---|
| 全員=闇（有利） | 1.0（従来） | 40% | 5.5 | 7,780,358 |
| 全員=闇（有利） | **0.8** | 40% | **4.8** | 5,971,865 |
| 全員=無属性（等倍） | 0.8 | **60%** | 5.2 | 0 |

**等倍のほうが勝率が高い**（60% 対 40%）ので、素直に属性を変える判断は変わらない。
一方で有利属性でも 5.5R → 4.8R と前進し、押し切る道が開いた。

## エンバーは吸収に触れない

ボスは光属性で、有利を取るのは闇だけ。
エンバーの技は火と無属性なので**最初から関係がない**。
速いのは吸収を突破しているのではなく、対象外だから。

属性を合わせなければ吸収が関係ないのは仕様として自然だが、
「ギミックを無視できるキャラがいる」状態ではある。

## 体感の原因は「全属性適応2」だった

利用者が「ギミックが働いていない」と感じていた理由が判明した。

`damage.js:349` に

```js
if (mods.adapt >= 2) element = Math.max(element, ADVANTAGE);
```

とあり、**全属性適応2は全攻撃を有利化する**。ところが吸収の判定は素の属性表しか
見ていなかったので、適応2を取ると **有利倍率(1.5倍)は得たまま吸収だけ回避** できた。
実セーブはパーティ4人全員が適応2。

素の属性に限定していたのは「全部吸収されて逃げ道が消える（勝率0%）」ためだったが、
**吸収が割合(0.8)になった今は2割が通る**ので行き止まりにならない。前提が変わった。

`adapt >= 2` を有利として数えるようにした。

| 構成 | 勝率 | 平均R | 吸収された量 |
|---|---|---|---|
| 適応2あり（実セーブそのまま） | **60%** | **5.8** | **139,608,426** |
| 適応を外した | 90% | 2.9 | 1,042,414 |

修正前は 100% / 3.5R で素通りしていた。いまは吸収量がボスHPの5倍を超え、
ギミックが本来の働きをしている。

**適応を外せば 90% / 2.9R** なので「このボスには適応を切って挑む」という解答が生まれ、
かつ適応2のままでも勝率60%で押し切れるので行き止まりではない。

適応2は属性の悩みを丸ごと消す強力な枝なので、**それを咎える相手が1体いる**のは健全。
