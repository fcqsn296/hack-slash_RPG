## 固まったレシピ

画風の語は **`data/artprompts.js` の `rarityTags.LEGEND` に焼き付けてある**ので、
`--add` で足す必要はない。決めた経緯も同じ場所のコメントにある。

```bash
python tools/novelai_gen.py <ID> --count 6     # 通常
python tools/novelai_gen.py <ID> --count 10    # 体と交差する持ち物のとき
python tools/novelai_gen.py <ID> --dry-run     # 投げる前に必ず
```

### 守ること

- **個別プロンプトの先頭に `1girl` を書かない。** 書くと rarityTags が丸ごと落ちる
  （道具が警告を出す）
- **`deep shadows` などの陰影を強める語を入れない。** 明度が沈む
- **属性色は1箇所で足りる。** 髪・装備・装飾・エフェクトのどれか1つが強ければ伝わる。
  全部を属性色に寄せると表現の幅が狭くなる。例外は肩書きが属性の格を名乗るとき
- **胸は現行を基準に。** 分散は第二。無理に散らすと別人になる。
  技法は `art-prompt-authoring` スキルにまとめてある
- **体と交差する持ち物（鎖・弓・大型武器）は10枚。** 破綻はプロンプトで制御できないので
  数で対処する。単純な持ち物なら6枚
