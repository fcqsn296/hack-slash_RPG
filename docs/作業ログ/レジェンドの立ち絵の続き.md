# レジェンドの立ち絵を V5 で作り直す — 完了

**状態**: **45人すべて完了**。ブランチ `work/レジェンドの立ち絵をV5で作り直す` で作業し、main へ入れた。

## やったこと

NovelAI V5（`nai-diffusion-5-full`）で全レジェンドの立ち絵を作り直した。
V5 は**最初から透過で出せる**ので、髪の内側や武器の隙間のような
「外周と繋がっていない領域」を塗りつぶしでは抜けないという、
これまでの切り抜きが原理的に届かなかった問題が消えた。
そのぶんエフェクトとアクセサリーを盛れる。

生成と候補づくりは Sonnet のサブエージェントに任せ、**採否は依頼側が決める**分担で回した。
1回あたり5〜6人、候補は6枚（持ち物が体と交差するキャラは10枚）。

## 固まったレシピ

画風の語は **`data/artprompts.js` の `rarityTags.LEGEND` に焼き付けてある**ので
`--add` は要らない。決めた経緯も同じ場所のコメントにある。

- **個別プロンプトの先頭に `1girl` を書かない。** 書くと rarityTags が丸ごと落ちる
- **`deep shadows` などの陰影を強める語を入れない。** 明度が沈む
- **属性色は1箇所で足りる。** 全部を属性色に寄せると表現の幅が狭くなる。
  例外は肩書きが属性の格を名乗るとき
- **アポストロフィを書かない。** 所有格のためにダブルクォートを使うと
  パーサがそのキーを落とす（下記）
- 体と交差する持ち物は10枚、単純な持ち物なら6枚

## 途中で見つけて直した道具の穴

**① プロンプトのパーサがダブルクォートで黙って落ちる**（`tools/novelai_gen.py`）

シングルクォートの連結しか読んでいなかったので、`"gown's"` と1箇所書くだけで
**そのキー全体が抽出できず、警告も出さずに自動合成へフォールバック**していた。
絵は出てしまうので気づきにくい。両対応にしたうえ、
**読めなかったキーを警告する**ようにした。

**② 顔の確認枠を高さ基準で描いていた**

`face.size` は**幅**に対する割合（`src/ui/facecrop.js` の `applyRect`）。
`size × 画像高` で確かめていたため実際より4割広い枠を見ており、
**顔が端に寄る程度のズレを5人ぶん見落としかけた**。
`game-art-pipeline` スキルに書き足した。

## 顔の自動計測は当てにならない

明るく大きな塊が首の高さにあると頭として拾う。**11人中9人で外れた。**

| 誤認したもの | 例 |
|---|---|
| 掲げた／担いだ武器 | ノエルの長剣、ヴェロニカの大槌、ベルガの大鉈 |
| 頭に近い装飾 | マリカの後光、ベルガの肩の頭骨 |
| 大きな髪型 | フィオナのポニーテール、シャノンのフード |

**数値が中央に見えても外れていることがある**（マリカは x=0.499 のままだった）。
必ず切り抜きを描き、十字線を引いて、既に配信されている絵と並べて確かめる。

手で直したキャラには `data/characters.js` の `art` に
「再計測しても上書きしないこと」と理由が書いてある。
