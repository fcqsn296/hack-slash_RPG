### 1.4 訂正: 「防具ユニークはゼロ」は不正確

依頼文は「物理は2種(7%)のみで防具ユニークはゼロ」と書いていたが、これは
**防具全体がゼロという意味では読めない**（防具ユニークは `eq_robe`1 + `eq_relic_mail`4 = 5個あり、
ゼロではない）。§1.2 の表で数え直すと、**本当にユニークが0個のベースは3つ**:

- `eq_plate`（**物理防具**）— 防具の中で唯一のゼロ
- `eq_longsword`（物理武器）
- `eq_rod`（魔術武器）

依頼文の「防具ユニークはゼロ」は、正確には「**物理の防具（`eq_plate`）がゼロ**」の意味だったと
解釈できる（物理2種の内訳が武器1・装飾1だけで防具が0、という文脈）。魔術は他に4種（ローブ・護符3）
あるので、`eq_rod`単体が0でも「魔術が薄い」とまでは言えない。

**→ この読み直しに基づき、埋めるのは `eq_plate`（物理防具）と `eq_longsword`（物理武器）の2つに絞った。**
`eq_rod`（魔術武器）は魔術全体では薄くないため今回は埋めない（§4 参照）。

## 2. 足した装備

`docs/強いビルドの組み方.md §6.3`「ユニークは系統タグを捨てる装備」を踏まえ、
**タグ倍率は持たせず**、既存27種が1つも使っていない効果キー（`reflect`／`chain`+`chainPower`）を
新たに使うことで、役割が重ならないようにした。

### 2.1 返照の鎧（`uq_returning_wall`）

```
base: eq_plate（物理防具、初のユニーク）
stats: { def: 190, hp: 1350 }
effects: { reflect: 0.18, shieldRegen: 0.06 }
note: 受けたダメージの18%を反射／ラウンド終了時に最大HPの6%の障壁
```

**数値の決め方**:
- `stats`（def/hp）は、同じ「殴られてから効く」役割の既存防具ユニーク4種
  （衆目の甲 def120/hp1100、一騎の誓い def150/hp1100、不落の心臓 def260/hp1600、
  反響の外殻 def180/hp1400）と同じレンジに揃えた。中間よりやや高めの反響の外殻に近い値。
- `reflect` は既存27種のどれも使っていなかった軸。ツリー側の投資量
  （`tr_reflect` 中級8%×4段=32%、`tr_reflect_hi` 上級15%×3段=45%、合計で最大77%まで伸ばせる）
  と比べ、**単独の1段〜2段ぶん**に相当する0.18に置いた。ツリーを積み切った人の到達点を
  ユニーク単体で超えないようにするため。
- `shieldRegen` も既存未使用。ツリー側の最大値（基礎2.5%×4+中級4.5%×4=28%）や
  クラス技（最大15%程度）と比べ、1段ぶんよりやや上の0.06に置いた。

### 2.2 渡り刃（`uq_wandering_edge`）

```
base: eq_longsword（物理武器、初のユニーク）
stats: { atk: 190 }
effects: { chain: 0.22, chainPower: 0.35 }
note: 単体攻撃の余波が他の敵へ威力22%で及ぶ／その余波の威力+35%
```

**数値の決め方**:
- `stats`（atk単独）は、同じ「武器・単一ステータスのみ」の既存2種
  （破暁の一撃 atk190、巨躯断ち atk200）と同じレンジ。破暁の一撃と揃えた。
- `chain`/`chainPower` も既存27種のどれも使っていなかった軸。ツリー側の投資量
  （`tr_chain` 中〜上級13%×3段=39%、クラス技12%×2段=24%）と比べて0.22はその中間程度、
  `chainPower`（ツリー最大 0.12×4+0.2×4=1.28）に対して0.35は1/3程度に抑えた。

## 3. 実測（`test/balance.html` 相当。`RPG.balance` をブラウザコンソールから直接叩いた）

**方法**: Lv255・5凸・竜の宝箱+9で揃えたキャラの装備スロットを**1本だけ**対象のユニークに
差し替え、`RPG.rng.seed()` で同じ乱数系列に揃えて（装備ロールの個体差をそろえて）比較した。
`localStorage` には一切触れていない（`RPG.balance` 系のシミュレータは元々セーブデータを使わない設計）。

### 3.1 単発火力（Lv255・5凸・竜+9・weapon1本だけ差し替え、basicAttack）

| | ATK | 最大単発ダメージ |
|---|---:|---:|
| baseline（竜のみ、装飾なし） | 4,388 | 196,659 |
| 既存: 破暁の一撃 | 4,124（-6%） | 157,449（-20%） |
| 新規: 渡り刃 | 4,124（-6%） | 157,449（-20%） |
| 既存: 巨躯断ち | 4,134（-6%） | 157,831（-20%） |

**渡り刃は破暁の一撃と完全に同じ単発火力**（stats.atkを同じ190に揃えたため）。
`§6.3` の実測（装飾/武器を1枠あけると-8〜-15%）と近い落ち込み幅で、単発だけ見れば
既存ユニークと同じだけ「代償」を払っている。突出はしていない。

### 3.2 多数の敵と戦う場面（`fl_verge`・臨界の際、Lv225/0凸、3ウェーブ、hero1人ぶんの
実与ダメージ合計を`battle.events`から集計、25戦平均）

| weapon | hero合計ダメージ | うち渡り刃の余波ぶん | 勝率 |
|---|---:|---:|---:|
| baseline（竜のみ） | 2,425,252 | — | 100% |
| 新規: 渡り刃 | **2,491,571（+2.7%）** | 861,473 | 100% |
| 既存: 巨躯断ち | 2,348,947（-3.1%） | — | 100% |
| 既存: 万手の刃 | 2,131,674（-12.1%） | — | 100% |

単発では-20%の代償を払っているのに、**複数の敵がいる場面では余波（chain）ぶんで
baselineを上回る**。同じ場面で巨躯断ち（ボス特化）・万手の刃（小技特化）は
むしろbaselineを下回る——「向いていない場面のユニークは竜に負ける」という
`§6.3`の設計意図どおりの並びになっている。突出した強さではない。

### 3.3 耐久・反射の場面（`fl_beyond`・還らぬ位相、Lv200/0凸、1ウェーブボス戦、
armor1本だけ差し替え、25戦平均。8〜9ラウンドかかる厳しめの戦いを選んだ）

| armor | 勝率 | 平均ラウンド | 反射ダメージ | hero被ダメージ | heroの戦闘不能率 | HP残り% |
|---|---:|---:|---:|---:|---:|---:|
| baseline（竜のみ） | 92% | 8.72 | 0 | 30,081 | 16% | 75.9% |
| 新規: 返照の鎧 | 92% | 7.92 | 93,682 | 20,018 | **8%** | 79.3% |
| 既存: 不落の心臓 | **100%** | 8.40 | 0 | 36,942 | 8% | **86.2%** |
| 既存: 反響の外殻 | 84% | 9.36 | 0 | 33,473 | 24% | 70.5% |

返照の鎧はbaselineより明確に安定する（戦闘不能率が半減、決着も0.8ラウンド早い）が、
`stats`が最も高い不落の心臓（def260/hp1600、3効果構成）には及ばない。反響の外殻
（オート戦闘だと怒りの解放タイミングを活かせず、baselineより悪化）よりは安定している。
**baselineと最強格（不落の心臓）のあいだに収まっており、突出していない。**

## 4. 埋めなかった穴

- **`eq_rod`（魔術武器）のユニークが0個。** §1.4のとおり、魔術は他に4種
  （ローブ1・護符3）あり系統全体としては薄くない。「防具ユニークがゼロ」→
  「物理タグが2種だけ」という依頼文の優先順位のうち、物理側の2つ
  （`eq_plate`・`eq_longsword`）を埋めることを優先し、`eq_rod`は今回は見送った。
- 系統タグ側で言えば魔術は19%→変わらず、物理は7%→4/29=**約14%**まで改善。
  依頼文にあった「防具ユニークがゼロ」の実体である`eq_plate`のゼロは解消した。
