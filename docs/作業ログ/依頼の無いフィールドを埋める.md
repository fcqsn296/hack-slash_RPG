# 依頼の無いフィールドを埋める（拡張ロードマップ D1・D2）

**ブランチ**: `work/深層と封印帯の依頼`
**開始**: 2026-09-10

## 何をしたか

依頼を1件も持っていないフィールドが2つ残っていた。

| フィールド | 推奨 | 状態 |
|---|---|---|
| 封絶の浅層 `fl_deep` | 20 | 依頼なし → **門の数え** |
| 封絶区画 `fl_sealed` | 130 | 依頼なし → **渡す相手** |

残る空きは還らぬ位相 `fl_beyond`（推奨250）だけ。
検証テストに「依頼の無いフィールドが増えていない」を足して、
これ以上増えたら落ちるようにしてある。

## 縛りは憶測で決めず、失敗率で選んだ

「何を問う依頼にするか」を先に決めてから測ると、成立しない案に時間を使う。
先に**どの縛りなら合否が割れるか**を測り、割れた軸だけを採った。

### 封絶の浅層（Lv20 相当・青銅40と白銀16の箱を開けて自動装備）

| 人数 | 勝率 | 誰か倒れた率 | ラウンド |
|---|---:|---:|---|
| 4人 | 100% | 4% | 7〜15R 中央11 |
| 3人 | 100% | 0% | 7〜21R 中央14 |
| **2人** | **88%** | **25%** | 17〜58R 中央30 |
| 1人 | 0% | 96% | —— |

崖は2人と1人のあいだ。2人が「通るが張り詰める」線だった。

### 封絶区画（Lv130 相当・黄金40と竜鱗24の箱を開けて自動装備）

人数以外は**どれも壁にならなかった**。

| 試した縛り | 結果 |
|---|---|
| 敵レベル Lv150 / 180 / 210 / 240 / 255 | すべて勝率100%（6〜10R） |
| 属性単色（7属性すべて） | すべて勝率100% |
| 敵ATK ×2 / ×3 / ×4 | 勝率100%（楯と癒しを含む編成なら無傷100%） |
| 人数 4人 / 3人 / 2人 | すべて勝率100% |
| **人数 1人** | **勝率0%（汎用の振り方）** |

Lv130 のパーティ4人は Lv255 の敵にも無傷で勝つ。
**この帯では人数を削る以外に問いが立たない。**

## 捨てた案 —「防御を上げて防御無視を学ばせる」

ロードマップの D1 は「到達時に使える育成・装備を1つ学べる依頼」と書いてあったので、
`enemyScale` の `def` だけを上げ、貫きの型（初級3SP・穿孔弾を習得）を答えにしようとした。

**成立しなかった。** 被ダメ倍率は `1 - DEF/(DEF+C)` で頭打ちになるので、
倍率を上げても壁にならない。

| 敵のDEF | 貫き0人 | 貫き1人 | 貫き2人 |
|---|---|---|---|
| ×10 | 9〜22R 中央15 | 8〜16R 中央13 | 9〜17R 中央13 |
| ×15 | 9〜21R 中央15 | 8〜17R 中央12 | 9〜19R 中央14 |
| ×22 | 13〜22R 中央17 | 10〜21R 中央13 | 11〜17R 中央14 |

中央値は動くが**分布が完全に重なる**。Lv20 では装備の引きのほうが
3SPの枝より大きく、合否が運で決まる。そこへ `maxRounds` を置いても
「学べる依頼」ではなく「引きの良い日だけ通る依頼」になる。

`def` を上げる案は、DEF が逓減する式である以上どの帯でも同じ壁に当たる。
**やるなら防御ではなく、防御を無視できない別の仕掛けが要る。**

## 入れた2件（依頼として40試行・オート）

### 門の数え（`q_gate_count` / fl_deep / Lv20 / ちょうど2人）

| 相棒 | 達成率 | ラウンド |
|---|---:|---|
| シャルロッテ (RARE) | 93% | 14〜47R 中央27 |
| ブランカ (COMMON) | 75% | 14〜38R 中央27 |
| イージス (LEGEND) | 100% | 6〜16R 中央11 |

誰を連れても通るが、**不落の楯姫(Lv10)で配った楯がそのまま答えになる**。
落ちるときは全部が全滅で、時間切れは0件——何が足りないかが分かる。

### 渡す相手（`q_one_to_receive` / fl_sealed / Lv130 / 1人以下）

主人公は編成から外せないので、これは「主人公ひとり」を意味する。
担い手を選べる縛りではなく、**主人公の振り方の検査**になる。

| | 達成率 | ラウンド |
|---|---:|---|
| Lv130・汎用の振り方 | **8%** | 34〜45R（全滅） |
| Lv130・狙って組んだ振り方 | **88%** | 5〜6R |
| Lv150・狙って組んだ振り方 | 98% | 5〜6R |

同じレベル・同じ装備でも、振り方だけで 8% と 88% に割れる。
解放レベルちょうどでは実力を問われ、20レベル上げれば甘くても通る。

**計測はすべてオート。手動ならこれより上に出るので、上の数字は下限。**

## 決めたこと

- **どちらもオートを禁じない。** 問うているのは編成と育成であって段取りではない。
  Lv20 帯には既に手動前提の依頼が3件ある
- **`allAlive` は使わなかった。** 不倒の陣(Lv150・創世の残響)が隣の帯で
  同じことを問うている。2件目は意味を持たない
- **`autoCharge` は付けなかった。** 配れる合計が 99 で頭打ち100 に対して
  余裕が1しかない（検証テストが数えている）

## 残っていること

- 還らぬ位相 `fl_beyond`（推奨250）に依頼が無い。何を問う場所かを決めていない
- ロードマップ D3（第二章の補強）は未着手。文章仕事なので単独で行う
