# 多段と一撃の釣り合い（双撃の理を選択式にできるか）

ブランチ `work/支援の価値`。**まだゲームのファイルは変えていない。測っただけ。**

## 発端

手数（双撃の理＋双月の環×2）が全型に 2.4〜3.1倍 効き、**事実上の必須**になっている。
「双撃の理と排他の、上限突破＋火力上昇のパッシブを置いて選択式にする」案を測った。

## 測り方

ヴァルキュリア（大技型）・Lv255・同じSP（254）・同じ装備の骨格。
HPだけ2億にしたボス（DEFは素）へ当てて決着ラウンド。耐久は切り離し。
オート・6試行の中央値。

基準は **大技＋手数 = 16R**、**大技のみ = 49R**。

## 結果1: 上限突破だけでは全く届かない

| 一撃側に与えたもの | 決着R |
|---|---:|
| 上限突破 +2 / ATK +30% | 43R |
| 上限突破 +8 / ATK +50% | 35R |
| 上限突破 +12 / ATK +100% | 31R |

**上限突破は単独では効かない。** 内訳を見ると `capped = false`——
そもそも上限に一度も当たっていなかった。
`強いビルドの組み方.md` §8.1「上限に当たっていないのに上限突破を積む」を、
測っている側が踏んだ形。

## 結果2: 火力だけでも届かない

| 一撃側に与えたもの | 決着R |
|---|---:|
| 大技の火力 +100% | 42R |
| 大技の火力 +200% | 37R |
| 大技の火力 +300% | 34R |
| 大技の火力 +400% | 30R |

伸びが鈍い。火力を上げると今度は上限に当たり、**超過分は0.1倍に潰される**ため。

## 結果3: 組で振ると釣り合う

| 火力 | 上限突破 | 決着R |
|---:|---:|---:|
| +200% | +4 | 35R |
| +300% | +6 | 28R |
| +400% | +8 | 25R |
| +500% | +10 | 21R |
| +600% | +12 | 22R |
| **+800%** | **+16** | **16R** ← 多段と同じ |

**火力と上限突破は組でしか効かない。** 片方だけでは、上限に当たっていないか、
当たりすぎて潰されるかのどちらかになる。これはご提案どおりの構造だった。

## 分かったこと

多段が強いのは、**上限の下で回数を増やすから**。
1発を大きくする側は上限という壁に当たり、超えたぶんが1割に減らされる。
だから対抗するには「火力」と「壁を押し広げる」を同時に積む必要がある。

釣り合いの点は **火力+800% ／ 上限突破+16**。
双撃の理（8SP・ATK -30%）1本と釣り合わせるには、この数字が要る。

## ここから先は設計の判断

数字は出たが、そのまま置くと**文言が異様**になる
（「大技の火力+800%、上限突破+16」）。取れる道は2つある。

### 案A 一撃側を釣り合う値で置く

提案どおり、双撃の理と排他のノードを新設する。
- 必要な値: 火力+800% ／ 上限突破+16 前後
- 排他の仕組みがツリーに無いので足す必要がある
  （`canInvest` は段位とSPしか見ていない。`excludes` を足す）
- **注意**: 双撃の理だけを排他にしても、双月の環×2 で多段は積める。
  「多段そのものを受け付けない」形にしないと選択にならない
  （支援の【極】が使っている遮断フラグと同じ作り）

### 案B 多段の側を軽くする

上限の下で回数が丸ごと効く、という構造そのものを緩める。
- 双撃の理の代償を重くする（いまは ATK -30%）
- あるいは多段の2発目以降に減衰を入れる
- **既に取っている人の強さが下がる**ので、影響は案Aより広い
