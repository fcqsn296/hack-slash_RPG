# 5軸のレジェンド15人の立ち絵

## 生成

新しいプロンプト（レア層＋書き直した個別）で **1体4案ずつ、計60枚**。
逐次1件ずつ、10秒間隔。4体ずつに分けて流した。

選定は一覧画像を作って目で見た。基準は3つ。

1. **役割が絵で読めるか** — 盾持ちなら盾が見えているか、灯なら灯が大きいか
2. **装飾の量** — 高レアらしさは飾りの密度で決まる
3. **他51体との差** — 似た silhouette が既にいないか

| | 採用案 | 理由 |
|---|---|---|
| マリカ | 4 | 光輪が眼の意匠。ただの輪ではないぶん見分けが付く |
| ネヴィア | 4 | 青い炎の灯が最も大きい。識別子そのもの |
| アガタ | 3 | 紫の発光が入り、ただの修道服から離れる |
| ガーネット | 3 | 金の円盾を掲げている。盾が読める唯一の案 |
| ルクレツィア | 1 | 甲冑＋発光する装飾剣＋外套。鉄の血脈に一番近い |
| ヨハンナ | 4 | 冠状の頭飾りと両手の香炉鎖。装飾が最も多い |
| エコー | 3 | 双刃を左右に広げた形。反撃が読める |
| ブリギッタ | 3 | 金の三つ編みと開いた両手。1案の光球は概念違い |
| ヴェロニカ | 3 | 棘付き棍を掲げ、小さな冠 |
| オルガ | 3 | 炎の髪と腕を広げた挑発。名乗りそのもの |
| シャノン | 1 | 紫のグラデーションが入った外套。影が最も深い |
| フィオナ | 3 | 細剣と流れる髪。紙一重の身軽さ |
| ベルガ | 3 | 巨大な刃を肩に担ぐ。silhouette が最も強い |
| イルマ | 4 | 金の装甲が最も厚く、剣を地に突いている |
| ターニャ | 2 | 腰の宝珠が最も大きく、裾が流れる |

## 顔の位置で3体を手直しした

自動計測と「頭部の塊」を突き合わせたところ、3体で 0.04 以上ずれていた。

| | 自動 | 実際 | 何を拾っていたか |
|---|---|---|---|
| ヴェロニカ | 0.651 | **0.500** | 掲げた棘付き棍を頭と誤認 |
| オルガ | 0.578 | **0.519** | 右へ伸びる炎の髪 |
| ベルガ | 0.635 | **0.560** | 肩に担いだ大刃 |

**ヴェロニカは頭部の塊のほうも 0.752 とさらに外していた。** 掲げた棍が
頭の高さにあるので、上端から測る方法自体が効かない。切り抜いて目で見て決めた。

「大道具が斜めに伸びる絵は自動計測がずれる」は前から分かっていたが、
**頭より高い位置に大道具があると、代わりの測り方も効かない**のは今回の追加。
