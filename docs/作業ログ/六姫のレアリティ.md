# セレナ・カグラをレジェンドへ

拡張パック「六姫の協奏曲」の6人のうち、2人だけレアリティが下のまま実装されていた。

| | 前 | 後 |
|---|---|---|
| セレナ（深碧の風守り） | RARE | LEGEND |
| カグラ（紅蓮の舞姫） | SUPER_RARE | LEGEND |

## レアリティが変えるもの

キャラクターのレアリティは**能力値に一切かからない**。効くのは2つだけ。

- ガチャの排出率（レジェンドの棚に移るので出にくくなる）
- 重複したときのゴールド還元額（レジェンドのほうが多い）

Lv255換算の総合力で見ると、カグラ(5,990)はレジェンド帯の中位、
セレナ(5,106)は最下位のフィリア(5,304)を少し下回る位置。
どちらも外れ値にはならないので、能力値はそのままにした。

## テストが1つ落ちた

**「§8 レジェンドは特殊パッシブか特殊技を持つ」** が セレナ / カグラ で落ちた。
既存25人のレジェンドは**全員が固有パッシブを持っている**ので、この決まりは生きている。
テストを緩めるのではなく、2人に固有パッシブを足した。

### セレナ — `situational: { weakGuard: 0.35 }`

纏った風が、突かれた弱点を受け流す。実測で被ダメージ 10,299 → 6,694（−35%）。

**味方を庇う系（guardAlly / damageShare / backGuard）は使わなかった。**
テオドラの領分であるのに加えて、`battle.js` は
`party.find(u => u.passives.guardAlly > 0)` で**先に見つけた1人しか庇わせない**。
同じ鍵を持つ2人を並べると、片方が黙って働かなくなる。

なお、彼女の固有技「風神の障壁」は `addReductionBuff` を通るが、ここは
`buffAmount` も `afterBuff` も通らない（軽減は合計1.0で無敵になるため、
かける側の倍率を乗せない作りになっている）。つまり `allyBuffPower` /
`buffShield` / `buffExtend` を持たせても**彼女の看板技には一切効かない**。
守りの方向をずらしたのはそのため。

### カグラ — `passives: { statusOnHitKind: { burn: 0.30 } }`

舞うたびに焼く。攻撃時30%で火傷を撒く。

ルーナの `vsStatusPower: { burn: 0.35 }`（火傷中の敵への火力）とは別物で、
こちらは火傷を**撒く側**。組ませると噛み合う。
フリーシアが同じ鍵を freeze で持っているが、パック内でも
エレナ／ルーナが `vsStatusPower` を別の異常で分け合っており、同じ流儀。

## 併せて足したテスト

`effectiveWeights()` は候補が0人のレアリティを**黙って外す**ので、
棚を空にしても排出率のテストは通ってしまう。
「§6.2 どのレアリティにも排出候補がいる」を足した。
今回の移動後は COMMON 5 / RARE 5 / SUPER_RARE 4 / LEGEND 26。

検証テスト 1220/1220。
