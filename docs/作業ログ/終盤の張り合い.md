# 終盤の張り合い

`docs/保留中のアイデア.md`「終盤にオート用の張り合いが無い」に着手した記録。
**この文書は進行中の状態だけを書く。** 判断の履歴はコミットに残す。

## 方針（保留文書の結論を引き継ぐ）

- 周回フィールドを一律に難しくしない。オートで100%回せる手前へ移られるだけになる
- 「組み方で結果が分かれる場」を、**選んで入る場所**として置く。オートで挑めること
- 組み方を問う軸は、実測で分かれているもの（耐久と分業・状態異常・属性）を使う。
  多段を塞ぐ仕掛け（firstHitOnly）は周回へ持ち込まない（「弱くされた」としか映らない）

## 1単位目: 還らぬ位相を「一体が桁違いに濃い」場所にした — 済

フィールド定義には「育っても張り合いが残るDPSの試験場」と書いてあったのに、
純度（HP 3万台）は主力の1発（100万超）で倒れていた。組み方が結果に出ない。

### 測ったこと（seed固定24回、Lv255・5凸・竜80＋星辰10から自動装備）

型は `test/builds.js` の REFERENCE（強いビルドの組み方 §7.0、実プレイの約83%）を土台に3つ:
攻撃専念＝処方から軽減・庇う・挑発・回復を抜く／既定＝処方そのまま（軽減20%）／
守り役1＋攻撃専念3＝1人だけ挑発・庇う・軽減・HPを優先。

| 還らぬ位相の敵HP | 攻撃専念 | 既定 | 守り役1＋攻撃3 |
|---|---|---|---|
| ×1（以前） | 24/24・6R | 24/24・5R | 24/24・5R |
| ×10 | 24/24・6R | 24/24・7R | 24/24・6R |
| ×20 | 20/24・1.3人倒れる | 23/24・11R | 24/24・8R |
| **×30（採用）** | **11/24・3.0人** | **18/24・16R** | **24/24・10R・0人** |
| ×35 | 6/24・3.5人 | 18/24・19R | 24/24・11R |

1ラウンドあたりの実入り（×30、新しい倍率、負けた回も含む）:

| | 金 | 箱 | 経験 |
|---|---|---|---|
| 回廊（参考、どの型もほぼ同じ） | 2,900〜3,100 | 8.1〜9.1 | 12,700〜13,800 |
| 位相・守り役1＋攻撃3 | 3,538 | 9.83 | 15,626 |
| 位相・攻撃専念 | 1,957 | 6.20 | 9,318 |
| 位相・既定 | 1,868 | 5.47 | 8,515 |

**組んで来れば回廊より1割強多く、組まずに来ると回廊の6〜7割。** 回廊はどう組んでも安定して稼げる。

### 変えたもの

- 純度・名を失くした帝の HP（base・growth）を30倍。攻撃力は触っていない
- 位相の倍率 金0.40→0.88／経験0.62→1.62／箱1.0→4.0
- 依頼「無一色」は enemyScale hp 120→4（敵の実際の厚さは同じ）
- 回廊と位相の説明文（回廊＝どう組んでも稼げる、位相＝守りの有無で実入りが変わる）

## 2〜4単位目: 候補を測って3つとも閉じた

どれも実装する前に測り、**入れないほうがよい**と分かった。測った値は残す（同じ検討をやり直さないため）。

### 回廊に異相を開く — 入れない

回廊の敵は打撃が軽く、相がほぼ無料になる（REFERENCE の型・Lv255・24回、1ラウンドあたりの金、素 3,114）:

| 相 | 結果 | 金/R |
|---|---|---|
| あまねく相 | 24/24・最低HP 95% | 5,837（×1.87） |
| 硬きを試す相 | 24/24・最低HP 86% | 6,040（×1.94） |
| 他の4つ | 24/24・6R のまま | ×1.27〜1.30 |

臨界の際では同じあまねく相が 19/24・最低HP 54% で対価を払っている。回廊に開けると
「回廊＋あまねく」がほぼ2倍の一強になり、位相（組めば稼げる）の意味も消える。
理由は `data/aspects.js` の冒頭に書いた。

### 臨界の際を「数で来る＝全体攻撃が効く」場所にする — もう成立している

全体技（乱れ撃ち）と波及を先に取った型（rsweep）と、処方そのまま（ref）を比べた:

| 臨界の敵HP | ref 金/R・箱/R | rsweep 金/R・箱/R |
|---|---|---|
| ×1（いま） | 1,863・5.02（6R） | **2,193・5.75**（5R、+18%） |
| ×3 | 1,855・5.06 | 2,220・5.63（変化なし。過剰撃破のまま） |
| ×5 | 1,592・4.22 | 2,102・5.88（差は +32% に広がるが、ref が15%損する） |

いまでも全体攻撃の型が2割近く稼げる。差を広げるには ×5 以上が要り、そこでは普通の型が損をする。
臨界は上限前の主な狩場なので、誰かを損させてまで差を広げない。

### 位相の雑魚に反撃を持たせる — 重ねすぎ

位相（HP×30）の雑魚に反撃（50%・威力0.6、弱め）を足した:

| | 攻撃専念 | 既定 | 守り役1＋攻撃3 |
|---|---|---|---|
| 反撃なし（いま） | 11/24 | 18/24 | 24/24 |
| 反撃 50%・×0.6 | **0/24** | **0/24** | 21/24 |

位相は既にHPの厚さで「守りを捨てた者への税」を取っている。反撃を重ねると守り役しか通れない場所になる。

## 5単位目: 塔の100階より先に目標を置いた — 済

`sim.climb`（`test/sim.node.js`）を足して、オートで塔を登らせた。101階から、seed固定8回:

| | 到達階の中央 | 範囲 |
|---|---|---|
| 攻撃専念 | 124 | 122〜127 |
| 既定（軽減20%） | 133 | 129〜136 |
| 守り役1＋攻撃専念3 | 153 | 140〜157 |

**塔は既に、オートのまま組み方が結果に出る場所だった。** 足りなかったのは100階より先の目標だけ。
節目を5つ足した: 110階 星辰×3／125階 天頂の剣（スコア754）／150階 星霜の欠片×2・星辰×3／
175階 不落の天蓋（834）／200階 欠片×3・星辰×8。装備は竜の LEGEND 上位1割（750〜870）に並べた。
オート回数の上限は配らない（報酬の合計が頭打ち100を既に使い切っている。検証テストが見ている）。
節目が道具を配れるよう `tower.js` の受け取りと画面の表示に口を足した。

## 6単位目: 残っていたボス3体に専用の一手 — 済

二番機ドゥオ（浅層）「写しの命令」、初代管理機ウーヌス（封絶区画）「渡せぬ鍵」、累なる貌（回廊）「累ねの貌」。
浅層・封絶区画は物語でも出る、回廊は安定して稼ぐ場所にした——ので、**置き換える技とほぼ同じ威力の単体技**に
弱い異常を1つだけ乗せた。ボス戦（1戦・ボスあり、seed固定48回）の前後:

| | 前 | 後 |
|---|---|---|
| 浅層・物語序盤相当（主人公＋COMMON2人 Lv20・銀箱） | 48/48・最低HP 68% | 48/48・69% |
| 浅層・推奨Lv編成 | 48/48・93% | 48/48・94% |
| 封絶区画・弱め（同 Lv130・竜箱） | 48/48・64% | 48/48・68% |
| 封絶区画・推奨Lv編成 | 48/48・99% | 48/48・99% |
| 回廊・Lv255 | 48/48・89% | 48/48・92% |

難度は動いていない。これでフィールドのボス12体がどれも専用の技を持つ（テストで見張る）。
