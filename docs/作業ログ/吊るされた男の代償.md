# 吊るされた男の代償 — 手番を数で奪う案を2つ捨て、麻痺に落ち着くまで

いまの状態: **`self_bind`（縛り）で実装済み。検証テスト 1514/1514 合格。公開はまだ。**

## 結論

代償は「常に麻痺している」扱いにした。値はそのまま動けない確率で、`0.15`。

```js
effects: [
  { kind: 'self_bind',    value: 0.15 },
  { kind: 'always_crit',  value: 1 },
  { kind: 'always_power', value: 1.50 },
  { kind: 'cap_break',    value: 4.00 },
]
```

**状態異常として貼らず、`statusRatio` の下限として合流させている。**
貼る作りにすると解除技で自分の代償を外せてしまい、ウェーブごとの貼り直しも要る。
下限なら通り道が1本で済み、消える経路が存在しない。
敵が撒いた麻痺とは `max` で合流するので、重ねても二重には効かない。

## 捨てた案2つ — どちらも理由は「目盛りが無い」

| 案 | 何が起きたか |
|---|---|
| `turn_debt` 毎ラウンド手番を1つ失い再行動で返す | 返済の口が `extra_action` しかなく、**殴る札なのに戦術家を選ぶのがほぼ唯一の解**になった。しかも確率なので「運が悪いと延々動けない」体験が残る |
| `turn_stride` 確定で2回に1回 | 運は消えたが `ticks % stride` なので 2 の次は 3。**「3回に2回」が作れない** |

### 刻みが段差になった実測

実ビルド（`_scratch/save_latest_20260917.json`・Lv255・4人編成）、`fl_endless` 10ウェーブ:

| 条件 | 素 | 刻み2回に1回 |
|---|---|---|
| 等倍 | 100% / 10.0R | **100% / 10.2R**（代償が存在しない） |
| HP×10 | 100% / 10.3R | 70% / 13.3R |
| HP×35 | 100% / 11.1R | **0%（ウェーブ4.6で全滅）** |

**利を威力2000%・上限突破4000%まで上げても HP×35 は 0% のままだった。**
手番が半分になるとウェーブごとに2ラウンドかかり、被弾機会が倍になる。
硬さの問題なので火力の目盛りでは届かない。

さらに、付ける相手でも段差になった（HP×35・同じ編成で付け替えただけ）:

| 付けた相手 | 勝率 |
|---|---|
| 主人公（担ぎ手） | **0%** |
| アストラ / シャンタル / オーロラ | いずれも 100%・11.0〜11.3R（＝素と同じ） |

素のとき味方は1.7回しか動かない——主人公が全部倒しているため、
「手番を半分」は味方には無意味で、担ぎ手には致命になる。

## 麻痺にすると傾斜になる

同じ HP×35 で、縛りの比率だけを振った:

| 縛り | 勝率 | ラウンド |
|---|---|---|
| 15% | 93% | 13.7 |
| 25% | 63% | 14.8 |
| 35% | 30% | 17.1 |
| 50% | 23% | 22.0 |
| 75% | 0% | — |

**比率なのでいくらでも細かく置ける。** これが刻みとの決定的な差。

## 利と害の形（本実装・`fl_endless` 5ウェーブ・60回）

| | 等倍 | HP×35 | HP×300 | HP×1000 |
|---|---|---|---|---|
| 素 | 100% / 5.0R | 100% / 6.1R | 85% / 10.8R | 65% / 18.2R |
| **吊るされた男** | 100% / 5.1R | 97% / 7.1R | 77% / 11.8R | **63% / 14.3R** |
| 力 | 100% / 5.1R | 98% / 5.7R | 72% / 9.0R | 43% / 14.7R |
| 戦車 | 100% / 5.0R | 92% / 5.2R | 33% / 6.7R | 13% / 8.3R |

**火力が足りない場面ほど得をする札になった。** HP×1000 では勝率が素と並んだまま
ラウンドが 21% 短い。逆に HP×300 以下では素より遅く、勝率だけ下がる。
3枚が「速さと事故りやすさ」の階段に並ぶ。

## 測るときに踏んだ罠

**同じ罠を3回踏んで、そのたびに結論が食い違った。次も踏むので必ず読むこと。**

### 1ウェーブ1ラウンドの床を忘れない ← 最大の落とし穴

終盤ビルドは **1ウェーブ1ラウンド**で勝っている（HP×35 でも 10ウェーブ 10.9R）。
床より速くはなれないので、**火力の利は買うものが無く、手番の害だけが残る**。
この土俵で測ると、どんな利を乗せても「害しかない札」に見える。

火力が効く難度を先に探すこと。実測:

| | 1ウェーブあたりのラウンド |
|---|---|
| HP×35 | 1.23（床） |
| HP×100 | 1.48 |
| **HP×300** | **2.04** |
| **HP×1000** | **3.29** |

### `q_endless_vigil` を物差しに使わない

「8ラウンド以内」が達成条件。手番を減らす札は**火力をいくら上げても 0% に張り付く**。
`fieldId: 'fl_endless'` を直接指定して、条件の無い場で測ること。

### 倒し切ると与ダメが残HPで頭打ちになる

手番の少ない条件ほど敵が健在なので「1発が重い」と誤って出る。
実際「刻みだけ」（一撃には何も足していない）で 1.18倍 という有り得ない値が出た。

### `enemyScale: { hp: 100000 }` は使えない

割合ダメージの技が跳ね上がり、1手番1,500M という桁違いの値になる。
順序が乱数で入れ替わり、`突6 < 突9 > 突12` のような非単調な表になった。

### 素を「会心しない1発」で測ると札を過大評価する

素は既に29%会心している。期待値
（`p×crit + (1-p)×noncrit`）で並べること。

### 麻痺はクールダウンを進めてから飛ばす

`commandSkill` は `startCooldown` の**あと**で麻痺を判定する。
「大技を抱えた相手ほど損が大きい」(§5.8) という意図的な作り。
この札は大技で殴る札なので、**名目の15%より重く効く**。
数字を動かすときは必ず実測すること。

### `skipDeadActors` は1手番に複数回呼ばれる

旧 `turn_debt` は残債を減らす作りなので何度呼ばれても平気だったが、
カウンタを進める作りにすると呼ばれた回数だけ進む（`turn_stride` がそうだった）。
**数える処理をここへ置かないこと。**

## 威力% と上限突破の効き方が違う

一撃の期待値（`bs_nameless_sovereign` 相手・素の会心率込み）:

| | 斬撃 | 覇王斬 | 黄昏 | 終焉の一撃 |
|---|---|---|---|---|
| 威80 突2 | 2.39 | 1.68 | 1.74 | 1.88 |
| 威80 突6 | 2.36 | 2.68 | 2.70 | 2.61 |
| 威300 突8 | 5.10 | 3.50 | 3.47 | 4.07 |

**威力% は基本攻撃だけを膨らませ、上限突破は大技を均等に持ち上げる。**
突6以降は斬撃が 2.36 で止まる（上限に当たらなくなる）。
「重い一振り」の札に合うのは突破側。

## 付随して決めたこと

`src/core/tree.js` の `extraActionRate` 上限（0.5）がクラス合流後に破られる件は、
**戦術家の特色として意図的に残す**とコメントで明記した。
ここで全体に蓋をすると、戦術家を選ばずユニーク装備2つで盛るほうが得になり、
クラスを選ぶ理由が消える。
