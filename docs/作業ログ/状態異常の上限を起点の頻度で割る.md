# 状態異常の上限を「起点の頻度」で割る

## 何が壊れていたか

6種の異常は**効くタイミングが全部ずれている**のが設計の芯で、どれを撒くかが
そのまま戦い方の選択になる（`docs/拡張コンテンツの作り方.md`）。

ところが `status_power` を積むと ratio が **4.7倍** まで伸びる。技の素の値は
0.06〜0.10 しかないので、**全部が上限へ収束する。**

| | 素 | ×4.7 | 上限 |
|---|---:|---:|---:|
| 毒牙 | 0.06 | 0.28 | 0.5 |
| 疫病の坩堝 | 0.10 | **0.47** | 0.5 |

つまり**上限が実質の値**になっていた。毒も火傷も同じ 0.5 なので、
「1ラウンドに1回しか起きない毒」と「5回起きる火傷」に**同じ1回ぶんの威力**が
割り当てられていた。掛け算になるのは当然だった。

## 直し方

上限を「1ラウンドに何回起きるか」で割る。

| | 前 | 後 | 意味 |
|---|---:|---:|---|
| 毒 | 0.5 | **0.18** | ラウンド終了時に1回。確実に入るぶん厚く |
| 火傷 | 0.5 | **0.06** | 相手が攻撃するたび。通常1回・闘技場3〜5回 |

**個性が戻る。**

- 1手番のボス … 毒18% 対 火傷6% → 毒を選ぶ
- 闘技場のボス（5手番）… 毒18% 対 火傷30% → 火傷を選ぶ
- 分岐点は3手番

### 回数で縛る案は捨てた

一度「火傷は1ラウンドに1回まで」を実装したが撤回した。
**それでは火傷が毒の色違いになる。**「動くほど焼ける」が火傷の個性で、
そこを縛ると6種の区別が1つ減る。手引きの「毒の色違いを足さないでください」に
真正面から反する。

## 実測（ハード・耐久を切り離して）

| | 前 | 後 |
|---|---:|---:|
| 毒＋火傷 | 2R（50%/R） | **5R（20%/R）** |
| 火傷のみ | 2R | **7R（14.3%/R）** |

比較: 大技型 7R ／ 中技・小技・棘・反射 9〜10R。
**3.5倍速かったものが1.4倍**になった。

通常フィールドへの影響は無い（状態異常ビルドでも1ラウンドで抜ける。
攻撃役が先に倒すため）。

## これは定数を直しただけで、構造は残っている

別途測った結果、**状態異常の決着ラウンドは相手のHPにほとんど依存しない。**

| ボスHP | 状態異常 | 攻撃型 |
|---:|---:|---:|
| 94M | 5R | 3R |
| 376M | 4R | 12R |
| 1,502M | **5R** | **>200R** |
| 6,009M | **5R** | **>200R** |

攻撃型は **31M/ラウンドで頭打ち**（ダメージ上限があるため）。
状態異常は **HPに比例して伸びる**（上限が無いため）。

交差点は **HP 約1億5千万**。闘技場ハードは2億なので、既に超えている。
**HPで壁を作るほど、この差は開く。** 上限を下げたのは交差点を動かしただけで、
構造そのものは残っている。ここは別途の判断待ち。
