# 闘技場ハードをコンセプトに合わせる

**ブランチ**: `work/arena-hard`
**日付**: 2026-08-25

## 方針

プレイヤー側のインフレは削らない。**これはこのゲームの利点**で、
「重なったらインフレする」というプレイヤーの想定がそのまま形になる。
長期運営の制約がある商用ソシャゲでは作れない面白さなので、ここは守る。

代わりに**ボス側をコンセプトに合わせて対策する**。

## 発端: 闘技場が2ラウンドで落ちていた

実セーブのパーティで、指定された手順（3人が手番を捨てる）を再現:

```
R1 アルト  氷河期       58,101 + 126,252
R1 ゼロ    破鎧撃      232,390 + 186,666
R1 エンバー 焔の連舞  10,092,926
R2 3人が闘気集中（手番を捨てる）
R2 エンバー 焔の連舞  23,887,749   ← 撃破
```

**エンバー1人でボスHPの85%。** 2ラウンドで終わる。

### 犯人は ignoreCap ではなくヒット数だった

| | 主人公 | エンバー |
|---|---|---|
| 技 | 終焉の一撃（威力800・上限無視） | 焔の連舞（威力85・4段） |
| 1手番のヒット数 | 4 | **16** |

ダメージ上限は1ヒットごとなので、**ヒット数を増やすと上限そのものが増える**。
上限無視の1発×4より、上限に16回ぶつかるほうが多く出る。

さらに `sk_lg_pyre` の desc に「1発が小技の帯なので、拡散・連射・追撃のパッシブが
全段に乗る」とあり、多段特化すると:

```
4段 × (1 + doubleHits 3) × (1 + 小技の連射 3) = 64ヒット/手番
64 × 4行動（本来1 + MAX_EXTRA_ACTIONS 3） = 256ヒット/ラウンド
```

なお `MAX_EXTRA_ACTIONS = 3` の上限が既にあり、
刻の号令(`mass_extra`)は `grantedExtra` が真偽値なので
**味方何人から貰っても再行動は3回で頭打ち**。

## クラス技が一度も動いていなかった

| 対象 | 平均R | クラス技の発動/戦闘 |
|---|---|---|
| fl_mine（推奨12） | 1.25 | **0** |
| fl_origin（推奨150） | 1.25 | **0** |
| fl_endless | 1.21 | **0** |
| 闘技場ハード | 4.67 | 0.75 |

クラス技の解禁は2〜4ラウンド目。**通常コンテンツは平均1.2Rで終わるので全部死んでいた。**
推奨12と推奨150が同じラウンド数なのも問題。

方針としては「通常は速いままでよく、高難度側でラウンド数を要求する」（B案）だが、
**その受け皿である闘技場が2ラウンドで落ちていた**のが今回の発端。

## 入れたもの

`data/arena.js` のボス定義に `hard` を足し、ハード専用の上書きを可能にした。

```js
hard: { hpMult: 3.75, gimmicks: { hitAbsorb: 30 } }
```

`scale` ではなく `hpMult` を別に持つのは、scale が攻撃力にも掛かるため。
「HPを盛ってDPSチェックにする」調整を scale でやると一撃の重さまで上がり、
**削り切れないうえに殴り殺される**二重の理不尽になる。

### 終刻の審判者 — DPSチェック

「刻を数えるもの」なので、対策は搦め手ではなく制限時間。
HPを 39,981,600 → **149,931,000**（hpMult 3.75）。8ラウンドの `enrageRound` はそのまま。

| | 修正前 | 修正後 |
|---|---|---|
| 勝率 | 63% | 88% |
| 平均R | 4.67 | 4.5 |
| クラス技/戦闘 | 0.75 | 0.94 |

（勝率が上がって見えるのは測定パーティが変わったため。ラウンドは3〜8に散る）

### 千葬の守り手 — 手数への関門

`hitAbsorb` 2 → **30**。

**このボスは元々「重い一撃をメタる」側**で、刹那の巨兵(`firstHitOnly`)の対になっている。
実測では重い一撃型は無効化2でも勝率0%（1ラウンドに3ヒットしか出ないため）。
メタは既に成立しているので、上げる目的は多段型への関門を作ること。

| 無効化 | 勝率 | 平均R | 最長R | クラス技/戦闘 |
|---|---|---|---|---|
| 2 | 100% | 2.25 | 4 | 0.21 |
| **30** | **92%** | **3.25** | **10** | **0.71** |
| 40 | 83% | 5.17 | 12 | 0.92 |

実パーティは1ラウンドに最大55ヒット出すので、30なら半分以上が捨てられる。
40は歯応えが出るが最長12ラウンドと長すぎる戦闘が混ざる。

**多段は三連の型(`tr_grant_triple`、中級3SP)で誰でも組める**ので、
ここを上げても特定キャラ専用の関門にはならない。

### 刹那の巨兵 — 触らない

`firstHitOnly`（各ラウンド最初の1撃のみ通る）が多段ビルドを直接潰しており、
既に最も手強い。実測で平均4.69R・クラス技0.88回。

## 持ち越したもの: 1ラウンドに認める傷の上限

HPを盛るだけでは上振れが止まらない。多段特化ビルドは1ラウンドで3,095万を出し、
最短2ラウンドで沈める（クラス技の発動が0.92→0.21回に落ちる）。

`maxRoundDamageRatio` を作ったが、**6戦のうち2戦は教科書どおりに動く一方、
残りでは上限の4倍が通る**。HPを減らす道が10箇所以上あり、5回作り直しても
塞ぎ切れなかったため、今回は撤去して `docs/保留中のアイデア.md` へ持ち越した。

最有力の原因は `resolveEchoes`（残響）が `arenaRoundTick` の直後に走ること。
詳細は保留中のアイデア側に記録してある。

## 次に作るとよいもの

**1ヒットごとに一定ダメージを減算するボス。**

```
1ヒットごとに -600,000
  重い一撃(1発250万)  → 190万通る（76%残る）
  多段(1発50万×64)    → 全部0になる
```

`hitAbsorb` と違って**下を切り捨てない**（重い一撃型は普通に戦える）。
多段型を直接メタる唯一の形で、しかも**上限突破ビルドが生きる**。
現状これに当たるボスがいないので、新しい闘技場ボスの軸になる。

検証テスト 1209/1209。
