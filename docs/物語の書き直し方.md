# 物語の文章を書き直す

台詞や場の説明だけを取り出して、好きなエディタで直して、戻せます。
`data/story.js` を直接開く必要はありません。

```bash
python tools/story_text.py --export    # docs/物語の文章.txt へ書き出す
#   ここでテキストを直す
python tools/story_text.py --check     # 何が変わるかだけ見る
python tools/story_text.py --import    # データへ戻す
```

戻したら **`test/index.html` を開いて全件合格を確かめてください。**

## 書き出されるテキストの形

```
--- ch1_wake ---
# 地の文
[ch1_wake.0] ——起動。生体維持プロトコル、解除。
# アルト
[ch1_wake.2] ……ここは。
```

- **`[鍵]` は消さないでください。** 戻す場所の目印です
- `#` で始まる行と空行は読み飛ばします。話者は**目印として出しているだけ**で、
  ここを直しても話者は変わりません
- **文章の差し替えだけ**ができます。行を足したり消したりはできません

## 何を触れて、何を触れないか

| | 差し替えられる |
|---|---|
| 章の名前・導入文 | ○ |
| 場面の台詞・地の文 | ○ |
| マップの名前 | ○ |
| マップの事象文（話しかけ・調べもの） | ○ |
| 話者・条件(`when`)・後処理(`then`)・旗 | **×** |
| 場面や台詞を増やす／減らす | **×** |

構造を触らないのは事故を防ぐためです。増やすときは `data/story.js` を直に開いてください。

## 設定の説明は、会話に書かない

**物語は会話が主体です。** これから何をするのか、どこへ向かうのか、誰が何を望んでいるのか——
それを、その人らしい言い方で話させる場所です。

世界がどうしてこうなっているかの説明は、**記録**（`data/records.js`）へ置いてください。
物語を進めると手に入る箱で、図鑑の「記録」から読み返せます。

| | 行き先 |
|---|---|
| いま何が起きているか／次にどこへ行くか／誰が何を望んでいるか | **会話** |
| なぜ世界がこうなっているか（背景・来歴・仕組み） | **記録** |

### 境目を間違えないこと

**筋を追うのに要ることは、記録へ逃がさないでください。** 図鑑は、読まない人が読まない場所です。
そこへ本筋を置くと、開かなかった人にとって物語が空になります。

記録が引き受けるのは「なぜそうなのか」までで、「何が起きたか」は会話に残します。

### 記録は、説明文ではなく銘文として書く

文体は `data/records.js` の冒頭に置いてあります。要点だけ:

1. 一行目は体言止めで「それが何か」だけを言う。意味を言わない
2. 行で切る。句点で流さない（`
` がそのまま改行になります）
3. 段は短く、1〜4行。段のあいだが最も雄弁になる
4. 断定しない。「という」「らしい」「だろう」——知っている声で書かない
5. 肝心なことは書かず、傍らに置く
6. 最後の段で一度ふり返る

強調記号（`**`）は使わないでください。太字が混ざると、そこだけ説明書の声になります。
仕組みの説明（何回で何が起きる、など）も書きません。それは用語集の仕事です。

### 地の文の割合を見る

書き直したあとに測ってください。会話より地の文が多い章は、たいてい説明を抱えています。

```bash
node -e "const s=require('./test/sim.node.js');const R=s.load();let n=0,d=0;for(const c of R.data.story.chapters)for(const x of c.scenes||[])for(const l of x.lines||[])(l.who==null?n+=l.text.length:d+=l.text.length);console.log('地の文',n,'字 / 会話',d,'字 =',Math.round(n/(n+d)*100)+'%')"
```

2026-09-10 時点で全体 43%、第四章が 52% と最も高い。**第二章の 34% が目安**です。

## 章を足したら、道具の側は直さなくてよい

対象のファイルを固定の一覧で持っていません。`RPG.data.story` か `RPG.data.maps`
を含む `.js` を**毎回探し直し**、中の章・場面・事象もその場で数え直します。

第九章を足して試したところ、登録なしで 182 件 → 186 件に増えました。
`content/` に置いた拡張も同じ条件で拾います。

## 安全のための作り

**鍵が食い違ったら書きません。** 書き出したあとに `data/story.js` 側を編集すると、
差し替える位置がずれて**別の台詞を上書きしてしまいます**。
そうなる前に断って、`--export` の取り直しを促します。

```
鍵が食い違っています。書き出し以降にデータ側が変わった可能性があります。
  テキストに無い: ch1_wake.2
--export で取り直してから編集し直してください。
```

**往復しても1バイトも変わりません。** `--verify` で毎回確かめられます。
書き出して、何も直さずに戻して、ファイルが完全に一致することを見ています。
往復で形が変わる道具は、書いた本人以外は怖くて使えないためです。

## 書き戻しの見た目

- `'` を含む文章は自動で退避します（`\'`）
- 58文字を超える文章は**句点で折って連結**にします。元のファイルが
  そう書かれているので、差分が本文以外に広がらないようにするためです
- 折り返しの字下げは**その行の頭**に合わせます
