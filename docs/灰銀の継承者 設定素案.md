# **『灰銀の継承者』設定素案**

## **1\. 概要・コンセプト**

> * **作品タイトル / 主人公の二つ名：** 『灰銀の継承者』（Inheritor of Ash & Silver）  
> * **ジャンル：** サイエンスファンタジー（ポストアポカリプス / 崩壊世界）  
> * **コアコンセプト：** 「失われた超物理文明」と「台頭する神秘（魔法）」の相克、そして二つの理を同一の力として調停する「唯一の遺産」。

## **2\. 世界観と歴史**

### **■ 世界観の背景**

かつて世界は、素粒子工学や超高度ナノテクノロジーを極めた\*\*「超高度物理文明」**の頂点にあった。しかし、突如として大気中に飛来・発生した未知の**「神秘エネルギー（エーテル）」\*\*により、既存の物理法則が汚染・歪曲。高度な機械群は機能を停止・暴走し、文明は瞬く間に灰燼（かいじん）へと帰した。  
崩壊から長い年月が経った現在、環境に生じた神秘エネルギーに適応し、術式を編んで奇跡を起こす\*\*「魔法使い（新人類）」\*\*が台頭。かつての物理科学は「古代の遺物」として信仰、あるいは恐怖の対象となっている。

### **■ 作中の3大システム・勢力カテゴリ**

> 1. **【物理（Ash / 灰）】**  
   * 肉体運動、質量、実体兵器、荒野の泥臭い生存技術。  
   * 滅び去った旧世界の残滓と、神秘を使えない人々の生存手段。  
> 2. **【魔法（Ether / 漆黒・神秘）】**  
   * 精神力、エーテル演算、新世界の自然律を書き換える術式。  
   * 文明崩壊後に台頭した新勢力・魔法使いたちが操る力。  
> 3. **【遺産（Silver / 銀）】**  
   * 旧文明が滅亡直前に到達したオーバーテクノロジーや失われた遺物。  
   * 主人公の体内に宿るコアをはじめ、世界各地に眠る巨大な特異点。

## **3\. 主人公設定**

### **■ 人物像と二つ名の由来**

> * **二つ名：** 灰銀の継承者  
> * **概要：** 荒野のシェルター（旧文明施設）でコールドスリープから目覚めた記憶喪失の青年/少女。  
> * **二つ名の意味：**  
  * **灰（Ash）：** 滅亡した物理文明の残滓、失われた個人の記憶と過去。  
  * **銀（Silver）：** 体内に埋め込まれた旧世界最後の遺産（灰銀コア）、冷徹に作動する等価変換プロトコル。

### **■ 記憶喪失のメカニズム**

旧物理文明の末期、神秘エネルギーによる汚染から肉体と生命を維持するため、体内の「灰銀コア」が**主人公の生体記憶領域を緊急の演算リソースおよび防壁として消費・上書き**した。 そのため、個人としての記憶（名前、生い立ち）は消失しているが、旧世界の兵器の扱い方や未知の魔法術式の構造解読など、**「戦うための知識と技術」だけが無意識レベルで完璧に保持されている**。

## **4\. ゲームシステムと設定の融合（等価変換機構）**

### **■ 特性：【灰銀の理（アッシュ・コード）】**

ゲームシステムにおいて、\*\*「物理攻撃力と魔法攻撃力のうち、常に高い方のステータスに低い方を自動で同期・補正する」\*\*という固有パッシブ能力。  
\[プレイヤーの育成・ビルド\]  
 ├─ 物理特化ビルド（肉体・実体兵器を極める）  
 │     └─→ 【灰銀コア】が運動量をエネルギー変換 ─→ 魔法攻撃力が同値に引き上げられる  
 └─ 魔法特化ビルド（精神・エーテル術式を極める）  
       └─→ 【灰銀コア】がエーテル圧を質量変換 ──→ 物理攻撃力が同値に引き上げられる

### **■ 設定上の裏付け**

主人公の体内に流れる液状ナノマシン群（灰銀のコア）が、**「実体物理の運動エネルギー」と「神秘魔法のエーテル圧」をリアルタイムで等価相互変換**し続けている。これにより、どちらか一方の才覚を極めるだけで、もう一方の力も自動的に極限出力へと最適化される。

## **5\. ビジュアル・演出アプローチ**

> * **通常時 / 待機時：** 荒野の煤や灰を被った無骨なマントと実体武装（**灰**の泥臭い質感）。  
> * **戦闘時 / 術式発動時：** 攻撃の瞬間、身体や武装の隙間から銀色の液状金属（**銀**のナノマシン）が噴出。刃を振るえば銀の幾何学模様が空間を裂いて物理打撃を補正し、魔術を放てば衝撃波が物理的に大地を砕く。  
> * **フレーバーテキスト例：**「灰燼に帰した旧世界の肉体（物理）と、新世界を満たす神秘の理（魔法）。 滅亡の淵で鋳造された銀のコアは、二つの相反する世界をその身一つで調停し続ける。」

## **6\. シナリオ展開のキーポイント**

> 1. **異端としての存在感：** 魔法使いからは「術式も紡がずに魔法と同等の破壊力を出す怪物」と恐れられ、旧人類の生き残りのサルベージャーからは「失われた物理文明の希望」と見なされる。  
> 2. **記憶の回収と遺産の解放：** 強大な力を行使したり、世界各地の「遺産」と共鳴するたびに、断片的な記憶ログ（ノイズ混じりの旧世界の記憶）が再生され、世界が崩壊した真実へと近づいていく。
