# 新スキルプラグイン追加案

本ドキュメントは、ゲームシステム（属性・状態異常・ダメージ上限減衰・系統タグ・コンボ・装備シナジー等）の戦術の幅をさらに広げるための**新規スキルプラグイン（`src/plugins/` への追加候補）**の仕様設計案です。

---

## 0. 新規プラグイン追加の設計方針

1. **既存の数値インフレではなく「戦術の軸」を増やす**
   単に高倍率の技を増やすのではなく、パーティの組み合わせやスキルツリーの選択によって価値が変わるギミックを追加する。
2. **ダメージ上限減衰・状態異常タイミングとの整合性**
   単発技が上限に引っかかりやすい仕様を踏まえ、多段・拡散・即時変換などの手段を用意する。
3. **拡張コンテンツ（`content/`）から呼び出しやすい params 構造**
   パラメータの命名をシンプルに保ち、技定義の JSON から直感的に挙動を設定できるようにする。

---

## 1. 提案プラグイン一覧

| プラグインID | すること | 想定される params | 主な役割・戦術 |
|---|---|---|---|
| `pandemic` | 敵1体の状態異常・デバフを敵全体へ拡散 | `turns`（省略時は残りターン数維持） | 単体特化の異常付与役と全体攻撃役のシナジー |
| `barrier` | ダメージを肩代わりする耐久障壁（シールド）を付与 | `ratio`, `scaling`, `turns`, `party` | 最大HP超過の防御、背水ビルドの安全保護 |
| `chain_burst` | 敵から敵へ跳弾・連鎖しながら攻撃 | `chains`, `decay` または `bonus` | 少数〜中規模の敵グループに対する手数・連撃 |
| `charge_strike` | 自身をチャージ状態にし、次ターンの攻撃を特大強化 | `ratio`, `critRate`, `capBreak` | ブレイク時や追加行動と合わせた瞬間超火力 |
| `combo_finish` | パーティのコンボ段数を全消費して大ダメージ | `perCombo`, `maxRatio` | 手数・連撃ビルドの明確なゴール・決戦砲 |
| `counter_stance` | 迎撃構えを取り、被弾時に自動で反撃技を発動 | `turns`, `reduction`, `counterSkill` | ディフェンダー（かばう）や耐久反撃ビルド |

---

## 2. 各プラグインの詳細設計

---

### 2.1 `pandemic`（病禍の拡散）

#### 目的と背景
単体にしか強力な状態異常（毒・火傷・流血・凍結・麻痺・呪詛）を撒けないキャラクターの価値を、パーティ単位で全体化できるようにする。

#### パラメータ（`params`）
- `turns`: （省略可）拡散後の持続ターン数。指定がない場合は対象の「現在の残りターン数」を引き継ぐ。

#### 技定義の例
```js
skills: {
  sk_ex_epidemic: {
    name: 'エピデミック・カース',
    kind: 'active',
    plugin: 'pandemic',
    scaling_stat: 'magi_power',
    damage_type: 'magi',
    element: 'dark',
    power: 80,
    crit_rate: 0.05,
    params: {},
    desc: '闇属性の魔術攻撃。殴った敵に付与されているすべての状態異常を敵全体へ拡散する。',
  },
}
```

#### 処理ロジック概要
1. ターゲットにダメージを与える。
2. ターゲットに付与されている `statuses` を取得。
3. 他の生存している敵全員に対し、同じ異常（`kind`, `ratio`, `turns`）を付与する。

---

### 2.2 `barrier`（魔力障壁・シールド）

#### 目的と背景
純粋なHP回復（`heal`）だけでは「HP満タン時のオーバーヒール」や「HPが減っているほど強い背水キャラの保護」ができない問題を解決する。

#### パラメータ（`params`）
- `ratio`: シールド量の倍率（例: 1.5 = ステータスの150%分）
- `scaling`: 参照ステータス（`'magi_power'` | `'hp'` | `'def'`）
- `turns`: 障壁の持続ターン数（例: 3）
- `party`: `true` なら味方全体、`false` なら単体

#### 技定義の例
```js
skills: {
  sk_ex_rune_aegis: {
    name: 'ルーン・アイギス',
    kind: 'active',
    plugin: 'barrier',
    scaling_stat: 'magi_power',
    damage_type: 'magi',
    element: 'light',
    power: 0,
    cooldown: 4,
    params: { ratio: 2.0, scaling: 'magi_power', turns: 3, party: false },
    desc: '味方単体に魔力の200%分の魔力障壁を展開する（3ターン持続）。',
  },
}
```

#### 処理ロジック概要
1. 対象の味方に `shield: number` プロパティを付与/加算。
2. 被弾処理（`damage.js`）時に、HPが減る前に `shield` を優先して削る。

---

### 2.3 `chain_burst`（連鎖跳弾）

#### 目的と背景
単体技（高火力）と全体技（低威力）の中間となる「敵が少数〜複数の時に最も威力を発揮する手数技」を提供する。

#### パラメータ（`params`）
- `chains`: 最大跳弾回数（例: 4）
- `decay`: 跳弾ごとの威力減衰率（例: 0.15 = 1回飛ぶごとに-15%）または `bonus`（増加）

#### 技定義の例
```js
skills: {
  sk_ex_chain_lightning: {
    name: 'チェイン・ライトニング',
    kind: 'active',
    plugin: 'chain_burst',
    scaling_stat: 'magi_power',
    damage_type: 'magi',
    element: 'light',
    power: 120,
    crit_rate: 0.10,
    params: { chains: 4, decay: 0.10 },
    desc: '敵の間を最大4回跳弾する電撃。跳弾するたびに会心判定を個別に行う。',
  },
}
```

---

### 2.4 `charge_strike`（精神集中・チャージ）

#### 目的と背景
毎ターン殴るだけでなく、「1ターン溜めて次ターンに特大ダメージを叩き込む」というメリハリのある戦術や、ボスのブレイク・追加行動との合わせ技を作る。

#### パラメータ（`params`）
- `ratio`: 次の行動の威力倍率（例: 2.5 = 2.5倍）
- `critRate`: （省略可）次行動への会心率上乗せ（例: 0.50）
- `capBreak`: （省略可）次行動のダメージ上限突破（例: 0.50）

#### 技定義の例
```js
skills: {
  sk_ex_limit_charge: {
    name: '極限集中',
    kind: 'active',
    plugin: 'charge_strike',
    scaling_stat: 'atk',
    damage_type: 'phys',
    element: 'none',
    power: 0,
    cooldown: 3,
    params: { ratio: 2.5, critRate: 0.50, capBreak: 0.40 },
    desc: '精神を研ぎ澄まし、次のターンの攻撃威力を2.5倍・上限+40%突破・会心率+50%にする。',
  },
}
```

---

### 2.5 `combo_finish`（コンボフィニッシャー）

#### 目的と背景
小技・多段技・パッシブで稼いだ「コンボ段数」をリセットする代わりに、一撃で莫大なダメージに変換する「パーティーの終着点（フィニッシャー）」技。

#### パラメータ（`params`）
- `perCombo`: コンボ1段あたりの威力上乗せ率（例: 0.25 = 1段につき+25%）
- `maxRatio`: 最大上乗せ上限（例: 5.0 = 最大6倍）
- `consume`: `true`（コンボ段数を0にリセット）

#### 技定義の例
```js
skills: {
  sk_ex_final_resonance: {
    name: 'ファイナル・レゾナンス',
    kind: 'active',
    plugin: 'combo_finish',
    scaling_stat: 'atk',
    damage_type: 'phys',
    element: 'wind',
    power: 160,
    crit_rate: 0.15,
    params: { perCombo: 0.30, maxRatio: 5.0, consume: true },
    desc: '蓄積したコンボ段数をすべて消費し、1段につき威力+30%（最大6倍）の特大斬撃を放つ。',
  },
}
```

---

### 2.6 `counter_stance`（迎撃スタンス）

#### 目的と背景
盾役や高防御キャラが「敵を引きつけて殴られる」行為を、そのままパーティの主要ダメージソースへ昇華させる。

#### パラメータ（`params`）
- `turns`: スタンス持続ターン数（例: 2）
- `reduction`: スタンス中の被ダメージ軽減（例: 0.20）
- `counterSkill`: 反撃時に撃ち出すスキルID（例: `'sk_slash'`）

#### 技定義の例
```js
skills: {
  sk_ex_iron_counter: {
    name: '明鏡止水・構え',
    kind: 'active',
    plugin: 'counter_stance',
    scaling_stat: 'atk',
    damage_type: 'phys',
    element: 'earth',
    power: 0,
    cooldown: 4,
    params: { turns: 2, reduction: 0.25, counterSkill: 'sk_slash' },
    desc: '2ターンの間迎撃態勢を取り、被ダメージを25%軽減しつつ被弾時に斬撃で即時反撃する。',
  },
}
```

## 3. 実装・導入ステップのガイドライン

新規プラグインをコア（`src/plugins/`）に追加する際の標準的な手順：

1. **プラグインJSの作成**: `src/plugins/<plugin名>.js` を作成し、`RPG.plugins.<plugin名>` に登録。
2. **`index.html` への登録**: `<script src="src/plugins/<plugin名>.js"></script>` を追記。
3. **テストの追加**: `test/tests.js` に動作検証テスト（単体挙動、境界値、異常系）を記述。
4. **ドキュメントの更新**: `docs/拡張コンテンツの作り方.md` の「技（skills）」表にプラグイン名と params を追記。
5. **キャッシュ更新**: `python tools/build_precache.py` を実行。
