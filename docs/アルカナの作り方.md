# アルカナの作り方

アルカナ (§21) は**第二のクラス**。1人に1枚だけ就け、**大きな利と大きな害**を同時に背負う。
タロットの正位置と逆位置がそのまま利と害になる、という発想で作っている。

このファイルは、**実測して分かったこと**だけを書いてある。
「こうすると良さそう」ではなく「こうしたら数字がこう出た」で書く。
新しい札を考えるときは、まずここを読むこと。**同じ落とし穴が何度も口を開けている。**

---

## 1. いちばん大事な法則

> ### 数値を削る代償は、エンドビルドにほぼ全部吸収される。
> ### 効くのは、構造を変える代償だけ。

実ビルド（Lv255・限界突破5・装備2,207個）で代償の候補を片端から測った結果。
闘技場ハードで敵を倒せないようにして、8ラウンド（激昂）まで立てるかを見ている。

| 代償の案 | 結果 |
|---|---|
| 他者からの回復を止める | 8.0ラウンド → **7.9** |
| 他者からのバフも止める | 8.0ラウンド → **7.8** |
| パーティ全員の回復を止める | 8.0ラウンド → 6.9（**周回では差ゼロ**） |
| 属性を捨てる（無属性化） | **0%の損**（全属性適応Lv2を持つと有利1.5倍のまま） |
| 軽減を +20% 足す（逆向きの確認） | 7.8ラウンドのまま**変わらない** |
| HPを25倍にする（闘技場） | 落ちるラウンドが **3.7で不動** |

耐久・支援・HP・属性は、どれも装備と育成で埋められる。**埋められないものを探すこと。**

実際に効いた代償は、どれも「量」ではなく**仕組み**に手を入れている。

| 札 | 代償 | 何をしているか | 効き |
|---|---|---|---|
| 戦車 | `draw_fire` | **誰が殴られるかを書き換える** | 立てるラウンド 7.9 → 2.6 |
| 死 | `final_count` | **行動の回数を数える** | 闘技場で必ず終止符（2.5ラウンド目） |
| 魔術師 | `no_repeat` | **組み立てを禁じる**（最大火力の技を連打できない） | 闘技場の与ダメ 11M → 8M |
| 皇帝 | `decree` | **手番の持ち主を入れ替える** | 担ぎ手に着けると HP×300 で 5.1R → 19.4R |
| 正義 | `justice` | **攻撃の前に被弾を差し込む**（対象の敵の最強技を先に受ける） | 先制＋あまねくで主人公の倒れる戦 30% → 90% |
| 月 | `moon` | **ダメージが成立する場所を仲間の手番へ移す**（自分では削れない） | 雑魚の群れ HP×30 で 10.42R → 11.50R |
| 女帝 | `empress` | **自分の育成を半分にして編成へ配る**（自分のパッシブも半分） | 主人公に着けると DEF→ATK が半分になり、ボス6Rで 157B → 19B |
| 教皇 | `ritual` | **他の者の通常手番を使う**（加わった仲間は自分の技を選べない） | 全員強制にするとボス戦で回復役まで殴らされ、53M → 40M |
| 運命の輪 | `wheel` | **技の選び方に順番を課す**（外れると現在HPが半分） | オートに任せると HP×3000 で 6.50R → 7.45R |

逆に、数値を下げるだけの案はこの表に一つも残らなかった。

## 2. 効く利・効かない利

### 効くもの

| 効果 | なぜ効くか |
|---|---|
| `cap_break`（ダメージ上限突破） | **終盤で実効のある火力はこれだけ。** 上限の減衰は超過分を10%しか残さないので、威力だけ足しても潰れる |
| `turn_gift`（手数） | 手数は上限に潰されない。ダメージ上限は1発ごとに掛かるので、発数が増えれば天井も増える |

**ただし上限の「壁」を広げる効きにも天井がある。** 強化の乗った終盤の一撃は素点が上限の十数倍に達し、
そこでは一撃の大半が壁の先の ×0.1 の部分になる。壁を +200% しても ×1.17 にしかならなかった
（正義の実測。主人公の黄昏）。一時的な強化で**確実に倍率を出したい**なら、
節制のように威力と上限を同じ倍率で動かすか、正義のように「上限で削られた後の値」を引き上げる
（`min(素点, 削られた値 × (1+X))`）。**「曲線ごと拡大」は壁を広げるのと同じ式に化ける**ので使えない。
| 構造を変えるもの | 狙われ方・行動回数・倒れ方など |

### 効かないもの

| 効果 | なぜ効かないか |
|---|---|
| `stat_pct`（ATK・魔力などの％増加） | **装備が9割を占める。** 実ビルドに +60% を乗せても与ダメージは +5.6% にしかならなかった |
| 威力％だけを足す | 上限減衰に潰れる。実測で、威力を2000%にしても闘技場の勝率は0%のままだった |
| 属性まわり | `tr_adapt` Lv2「全属性適応」が**デメリット無しで全攻撃を有利1.5倍**にする。属性有利を配る札は既存ノードに負ける |
| 系統タグを1つ増やす程度 | 系統タグ倍率は実測 **×7.4〜×21.8**（タグ17本）。属性有利1.5倍などでは釣り合わない |

### 状況依存の倍率は「その状況でいる時間」で決まる

`low_hp_power`（瀕死ほど火力）のような効果を**戦闘中の平均で測ると薄まる**。
一度これで誤った結論を出した。

- 戦闘中の平均で測る → 「500%にしても +5.5%」
- HPを固定して測る → **HP10% で ×2.13**

条件を固定して測ること。そのうえで「その条件でいる時間」を別に測る。

**利と害を噛み合わせると、この問題ごと解ける。**
死は「必ずHP1で耐える」ので背水が常に最大で乗る——状況を利の側が作っている。

## 3. 発火しない参照先（作る前に確認すること）

提案の段階では良く見えるのに、**実測すると一度も発火しない**参照先がある。

| 参照先 | 実測 |
|---|---|
| **倒れている味方の数** | 主人公が行動する時点で**常に0人**。分布は `{"0": 9}` で例外なし（ウェーブ移行で味方が戻るため）。**常世セットの `fallenPower` が死んでいるのも同じ理由** |
| **撃破した敵の数** | 周回では9.8体まで伸びるが、**闘技場は雑魚がほぼ居ない**ので伸びない。利が周回で害が高難度、という逆向きの札になる |
| **長期戦であること** | 終盤は**1ウェーブ1ラウンドの床**に張り付く。周回で長期戦は起きない |

新しい参照先を思いついたら、**まず「それは何回起きるか」を数えるコードを書く。**
効果を実装する前に数えること。

## 4. 設計のチェックリスト

新しい札の案は、この6つを通してから実装に入る。

1. **軸は空いているか。** 既存の札が占めている軸（§5の表）と重なっていないか
2. **利と害の向きは揃っているか。** 「周回で利が出て高難度で害が出る」札は成立しない。
   高難度でこそ利が出て、高難度でこそ害を払う形にする
3. **代償は構造を変えているか。** 数値を削るだけなら吸収される（§1）
4. **つまみは1つか。** 死は `8` ひとつで利と害の両方が決まる。2つ以上あると測る回数が掛け算で増える
5. **確率が入っていないか。** 吊るされた男は当初 `extra_action` で返す負債にしたが、
   「平均が足りていても運が悪いと延々動けない」という体験になり捨てた。
   **期待値ではなく体験で測ると、確率つきの代償は実態より弱く見える**
6. **目盛りがあるか。** `turn_stride`（2回に1回）は `ticks % stride` なので 2 の次が 3 で、
   「3回に2回」が作れず**段差にしかならなかった**。比率や回数のように連続して置ける形にする

## 5. 既存の札と、占めている軸

| 札 | 軸 | 利 | 害 |
|---|---|---|---|
| **力 VIII** | 火力倍率 | 与ダメージ大＋上限突破 | 自分のDEF由来の軽減層が消える |
| **戦車 VII** | 手数と狙い | 毎ラウンド+1手番／7回まで立ち上がる | 必ず狙われ、軽減・障壁・庇いが働かない |
| **吊るされた男 XII** | 一撃の重さ | 必ず会心＋威力＋上限突破 | 15%で行動できない |
| **死 XIII** | 刻限 | 8回行動するまでHP1で耐える／残る手が少ないほど鋭い | 8回目の行動で必ず倒れる |
| **魔術師 I** | 系統タグと支援 | 全技が魔術系統になる／攻撃のたび味方へ障壁と回復 | 同じ技を続けて使えない |
| **皇帝 IV** | 手番の持ち主 | 自分の手番を味方1人の即時行動に置き換える | 命令できる味方がいる間、自分の技を使えない |
| **恋人 VI** | 編成の縛り | 同じ札を持つ味方1人につき火力 +45% | 受けた被害を、同じ札を持つ味方と分け合う |
| **節制 XIV** | 回復の余り | 回復技であふれた回復を、次の攻撃1行動の強化に変える | 溜まるのは回復技のあふれだけ。次の攻撃で使い切る |
| **正義 XI** | 被弾の順番 | 裁きを耐えた一撃は、上限で削られた値が最大 +100% | 攻撃の前に、対象の敵から最も重い攻撃を受ける |
| **女帝 III** | 育成の共有 | SPで取ったツリーのパッシブの半分を、他の味方それぞれへ（回数・ターンは切り捨て） | 自分に働くそのパッシブも半分。倍率・有無・一度きりは分けない |
| **教皇 V** | 手番の共有 | 自分の通常手番の攻撃技を、その技のほうが削れる後ろの仲間も各自の能力で撃つ | 加わった仲間はそのラウンドの手番を使い、自分の技を選べない |
| **運命の輪 X** | 技の系統の順番 | 物理→魔術→遺物の順で 防御崩壊・標的・凍結、一周で味方全員の次の一撃の上限 +100% | 輪に反した攻撃1回につき、敵が動く直前に現在HPが半分 |
| **月 XVIII** | ダメージの成立先 | 刻んだ幻傷を仲間の攻撃で実体化（敵1体・1ラウンド3回まで） | 自分の攻撃では敵のHPを減らせない。敵が動くと幻傷は消える |

**この表は札を足すたびに更新すること。** 軸が空いているかを見るための表なので、
古いままだと「空いている」と誤って判断する。

空いている軸の例: **時間**（ラウンドが進むほど）、**属性**（ただし `tr_adapt` Lv2 に
勝てる形が要る）、**隊列**（前後の並びを賭ける）。

### 棲み分けの書き方

似た題材でも、**死をどう扱うか**のように一段掘ると分かれる。

- 戦車 … 倒れても起き上がる＝**死を遅らせる**（回数ぶん、見返り無し）
- 死 … 刻限までは倒れず、近づくほど鋭い＝**終わりを力に変える**

新しい札を足すときは、既存のどれと隣接するかを書き、**何が違うのか**を1行で言えるようにする。

## 6. 測り方

### 物差しの選び方

| 測りたいもの | 使う場所 | 理由 |
|---|---|---|
| 純粋な耐久 | 闘技場ハード＋**敵を倒せなくする**（`e.maxHp = 1e15`） | 味方の火力で押し切ってしまうと耐久が測れない。実測でずっと4.0ラウンドで終わっていた |
| 一撃の重さ | `damage.calc` を**条件固定**で | 戦闘中の平均は、その条件でいる時間に薄められる |
| 周回への影響 | 相なしの5ウェーブ | ここで差が出る札は周回を壊す |
| 高難度への影響 | 相を重ねた場（先制＋あまねく等） | 闘技場は1ラウンドで終わることがあり測れない |

### 踏んだ罠

- **`q_endless_vigil` を物差しに使わない。** 「8ラウンド以内」が達成条件なので、
  手番を減らす札は火力をいくら上げても 0% に張り付き、**数値に反応しない**
- **倒し切ると与ダメージが残HPで頭打ちになる。** 手番の少ない条件ほど敵が健在なので
  「1発が重い」と誤って出る。実際「刻みだけ」で一撃1.18倍という有り得ない値が出た
- **`enemyScale: { hp: 100000 }` は使えない。** 割合ダメージの技が跳ね上がる
- **物差しの編成はSP残りを確認する。** アストラ141/259・ルーメン150/259・
  テオドラ259/259（丸ごと未使用）で測っていたことがある。
  「あの2人が落ちる」は戦闘の厳しさではなく未育成だった
- **闘技場の被害上限は「天井」で「床」ではない。** `maxHitRatio` は一撃死を防ぐ緩和なので、
  **闘技場のほうが通常フィールドよりやさしい**。等倍の周回フィールドで先制の相を付けたら、
  1発が最大HPの290%（相を重ねると587%）になった
- **テストページは途中で読むと部分集計が出る。** 非同期の検査が終わるまで待つこと

### 数値の目安

実ビルドでの一撃の倍率帯。新しい札はこの並びに収まるように置く。

| 札 | 一撃 |
|---|---|
| 力 | ×1.4 帯 |
| 死（最後の一撃） | ×3.17（斬撃 ×2.23／黄昏 ×2.68／終焉の一撃 ×4.60） |
| 吊るされた男 | ×2.7〜3.3 帯 |
| 正義 | 上限に当たる一撃だけ ×2.0（上限に届かない一撃は ×1.0。上限無視の技には足さない） |
| 女帝 | 一撃は変えない。補助役の変換（DEF→ATK など）の半分が主人公へ。ボス6Rの総与ダメ 157B → 257B（補助役1人が女帝） |
| 教皇 | 一撃は変えない。仲間の手番を教皇の技に置き換える（得なときだけ）。ボス相手の総与ダメ 53M → 82M（シャンタルが教皇） |
| 運命の輪 | 一撃は変えない。弱体3種と一周の祝福で味方の一撃を伸ばす（ボス相手の総与ダメ ×1.95、持ち主が3系統を持つとき） |
| 月 | 一撃を最大3回ぶん仲間へ預ける。ボス相手のパーティ総与ダメで +20〜32%（力と戦車のあいだ） |

**重い技ほど伸びる形が好ましい。** 小技は上限に当たらないので伸びしろが小さく、
上限突破を使うと自然に「大技だけが伸びる」ようになる。威力%だと小技まで膨らむ。

## 7. 足すときに触るファイル

効果種を新しく作るなら `docs/効果を追加するときの手引き.md` の5ファイル7箇所が先。
そのうえでアルカナ側は次を触る。

| ファイル | 何を書くか |
|---|---|
| `data/arcana.js` | 札そのもの。**なぜその数値なのかを実測つきでコメントに残す** |
| `data/quests.js` | 解放依頼。札の像を条件にする |
| `assets/ui/arcana-<名前>.svg` | 128px・白の塗りだけの単色マスク。26pxでも読める形に絞る |
| `test/tests.js` | 効果がユニットまで届くか、振る舞いが出るか |
| `docs/作業ログ/<題目>.md` | 測った値と、**没にした案とその理由** |

### 解放依頼の作り方

既存の札は、**札の像そのものを条件にしている**。

| 札 | 依頼 | 条件 |
|---|---|---|
| 力 | 退かぬ者 | 2人以下・HP×120 |
| 吊るされた男 | 三手の内 | 7ラウンド以内・HP×90 |
| 戦車 | 止まらぬ轍 | 2人以下・9ラウンド・HP×40 |
| 死 | 十三の門 | 13ウェーブ・**誰も欠けさせない** |
| 魔術師 | 一度きりの術式 | **同じ技を続けて使わない**・HP×60 |
| 皇帝 | 座して統べる | **主人公を一度も行動させない**・HP×70 |
| 恋人 | 二人の誓い | **2人だけ**で・誰も欠けさせない・HP×50 |
| 節制 | 注ぎ分ける者 | 誰も欠けさせない・**7ラウンド以内**・HP×55 |
| 正義 | 天秤の前で | **先を取る相**（敵が先に動く）・誰も欠けさせない・敵Lv210・HP×50 |
| 月 | 月下の四手 | **4人そろって**・ボスだけの1ウェーブ・6ラウンド以内・敵Lv225固定・HP×160 |
| 女帝 | 行き渡る実り | **あまねく相**（敵の攻撃が全員へ）・誰も欠けさせない・創世の残響 敵Lv160・HP×30 |
| 教皇 | 四声の祈り | **4人そろって**・誰も欠けさせない・12ラウンド以内・臨界の際 敵Lv225・HP×10 |
| 運命の輪 | 巡る三相 | **物理→魔術→遺物を2周**（規則 `wheelLaps`）・15ラウンド以内・HP×50 |

使う規則は `maxParty` / `maxRounds` / `allAlive` / `noRepeat` / `idleHero` / `wheelLaps` / `noAuto`。
依頼から異相を名指しすることもできる（`aspectIds`）。規則を新設せずに場の条件を足せる。
**まだ使われていない規則を選ぶ**と、依頼どうしの手触りが分かれる。

難度は**解放レベル帯（Lv200前後）を想定して置く。**
実ビルドに合わせて上げると、本来の対象者が挑めなくなる。
実測では、このエンドビルドは13ウェーブ HP×600 でも床（1ウェーブ1ラウンド）で通る。

## 8. 文面の書き方

- 利と害を**1行ずつ**で言い切る。読んだ瞬間に何が起きるか分かること
- 数値は札に書く。「大きく上がる」より「8回行動するまで」のほうが選べる
- 惹句（`flavor`）は1行。説明ではなく像を置く
- `desc` は「どういう姿か」。効果の言い換えにしない

## 9. 捨てた案の記録も残す

`data/arcana.js` のコメントには、**没にした案とその実測**を書いてある。
同じ案が何度も浮かぶので、「測って落ちた」記録がいちばん効く。

死の札には4つ書いてある——倒れた味方の数・撃破数・パーティ全員の回復不可・背水を威力でやる案。
新しい札でも同じように残すこと。
