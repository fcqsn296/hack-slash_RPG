# 教皇 V — 実装案

作成日: 2026-09-21
状態: 設計案。実装・整合性検証・バランス実測は未実施。

## 設計意図

教皇が使う技を儀式として仲間も実行する。参加者は自分の手番を使い、各自の能力とパッシブで同じ技を使う。
強いアタッカーのダメージを複製する札ではなく、「各人の異なる育成を、共通の技で働かせる札」とする。

最初の検証例は、攻撃時の確率デバフを積んだ4人が、教皇の固有多段技を使う構成。
その技を所持していない者も多段の手数を得て、本人のデバフ付与パッシブを活かせる可能性がある。
ただし、各ヒットで抽選されるか、重複付与の価値が残るかは実装担当が確認する。成立済みとは扱わない。

皇帝は他者本人の技に手番を渡す。月は保存した一撃を実体化する。教皇は技の構造を共有し、各自の能力で実行する。

## 札の文面案

- 利: 自分が使う技を、仲間もそれぞれの能力で実行する。
- 害: 参加した仲間は自分の手番を使い、その手番では自分の技を選べない。

参加範囲・対象技を確定した後、文面にも正確に反映する。
初版では「使える技ならすべて複製する」とせず、技の共有可否を明示する。

## 共有するもの・しないもの

| 教皇の技から共有 | 参加者本人から使う |
|---|---|
| 技の基本威力、固有の段数、基本属性と系統、対象範囲、技自体の効果 | 能力値、属性・系統の変換、系統倍率、会心、装備、ツリー、クラスのパッシブ、状態異常への投資 |

- 教皇の最終ダメージをコピーしない。
- 教皇のパッシブ由来の連撃回数や状態異常付与を全員に配らない。
- 参加者の多段・連撃・累撃等は本人の通常ルールで判定する。既存の排他や上限を解除しない。
- 共有した技を恒久的に習得させない。実行中だけ技定義を借りる。
- キャラ固有の資源や特殊状態を必要とする技は、参加者にも成立するかを調査する。条件を無視して配らない。

## 手番についての初期提案

以下は、これまで提案した制御案を実装検証の出発点として整理したもの。ユーザーが細部まで確定した仕様とは混同しない。
実装担当は現在の手番管理と照合し、成立しない点は根拠と代案を示す。

### 参加と消費

- 教皇自身の通常手番で儀式を開始する。
- 仲間は、生存しており、そのラウンドの通常手番が未使用で、共有技を合法に実行できる者だけが参加する。
- 初版の参加者は通常の出撃メンバーとする。召喚体まで含む拡張は人数・手番・画面を別に検証する。
- 儀式開始時に参加者と使用する手番を予約し、教皇から始めて安定した隊列順で1人ずつ実行する。
- 参加者1人の実行は、その人の通常手番1つを消費する。後で同じ通常手番をもう一度与えない。
- 既に動き終えた者へ、儀式を理由に新しい手番を作らない。
- 不参加者の通常手番は残す。生きている仲間全員を無条件に行動済みにしない。
- 儀式中は他の通常手番を割り込ませず、儀式終了後に未使用の手番へ戻る。

参加者を選べるか全員参加かは未確定。初版は適格な仲間全員が参加する案とし、参加者と失う通常手番を実行前に表示する。
自由に一部だけ参加できる場合、役割を縛る代償が薄れるため別に評価する。

### 手番の由来ごとの扱い

| 手番の由来 | 初期提案 |
|---|---|
| 教皇の通常手番 | 儀式を開始できる |
| 教皇の確率再行動・奇襲等 | 本人だけが技を実行する。新しい儀式は始めない |
| 皇帝から教皇へ渡された手番 | 本人だけが技を実行する。命令の再行動制限も守る |
| 号令等で教皇が得た追加手番 | 本人だけが技を実行する。通常手番に変換しない |
| 参加者の未使用の通常手番 | 儀式の実行へ充当する |
| 参加者が既に持つ追加行動権 | 通常手番とは別に残す。儀式への参加で勝手に消さない |
| 儀式で参加者が起こした再行動 | 既存の発火条件・本人の上限内で認める案。儀式終了後に本人の追加手番として解決し、儀式は起動しない |
| 次ラウンドの手番負債・反動による行動不能 | 儀式参加で帳消しにしない。通常の参加可否と支払い順序を検証する |

同じ追加行動権を予約時と実行後で二重に消費・発行しない。
「通常手番」「追加行動」「他者から借りた行動」を、行動者の位置だけで推測しない。
現行の `actorIndex` や真偽値の追加行動権だけで区別できなければ、行動の由来・消費元を明示する構造が必要。

### 増加・減少の重要な留意点

- 通常手番が4つの編成なら、4人の儀式は4つの通常手番を使う。技の多段を4回の手番と数えない。
- 行動権を予約した時点で失ったのか、実行時に使ったのかを分けて記録する。
- 儀式中の死亡・麻痺・反動等で動けない場合、別人へ手番を移したり、成功するまで何度もやり直したりしない。
- 行動不能時の手番消費、負債返済、追加行動の処理は現在の戦闘規則に合わせる。候補を表示しただけで負債を減らさない。
- 既存の追加行動権の重複上限を、儀式用の予約列を作ったことで撤廃しない。
- 儀式で生まれた再行動を後へ回すことで、状態異常・死亡・全滅の順序が変わる点も検証する。
- 前の参加者が敵を倒し切った場合は儀式を打ち切る。残る予約行動を次ウェーブへ持ち越さない。
- 敵フェーズやラウンド更新は、儀式の各参加者ごとには行わない。残る通常手番・追加行動を適切に処理してから1回だけ進める。

## 技の共有可否と対象

最初は固有多段の攻撃技で実装と価値を確認する。回復・支援技まで一括で許可することを前提にしない。

- 号令、前借り、召喚、儀式など、手番やユニットを生成する技は初版の共有対象外を推奨する。
- クラス固有技・解禁ラウンド・コンボ資源・固有ゲージは、所有者以外へ許可する意味を個別に確認する。
- 共有できない技を教皇が選んだときは本人のみ実行する案。全行動の共有を強制する案とは区別し、代償が薄れないか評価する。
- 単体攻撃は教皇が選んだ対象を共有する案。実行前に対象が倒れた場合、残敵から同じ規則で再選択するか不発にするかを確定し、手動・オートで一致させる。
- 全体技は各参加者の実行時点の生存対象を使う。
- 参加者がその技を元から持っている場合のCT競合も確認する。
- CTと資源を本人だけが払うのか、参加者も払うのかは未確定。初案は参加者も借りた技の使用条件・CT・本人側資源を適用し、合法に使えない者は参加不可とする。
- 技を知らないことだけは、儀式中の実行を拒む理由にしない。通常コマンドでは未習得技を使えない状態を維持する。

## パッシブと他のアルカナ

- デバフ付与は各参加者の効果・確率を用いる。抽選回数は技と既存の発火規則に従い、儀式だけ特別にヒットごとの抽選へ変えない。
- 累撃は参加者本人の1行動として扱う。教皇の段数を移さず、技の各ヒットで余分に進めない。
- 魔術師の系統変換・連続使用禁止・攻撃後支援などは本人の規則を保つ。
- 死の刻限も、参加者本人の実行した行動として通常どおり数える。
- 月・節制・正義等は最新の採用仕様に従い、参加者の札の規則を適用する。未実装なら未確認として記録する。
- 皇帝持ちは、自分の技を使えない条件が成立している間、儀式によってその禁止を迂回させない。参加可否を既存の中核判定へ通す。
- 別の教皇が儀式に参加しても、その実行から儀式を再帰起動しない。

## 実装担当への手順

### 1. 確認

CLAUDE.md、知見の索引、アルカナの作り方、手番・号令・皇帝・行動不能・累撃・デバフの最新実装を読む。
通常手番と追加手番の現在の区別を調べ、手番の発生元・消費先・リセット箇所を一覧にする。
他の作業の未コミット変更を確認し、上書きしない。

### 2. 検証

固有多段技1つと、異なる攻撃時デバフを持つ4人で、技共有の価値を検証できる条件を作る。
手番の台帳として、通常手番の消費、追加権利の取得・消費、失敗・消失を記録する。
実装前に確認できないものは未検証として残し、本実装後の検査条件を先に定める。

### 3. 実装

技を共有する処理と、手番を予約・消費する処理を分ける。
全員に技を直接連続実行させるだけで、合法性・麻痺・CT・刻限等を飛ばさない。
通常の技実行経路を共有し、儀式の参加行動には由来と復帰先を持たせる。
UI・オート・測定ツールは同じ中核判定を使う。
効果登録一式、札、検査を揃え、採用後に解放依頼・単色アイコン・知見を整える。

## 必須の検査

1. 4人儀式で通常手番を4つ消費し、未使用者だけが参加する。
2. 教皇の隊列位置を変えても、既に消費した手番が復活しない。
3. 教皇の再行動・皇帝の命令・号令で儀式が連鎖しない。
4. 参加者の既存の追加行動権が失われず、新規発生も既存上限を守る。
5. 死亡・麻痺・負債・反動・途中制圧で予約の重複や停止がない。
6. CT・資源・未習得技の例外が儀式中だけ適用される。
7. 各参加者の固有パッシブだけが発火し、教皇の付与効果を全員へコピーしない。
8. 多段とデバフ抽選の関係、状態異常の重複・上限が既存規則に従う。
9. 儀式中に敵フェーズやラウンドが重複して進まない。
10. 手動入力・オート入力・行動数・撃破報酬を二重計上しない。

## バランス評価

比較対象は「各自が自分の技を使う4人」と「同じ4人が儀式に参加する構成」。SP・装備・編成枠を上乗せしない。
単純な攻撃技の複製だけで結論を出さず、次を測る。

- デバフ役4人による固有多段の共有。
- デバフ役と通常アタッカー・支援役を混ぜた編成。
- 再行動なし／あり、皇帝・号令と組み合わせた編成。
- 単体ボスと複数敵、短期周回と長期戦。

記録する値: 勝敗、通算ラウンド、敵行動数、通常・追加・儀式別の実行行動数、デバフの付与試行数・成功数・維持時間、上限で無駄になった付与、総ダメージ。
回復や支援の手番を儀式へ使う損も記録する。
既に付与率や状態異常が上限に達していて追加抽選の価値がない場合、デバフ構成が成立したとは扱わない。

教皇がいることで、他のキャラの育成に新しい使い道が生まれることを採用理由とする。
手番を消費したのに弱い攻撃を複製するだけなら不採用。逆に手番の二重発行で強いだけなら実装不具合として直す。

## 残る判断

対象技、参加の任意性、追加行動の解決順、CT・資源、対象死亡時の再選択を確認・検証後に確定する。
これらは強さだけでなく操作の理解しやすさにも関わるため、無言で仕様を補完しない。
大きな変更が必要な場合は具体的な比較結果と代案を示し、それ以外の内部設計は担当の判断で進める。

今回の成果物はこの実装案のみ。ゲーム本体の実装・公開は行っていない。
